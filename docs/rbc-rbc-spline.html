Spline interpolation¶

The spline command performs spline interpolation and extrapolation on data stored in Rbc vectors. Two interpolation methods are available:

  • natural - natural cubic spline interpolation.

  • quadratic - shape-preserving quadratic spline interpolation.

Both operations use the same four-vector interface:

spline method x y splX splY

The vectors x and y contain the source data points. The vector splX contains the X coordinates at which the spline is evaluated, and splY receives the corresponding calculated Y coordinates.

Source data¶

The source vectors x and y must have the same length and contain at least three values. All source X and Y values must be finite.

Values in x must be strictly increasing. Duplicate or decreasing X coordinates are not permitted.

For example:

vector create x y

x set {0 1 2 3 4}
y set {0 2 1 4 3}

If source data are not already ordered by X coordinate, the vector sort operation can reorder x while applying the same permutation to y:

x sort y

Evaluation coordinates¶

The splX vector specifies the X coordinates at which the spline is evaluated. All values in splX must be finite.

Unlike the source x vector, splX does not have to be sorted. Evaluation coordinates may appear in any order, and the values in splY are produced in the corresponding order.

For example:

splX set {2.5 0.5 4.5 -1.0 1.5}
spline natural x y splX splY

Each component of splY corresponds to the component at the same position in splX.

Evaluation coordinates may lie outside the range of the source x vector. Both spline methods extrapolate such points:

  • values below the first source X coordinate are extrapolated using the first spline interval;

  • values above the last source X coordinate are extrapolated using the last spline interval.

Thus interpolation and extrapolation use the same command and no separate extrapolation option is required.

Generating evaluation coordinates¶

The vector populate operation is convenient for generating a more densely sampled set of X coordinates between the original source points:

x populate splX 10
spline natural x y splX splY

populate is not required. splX may contain any finite coordinates appropriate for the application.

Output vector¶

The result vector splY has the same length as splX.

If splY does not exist, it is created. If it already exists, it is resized when necessary and its previous contents are replaced.

Spline generation is transactional. The source vectors and evaluation coordinates are validated and the complete result is calculated before splY is created, resized, or modified. If spline generation fails, an existing splY vector is left unchanged.

Because the inputs are copied before the output vector is modified, splY may safely be the same vector as x, y, or splX.

Example¶

The following example generates both natural and quadratic spline values from the same source data:

vector create x y splX

x set {0 1 2 3 4}
y set {0 2 1 4 3}

splX set {-1.0 0.0 0.5 1.5 2.5 4.0 5.0}

spline natural x y splX naturalY
spline quadratic x y splX quadraticY

The first and last evaluation coordinates lie outside the source range and are therefore extrapolated.

Natural cubic spline¶

A natural spline is a piecewise cubic interpolating function that passes through every source data point. Its second derivative is zero at the first and last source points, providing the natural boundary conditions.

For evaluation coordinates outside the source range, the cubic polynomial of the first or last spline interval is continued beyond its endpoint.

Natural cubic splines generally produce smooth curves with continuous first and second derivatives.

Shape-preserving quadratic spline¶

The quadratic method generates an osculatory piecewise quadratic spline. Slopes at the source points are selected to preserve monotonicity and convexity where those properties are compatible with the source data.

For evaluation coordinates outside the source range, the spline defined by the first or last source interval is continued beyond its endpoint.

This method can be useful when preserving the qualitative shape of the source data is more important than the additional smoothness of a cubic spline.

Errors¶

Spline generation fails if:

  • either source vector contains fewer than three values;

  • the source vectors have different lengths;

  • a source X or Y value is not finite;

  • the source X coordinates are not strictly increasing;

  • an evaluation X coordinate is not finite;

  • required temporary storage cannot be allocated;

  • the spline calculation produces an invalid numerical result.

An error does not partially modify the output vector.

References¶

The natural cubic spline implementation is based on:

      1. Burden, J. D. Faires and A. C. Reynolds, Numerical Analysis, Prindle, Weber & Schmidt, 1981.

The shape-preserving quadratic spline implementation is based on:

      1. McAllister and J. A. Roulier, An Algorithm for Computing a Shape-Preserving Osculatory Quadratic Spline, ACM Transactions on Mathematical Software, Algorithm 574.
