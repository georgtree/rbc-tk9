Pen and palette C reference¶

These private services distinguish counted named-pen references from borrowed normal-palette entries. See Pens and style palettes for lifetime and selection rules.

Named pen references¶

int Rbc_GetPen(Graph *graphPtr, const char *name, Rbc_Uid classUid, Pen **penPtrPtr)¶

Acquire a reference to a named pen of a compatible concrete type.

Pair each successful acquisition with Rbc_FreePen. The returned pointer is graph-owned and must not outlive graph teardown.

Parameters:

  • graphPtr – Owning graph and interpreter for diagnostics.

  • name – Pen name to resolve; delete-pending pens are not found.

  • classUid – Required element class; strip and polar use line pens.

  • penPtrPtr – Receives the referenced pen on success.

Returns:

TCL_OK after incrementing refCount, or TCL_ERROR without acquisition.

void Rbc_FreePen(Graph *graphPtr, Pen *penPtr)¶

Release one acquired named-pen reference.

Decrements refCount and destroys the pen only when it reaches zero and PEN_DELETE_PENDING is set. Does not request deletion of a live named pen. Do not use for an uncounted embedded pen or a palette’s borrowed first entry.

Parameters:

  • graphPtr – Owning graph.

  • penPtr – Non-NULL pen for which the caller owns a counted reference.

Graph resource teardown¶

void Rbc_ReleasePenTkResources(Graph *graphPtr)¶

Release registered pen resources while the graph window is live.

Releases derived resources before Tk-owned option resources. Skips records not initialized or already released; leaves records and registry entries intact for later destruction. Does not release element-embedded pens.

Parameters:

  • graphPtr – Graph with initialized pen registry and live Tk window.

void Rbc_DestroyPens(Graph *graphPtr)¶

Destroy the graph’s remaining registered pens and pen hash table.

Does not wait for reference counts: element references must already have been released. Tk-dependent resources must be released before the window disappears. This destroys registry infrastructure and is not repeatable.

Parameters:

  • graphPtr – Owning graph during final teardown.

Element palettes¶

void Rbc_FreePalette(Graph *graphPtr, Rbc_Chain *palette)¶

Release named style entries while retaining the normal palette entry.

Releases pen references and removes links after the first entry. Does not release the first entry’s pen or destroy the chain itself. The caller owns the remaining chain and must destroy it when appropriate.

Parameters:

  • graphPtr – Owning graph used to release pen references.

  • palette – Valid palette chain; its first entry borrows the normal pen.

PenStyle **Rbc_StyleMap(Element *elemPtr)¶

Allocate a per-data-point map of borrowed palette style pointers.

Unmatched or unweighted points retain the first (normal) style. Weighted points search entries from last to first using normalized range tests with DBL_EPSILON tolerance. The map acquires no pen references and must not outlive its palette entries. Allocation-size overflow invokes Tcl_Panic.

Parameters:

  • elemPtr – Element with a valid nonempty palette and current data.

Returns:

Allocated pointer array owned by the caller; release with ckfree, including for zero points. Entries borrow styles from the element palette.
