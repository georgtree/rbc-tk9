Pen and palette C reference

These private services distinguish counted named-pen references from borrowed normal-palette entries. See Pens and style palettes for lifetime and selection rules.

Pen ownership and palette records

typedef struct PenStruct Pen
struct PenStruct

Common prefix of concrete drawing pens.

Named pens use counted references and deferred deletion; element-embedded pens follow their concrete owner lifetime. Keep this prefix compatible with concrete pen records.

Public Members

char *name

Named-pen identifier; embedded/default pens need not have a registry name.

Rbc_Uid classUid

Interned component class identifier.

char *typeId

Concrete pen type identifier used for compatibility checks.

unsigned int flags

Pen state bits, including PEN_DELETE_PENDING.

int refCount

Number of retained named-pen references.

Tcl_HashEntry *hashPtr

Registry entry referring to this record; NULL after detachment.

const Tk_OptionSpec *optionSpecs

Borrowed immutable option specifications for the concrete component type.

Tk_OptionTable optionTable

Tk option table associated with this record; managed by its configuration lifecycle.

int optionsInitialized

Nonzero once Tk option initialization has completed.

int tkResourcesReleased

Nonzero after the guarded Tk-resource release pass.

PenConfigureProc *configProc

void Rbc_FreePen(Graph *graphPtr, Pen *penPtr)

Release one acquired named-pen reference.

Decrements refCount and destroys the pen only when it reaches zero and PEN_DELETE_PENDING is set. Does not request deletion of a live named pen. Do not use for an uncounted embedded pen or a palette’s borrowed first entry.

Parameters:

  • graphPtr – Owning graph.

  • penPtr – Non-NULL pen for which the caller owns a counted reference.

Unmatched or unweighted points retain the first (normal) style. Weighted points search entries from last to first using normalized range tests with DBL_EPSILON tolerance. The map acquires no pen references and must not outlive its palette entries. Allocation-size overflow invokes Tcl_Panic.
