Marker C reference¶

These private entry points borrow the graph. Mapping and drawing assume the caller has prepared the appropriate layout and retained graph lifetime. See Marker lifecycle and drawing for class dispatch, special window behavior and cleanup.

Mapping and output¶

void Rbc_MapMarkers(Graph *graphPtr)¶

Map pending marker geometry in display-list order.

Skips hidden markers and markers without coordinates. MAP_ALL or MAP_ITEM selects mapping; each class mapper runs in a paired owning-track viewport scope and MAP_ITEM is cleared afterward. Does not draw or update axes.

Parameters:

  • graphPtr – Borrowed graph with prepared axes and plot geometry.

void Rbc_DrawMarkers(Graph *graphPtr, Drawable drawable, int under)¶

Draw one marker layer and synchronize embedded child visibility.

Synchronizes windows from both layers even when drawing only one layer. Track drawing preserves painter order with per-track clipping; ordinary graphs may batch compatible adjacent primitives. Window markers manage real children rather than paint them into the supplied drawable.

Parameters:

  • graphPtr – Borrowed live graph with current mapped marker geometry.

  • drawable – Borrowed compatible screen drawable.

  • under – Layer selector: 1 below elements, 0 above elements.

void Rbc_MarkersExport(Graph *graphPtr, Rbc_ExportContext *exportPtr, int under)¶

Export eligible markers from one layer in display-list order.

Skips missing exporters, absent coordinates, hidden markers and markers associated with an existing hidden element. Non-window track markers use a track viewport and renderer clip; window export follows its own capture path. Does not perform layout or own the export context.

Parameters:

  • graphPtr – Borrowed graph with export layout already mapped.

  • exportPtr – Borrowed initialized export context.

  • under – Layer selector: 1 below elements, 0 above elements.

Resource and record cleanup¶

void Rbc_ReleaseMarkerTkResources(Graph *graphPtr)¶

Release marker resources while the graph’s Tk window is still live.

Releases derived resources, common coordinates, tags and axis references before Tk option resources. Already released or uninitialized option records are skipped. Marker records and registry entries remain for later destruction. Window-marker cleanup destroys its current child.

Parameters:

  • graphPtr – Borrowed graph with initialized marker registry.

void Rbc_DestroyMarkers(Graph *graphPtr)¶

Destroy all marker records and their registry infrastructure.

Removes bindings and display-list entries, cleans remaining resources through the class-specific path, then destroys marker and tag hash tables and the display list. Release Tk-dependent resources before the window disappears. This whole-registry destructor is not a repeatable resource-release pass.

Parameters:

  • graphPtr – Owning graph being torn down.

Internal class interface¶

The class callbacks are local to rbcGrMarker.c. Their exact signatures and option-table fields are included directly:

typedef Marker *(MarkerCreateProc)(void);
typedef void(MarkerDrawProc)(Marker *markerPtr, Drawable drawable);
typedef void(MarkerFreeProc)(Graph *graphPtr, Marker *markerPtr);
typedef int(MarkerConfigProc)(Marker *markerPtr);
typedef void(MarkerMapProc)(Marker *markerPtr);
typedef void(MarkerExportProc)(Marker *markerPtr, Rbc_ExportContext *exportPtr);
typedef int(MarkerPointProc)(Marker *markerPtr, Point2D *samplePtr);
typedef int(MarkerRegionProc)(Marker *markerPtr, Extents2D *extsPtr, int enclosed);

typedef struct {
    const Tk_OptionSpec *optionSpecs;
    const Tk_OptionSpec *monoOptionSpecs;
    MarkerConfigProc *configProc;
    MarkerDrawProc *drawProc;
    MarkerFreeProc *freeProc;
    MarkerMapProc *mapProc;
    MarkerPointProc *pointProc;
    MarkerRegionProc *regionProc;
    MarkerExportProc *exportProc;
} MarkerClass;

Shared implementation reference¶

Concrete marker geometry and platform batching remain separate documentation work. These groups cover common transactions, lifecycle, mapping helpers and commands. Namespaces disambiguate private names without changing C linkage.

Option preparation and commit¶

group Marker common option transactions

Internal services shared by concrete marker classes.

Functions

static int InitMarkerOptions(Marker *markerPtr)¶

Initialize the concrete Tk option record while preserving the chosen name.

Chooses monochrome specifications when supplied on a one-bit display. Uses a normalized component resource name and class identity. Temporarily detaches the owned preliminary name so partial Tk cleanup cannot free it. Returns TCL_OK with initialized options, or TCL_ERROR after releasing partial Tk resources and restoring the original name for caller cleanup.

static int ConfigureMarkerOptions(Marker *markerPtr, Tcl_Size objc, Tcl_Obj *const objv[], int creating)¶

Apply one marker option transaction and commit a rename last.

Requires initialized options. Installs candidate Tk fields, validates a nonempty name not starting with a dash, and rejects rename collisions when not creating. Passes optionMask to the class configuration callback and clears it afterwards. On error restores saved Tk fields and diagnostic; the class owns rollback of derived state. On success commits registry rename and frees saved options. Creation permits replacement, handled by CreateOp.

static int GetMarkerTagsFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, char ***tagsPtrPtr)¶

Parse an optional tag list into one owned allocation.

Initializes output to NULL. NULL/empty input succeeds without storage. Tcl_SplitList owns both the returned pointer array and its strings in one allocation; the caller frees it with ckfree. Returns TCL_ERROR on list errors.

static int GetMarkerStateFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, int *statePtr)¶

Parse an exact normal, active or disabled marker state.

Borrows the non-NULL object. Writes statePtr only on success; otherwise returns TCL_ERROR with a diagnostic. Does not change drawing or binding state.

static int GetMarkerCoordinatesFromObj(Marker *markerPtr, Tcl_Obj *objPtr, Point2D **worldPtsPtr, Tcl_Size *nWorldPtsPtr)¶

Stage an owned coordinate array with class-specific point counts.

Initializes outputs to NULL/zero and accepts empty coordinates for every class. Nonempty lists must contain pairs and satisfy the class count limits. Checks allocation size and uses Tcl_AttemptAlloc. Each component is parsed through GetCoordinate, which can evaluate Tcl. Returns TCL_OK and transfers the array, or TCL_ERROR after freeing it. Borrows marker and list storage throughout; does not protect against callback mutation of owners/arguments.

static void FreeParsedMarkerOptions(Graph *graphPtr, ParsedMarkerOptions *optionsPtr)¶

Release candidate common resources that have not been transferred.

Frees tag/coordinate allocations and drops candidate axis references, clearing those pointers/counts. Track is borrowed and not released. Accepts a zeroed or partially populated candidate; does not free the candidate record.

static int ParseMarkerOptions(Marker *markerPtr, ParsedMarkerOptions *optionsPtr)¶

Prepare common tags, coordinates, state, axes and track association.

Zeros the caller-owned candidate, then parses all common fields and acquires axis references. A nonempty track must name an existing trackgraph track, and Y-axis ownership must equal the selected track (including NULL). Returns TCL_OK with staged ownership or TCL_ERROR after candidate cleanup. Coordinate expressions can execute Tcl; live records are not preserved here.

static void CommitMarkerOptions(Marker *markerPtr, ParsedMarkerOptions *optionsPtr)¶

Transfer common candidate allocations and axis references to the marker.

Releases old tags, coordinates and axes, moves candidate storage/references and copies borrowed track and state. Clears transferred pointers so candidate cleanup is safe. Does not register a name, map geometry or schedule redraw; the concrete configuration routine owns those remaining steps.

static int GetMarkerColorFromObj(Tcl_Interp *interp, Tk_Window tkwin, Tcl_Obj *objPtr, int allowDefault, XColor **colorPtrPtr)¶

Resolve an optional color or an allowed default-color sentinel.

Initializes output to NULL. Empty input succeeds; when allowDefault is true, a nonempty prefix of defcolor yields COLOR_DEFAULT. Other spellings acquire a Tk color reference. Returns TCL_OK/TCL_ERROR; callers must distinguish the sentinel from an owned color when releasing the result.

static int GetColorPairFromObj(Tcl_Interp *interp, Tk_Window tkwin, Tcl_Obj *objPtr, int allowDefault, ColorPair *pairPtr)¶

Stage foreground and background from a list of at most two colors.

Empty input yields a zeroed pair. Parses colors into temporary ownership; failure releases any first color and leaves the output pair unchanged. Success transfers the pair for eventual Rbc_FreeColorPair cleanup. Does not release an existing output pair, so callers must manage replacement explicitly.

static int GetCoordinate(Tcl_Interp *interp, const char *expr, double *valuePtr)¶

Evaluate a coordinate with special elastic endpoint spellings.

Exact Inf, +Inf and -Inf become positive/negative DBL_MAX. Other strings are passed to Tcl_ExprDouble and may execute Tcl. Returns Tcl status and writes valuePtr on success. No general finite-value check is performed here.

Record lifetime¶

group Marker record and resource lifecycle

Internal services shared by concrete marker classes.

Functions

static void ReleaseMarkerTkResources(Marker *markerPtr)¶

Release one initialized marker before the graph window is lost.

Guards uninitialized/already released records. Calls concrete cleanup before Tk frees option resources, then frees common coordinates/tags, drops axes, frees options/table and sets the release guard. Requires a live graph window. Registry links and record remain for final destruction. Class cleanup can release images or destroy a managed child; this is not just scalar cleanup.

static Marker *CreateMarker(Graph *graphPtr, const char *name, Rbc_Uid classUid)¶

Allocate an unregistered concrete marker and initialize common state.

Dispatches by interned class identity and returns NULL for an unknown class. Concrete allocation is asserted. Copies the name, borrows graph/class, sets MAP_ITEM and initializes option lifecycle flags. Caller must initialize and configure options, then register the marker or destroy the partial record.

static void DestroyMarker(Marker *markerPtr)¶

Remove binding and registry/list state and free a concrete marker.

Requires a live marker. Marks backing store dirty for under markers, removes object bindings, and releases initialized resources while the window exists. Handles pre-initialization failure with explicit cleanup instead. Deletes non-NULL hash/list links and frees the record. Bulk teardown or replacement may clear hashPtr first to retain control of the hash entry. Does not itself schedule a graph redraw or make callback-driven registry mutation safe.

Mapping helpers and picking¶

group Marker coordinate mapping and picking

Internal services shared by concrete marker classes.

Functions

static int BoxesDontOverlap(Graph *graphPtr, Extents2D *extsPtr)¶

Reject disjoint inclusive marker and current plot rectangles.

Requires ordered extents and graph plot bounds, checked with assertions. Touching edges count as overlap. Returns true only for disjoint rectangles; does not clip partial overlaps or map coordinates.

static double HMap(Graph *graphPtr, Axis *axisPtr, double x)¶

Map a horizontal marker coordinate, preserving elastic endpoints.

Borrows current axis range and graph geometry. DBL_MAX sentinels select normalized endpoints; descending axes reverse them. Legacy log mapping uses log10 for positives and zero for negatives, then ordinary normalization. Track-owned axes use full world width, otherwise graph hRange/hOffset. Does not clamp normalized values or update layout.

static double VMap(Graph *graphPtr, Axis *axisPtr, double y)¶

Map a vertical marker coordinate against full track or graph geometry.

Uses the same sentinel, descending and legacy log rules as HMap, with screen-Y reversal. Track ownership selects world bounds even outside a temporary track drawing scope. Visible clipping must not replace this span.

static Point2D MapPoint(Graph *graphPtr, Point2D *pointPtr, Axis2D *axesPtr)¶

Map one borrowed world point through its axes and graph inversion.

Uses marker-specific HMap/VMap, swapping logical axes when inverted. Returns screen coordinates without rounding or remapping graph layout. These helpers intentionally differ from ordinary element mapping.

int Rbc_MarkersUseTrack(Graph *graphPtr, RbcTrack *track, Axis *axis)¶

Test marker associations independently of display visibility.

Scans the registry, including hidden and coordinate-free markers. NULL track means graph-wide markers; NULL axis matches all markers in that scope. Otherwise compares the marker Y-axis pointer. Borrows all records.

Marker *Rbc_NearestMarker(Graph *graphPtr, int x, int y, int under)¶

Pick the first eligible marker in reverse painter order.

Despite its name, this returns the first successful class point test rather than comparing distances. Requires mapped geometry. Filters by layer, nonempty coordinates, hidden flag and STATE_NORMAL; active/disabled states are excluded. Local picks enforce visible track bounds and clipping. Does not apply the associated-element hidden check used by drawing/FindOp. Returns borrowed marker or NULL, without layout refresh or lifetime preservation.

void Rbc_MarkerFontsChanged(Graph *graphPtr)¶

Refresh all text-marker layouts after a font change.

Scans the registry including hidden text markers. Resets text style, replaces layout and rotated bounding geometry when text exists, then marks mapping dirty. Borrows graph/marker records; non-text markers are unaffected.

Registry and commands¶

group Marker registry and command dispatch

Internal services shared by concrete marker classes.

Functions

static int NameToMarker(Graph *graphPtr, const char *name, Marker **markerPtrPtr)¶

Resolve an exact marker name to a borrowed registry record.

Returns TCL_OK and writes markerPtrPtr on success. Otherwise returns TCL_ERROR with graph/name diagnostic, leaving output unchanged. Does not search display order, accept patterns or acquire a lifetime reference.

static int NamesOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return display-list names matching any supplied glob pattern.

No patterns returns all listed names. Traverses from first to last and emits each marker at most once; hidden markers remain eligible. Registry entries detached from the display list are not returned. Returns TCL_OK.

static ClientData MakeMarkerTag(Graph *graphPtr, char *tagName)¶

Intern a binding tag in the graph marker-tag table.

Creates the string-key entry when needed and returns its borrowed key pointer, valid until table destruction. Does not require a named marker to exist or install a binding script.

void Rbc_AppendMarkerBindingTags(Graph *graphPtr, Marker *markerPtr, Rbc_List list)¶

Append name, class and configured tags in binding order.

Borrows graph, marker and destination list. Interns tag identities in the marker-tag table; the list does not own their strings. Does not evaluate Tcl binding scripts or alter marker state.

static int BindOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

List interned marker tags or delegate a binding query/update.

No tag returns registry tag names in hash order, not only tags with scripts. Otherwise interns the tag at objv[3] and passes the remaining arguments to the graph binding table service. Returns its Tcl status.

static int CgetOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return a marker option through its concrete Tk option table.

Resolves objv[3] as an exact name and objv[4] as an option. Returns TCL_OK with its value or TCL_ERROR from lookup/Tk. Does not configure or redraw.

static int ConfigureOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query one marker or configure multiple named markers in sequence.

Scans names until the first dash-prefixed argument and validates them before applying options. Zero/one option arguments query the first named marker. Updates re-resolve each name and call ConfigureMarkerOptions independently. A later failure does not roll back earlier markers. Returns a Tcl status; it is not a multi-marker atomic transaction.

static int CreateOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Configure a new marker before replacing any same-named registry entry.

Resolves the class and scans complete option pairs for the last -name prefix; otherwise generates markerN. Creates and initializes the concrete record, applies options and validates the final name before publishing. A duplicate name destroys the old marker while retaining its hash entry. Appends the new record to display order, invalidates under-layer backing when needed and schedules redraw. Returns the configured name or TCL_ERROR with cleanup.

static int DeleteOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Destroy each existing exact name and ignore missing names.

Performs deletions sequentially, clears lookup diagnostics and schedules graph redraw even for no matching names. Returns TCL_OK. Concrete cleanup owns associated resources, which can include a managed child window.

static int GetOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return the current marker only when the binding context is a marker.

Recognizes only the exact selector current. Checks the common binding context before casting the current item, and verifies a supported marker class. Other selectors or absent/nonmarker items leave an empty result. Returns TCL_OK; does not pick coordinates or resolve ordinary names.

static int RelinkOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Move a marker link before or after an optional display-list reference.

Borrows graph and resolves both exact names before changing display order. Invalid names return TCL_ERROR without unlinking either marker. A reference to the target itself is a successful no-op. Otherwise moves the existing link, invalidates backing storage when the moved marker is an underlay and schedules redraw. No marker ownership or registry entries change.

static int FindOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return the first visible marker passing a class rectangle test.

Parses enclosed/overlapping and four integer screen coordinates, normalizes corner order and scans first-to-last display order. Filters hidden markers and existing hidden associated elements. Local searches require a visible track intersection; overlapping queries clip the search box to that track, enclosed queries retain the original box. Returns the first name or an empty result. No automatic layout refresh, layer filter or marker-state filter.

static int ExistsOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Report exact registry membership regardless of visibility or list order.

Returns TCL_OK with integer zero/one. Does not require coordinates or current geometry, and does not report an error for a missing name.

static int TypeOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return the interned class identity for an existing marker.

Resolves an exact name and copies classUid into the interpreter result. Returns TCL_ERROR on missing name; does not configure or map the marker.

int Rbc_MarkerOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Validate operation and arity before shared marker command dispatch.

Uses the complete widget-command argument vector with the operation at index two. Returns shared-dispatch or handler Tcl status. Does not itself refresh layout or preserve marker records across application callbacks.
