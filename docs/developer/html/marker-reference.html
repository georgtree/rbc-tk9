Marker C reference

These private entry points borrow the graph. Mapping and drawing assume the caller has prepared the appropriate layout and retained graph lifetime. See Marker lifecycle and drawing for class dispatch, special window behavior and cleanup.

Mapping and output

void Rbc_MapMarkers(Graph *graphPtr)

Map pending marker geometry in display-list order.

Skips hidden markers and markers without coordinates. MAP_ALL or MAP_ITEM selects mapping; each class mapper runs in a paired owning-track viewport scope and MAP_ITEM is cleared afterward. Does not draw or update axes.

Parameters:

  • graphPtr – Borrowed graph with prepared axes and plot geometry.

void Rbc_DrawMarkers(Graph *graphPtr, Drawable drawable, int under)

Draw one marker layer and synchronize embedded child visibility.

Synchronizes windows from both layers even when drawing only one layer. Track drawing preserves painter order with per-track clipping; ordinary graphs may batch compatible adjacent primitives. Window markers manage real children rather than paint them into the supplied drawable.

Parameters:

  • graphPtr – Borrowed live graph with current mapped marker geometry.

  • drawable – Borrowed compatible screen drawable.

  • under – Layer selector: 1 below elements, 0 above elements.

void Rbc_MarkersExport(Graph *graphPtr, Rbc_ExportContext *exportPtr, int under)

Export eligible markers from one layer in display-list order.

Skips missing exporters, absent coordinates, hidden markers and markers associated with an existing hidden element. Non-window track markers use a track viewport and renderer clip; window export follows its own capture path. Does not perform layout or own the export context.

Parameters:

  • graphPtr – Borrowed graph with export layout already mapped.

  • exportPtr – Borrowed initialized export context.

  • under – Layer selector: 1 below elements, 0 above elements.

Resource and record cleanup

void Rbc_ReleaseMarkerTkResources(Graph *graphPtr)

Release marker resources while the graph’s Tk window is still live.

Releases derived resources, common coordinates, tags and axis references before Tk option resources. Already released or uninitialized option records are skipped. Marker records and registry entries remain for later destruction. Window-marker cleanup destroys its current child.

Parameters:

  • graphPtr – Borrowed graph with initialized marker registry.

void Rbc_DestroyMarkers(Graph *graphPtr)

Destroy all marker records and their registry infrastructure.

Removes bindings and display-list entries, cleans remaining resources through the class-specific path, then destroys marker and tag hash tables and the display list. Release Tk-dependent resources before the window disappears. This whole-registry destructor is not a repeatable resource-release pass.

Parameters:

  • graphPtr – Owning graph being torn down.
