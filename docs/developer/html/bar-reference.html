Bar layout C reference¶

These static helpers belong to rbcGrBar.c. They are not cross-module APIs. See Bar grouping and placement for grouping passes, placement formulas and array ownership.

group Bar layout internals

Private data-space placement and mapped geometry services.

Source arrays and graph records are borrowed; these helpers do not invoke Tcl callbacks.

Functions

static int PlaceBar(Graph *graphPtr, Bar *barPtr, Tcl_Size index, int clip, Point2D *firstPtr, Point2D *secondPtr)¶

Compute one bar’s data-space corners and consume its group position.

Apply each element’s width, alignment and offset before subdivision. Duplicate keys use the original X value and both axis identities. Successful grouped placement advances count or lastY; this is not a pure query. Reset grouping state before a new ordered pass. Log-invalid and nonfinite input, invalid full X intervals, viewport rejection and stack overflow are skipped. Corners are not screen mapped or reordered for negative-height bars.

Parameters:

  • graphPtr – Borrowed graph with initialized grouping state.

  • barPtr – Borrowed bar element and axis pair.

  • index – Valid index in both source arrays.

  • clip – Reject full X intervals outside linear-axis viewport limits.

  • firstPtr – Receives the lower X edge and placed data-value Y.

  • secondPtr – Receives the upper X edge and baseline or previous stack Y.

Returns:

TRUE for a placement; FALSE leaves the output corners unchanged.

static void GetBarExtents(Element *elemPtr, Extents2D *extsPtr)¶

Compute bar data limits and translated error limits.

Includes full anchored X intervals, baseline rules and duplicate stack totals. Calls PlaceBar without viewport rejection to advance group state even when error bars retain data positioning. In bar positioning mode, owns a temporary per-source translation array and frees it after expanding error limits. The caller must reset group state before the ordered pass.

Parameters:

  • elemPtr – Borrowed bar element.

  • extsPtr – Receives bounds, or sentinel empty bounds without paired data.

static void ClosestBar(Graph *graphPtr, Element *elemPtr, ClosestSearch *searchPtr)¶

Search mapped bar rectangles while retaining source identity.

Interior hits have zero distance; other candidates use rectangle edges. rectToData translates mapped order back to source order. Reported X and Y are original data values, not shifted centers or cumulative stack values. No arrays are allocated and no graph state is changed.

Parameters:

  • graphPtr – Borrowed graph (unused by this search).

  • elemPtr – Borrowed bar element with current mapped rectangles.

  • searchPtr – In/out search; replaced only for a strictly closer hit.

static void MapBar(Graph *graphPtr, Element *elemPtr)¶

Replace bar display geometry from source data and group state.

Allocates owned rectangles and original-source indices, places bars in order, maps corners and bounds coordinates before integer conversion. Owns temporary error translations and style lookup storage; frees both after mapping errors and grouping geometry by pen. Active rectangles are rebuilt when explicit active indices exist. This consumes group state and must run in the ordered mapping pass, after its reset. Renderer clipping is separate from the window bounds used here to keep integer conversion safe.

Parameters:

  • graphPtr – Borrowed graph in the element’s mapping viewport.

  • elemPtr – Borrowed bar element whose old geometry is discarded.
