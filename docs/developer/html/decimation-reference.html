Line decimation C reference¶

These static helpers belong to rbcGrLine.c. They are not cross-module APIs. See Line decimation and source identity for fallback order and source-index ownership.

group Line decimation internals

Private screen-density reduction services.

All objects are borrowed from the owning graph; these routines neither mutate source vectors nor invoke Tcl.

Functions

static int CanPixelDecimateLine(Line *linePtr)¶

Test semantic eligibility, independently of source density.

Parameters:

  • linePtr – Borrowed live line/strip element.

Returns:

TRUE for automatic, ordinary XY, unsmoothed, single-pen traces without area fill, outside export. Does not guarantee that reduction will be attempted.

static int LineNeedsPixelDecimation(Graph *graphPtr, Line *linePtr)¶

Test source density against the physical data-X plot span.

Parameters:

  • graphPtr – Borrowed graph with current mapping/extents, including track scope.

  • linePtr – Borrowed element supplying the complete paired source count.

Returns:

TRUE at the renderer’s density threshold, FALSE for empty data or invalid/subpixel spans. Uses vertical extent when axes are inverted.

static int RefreshLineDecimateCache(Line *linePtr)¶

Maintain a persistent source-domain cache after element invalidation.

Exact Y changes rebuild affected summaries; X changes invalidate ordering. Growth delegates to checked prefix retention. Does not clear source change flags.

Parameters:

  • linePtr – Borrowed element with current source pointers and change metadata.

Returns:

TRUE when no cache exists or the existing cache can be retained or updated; FALSE asks the caller to invalidate it. Not a geometry-generation result.

static int BuildCachedPixelDecimatedScreenPoints(Graph *graphPtr, Line *linePtr, MapInfo *mapPtr)¶

Build reduced mapped geometry from source-domain summaries.

Supports a finite continuous monotonic-X run. Binary searches locate pixel buckets; block extrema supply first/min/max/last representatives in source order. Successful output belongs to the mapping caller. breakBefore is NULL.

Parameters:

  • graphPtr – Borrowed graph with current axes and plot scope.

  • linePtr – Borrowed eligible trace-only element; may build its persistent cache.

  • mapPtr – Caller-owned mapping record receiving allocated points and source indices.

Returns:

TRUE if handled, FALSE asks the caller to use the source-scanning fallback.

static void DecimatePointsByPixels(Graph *graphPtr, MapInfo *mapPtr)¶

Reduce eligible mapped geometry without changing source values.

Retains first/min/max/last representatives per pixel bucket and continuous run. Leaves geometry unchanged for short/nonmonotonic inputs, allocation failure or no useful reduction. Preserves source indices and run boundaries.

Parameters:

  • graphPtr – Borrowed graph defining the physical data-X direction.

  • mapPtr – Owned mapped arrays; replacements, when made, remain owned by caller.
