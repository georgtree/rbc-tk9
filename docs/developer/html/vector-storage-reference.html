Vector storage public C reference

These functions are public entries in generic/rbc.decls. Their contracts come from the reviewed implementations in rbcVector.c. See Vector C API and storage primitives for ownership, units, creation reuse and remaining callback restrictions; see Vector client C reference for observers and extrema.

group Vector storage public C API

Reviewed stubs-facing lifetime, storage and protection contracts.

Functions

int Rbc_VectorExists2(Tcl_Interp *interp, const char *vecName)

Test whether a literal registered vector name exists.

Searches the current/global namespace rules without parsing a vector range. Returns a boolean; accepts an interpreter and name, not an observer token. May lazily initialize interpreter vector data. Does not retain a found vector.

Parameters:

  • interp – [in] See Interpreter arguments; uses its vector registry.

  • vecName – [in] Borrowed literal name, resolved in the current/global namespaces.

Returns:

Nonzero if found, zero otherwise; no ownership is acquired.

int Rbc_GetVector(Tcl_Interp *interp, const char *name, Rbc_Vector **vecPtrPtr)

Resolve a vector reference into a borrowed C vector pointer.

Returns TCL_OK and writes vecPtrPtr on success; reports lookup failure with TCL_ERROR. Allows range syntax, updates the shared first/last selection and refreshes invalid cached extrema. Index expressions may execute Tcl. The result is the original vector identity, not a slice or ownership reference; callers must manage lifetime before using it across subsequent evaluation.

Parameters:

  • interp – [in] See Interpreter arguments; index expressions may execute Tcl.

  • name – [in] Borrowed vector reference, optionally including a range.

  • vecPtrPtr – [out] Required pointer receiving the borrowed identity on success; unchanged on error.

Returns:

TCL_OK on lookup success; TCL_ERROR with a diagnostic otherwise.

int Rbc_CreateVector(Tcl_Interp *interp, const char *name, Tcl_Size size, Rbc_Vector **vecPtrPtr)

Create or reuse a real vector through the typed creation interface.

Delegates to Rbc_CreateVectorWithType with RBC_VECTOR_REAL. Returns a Tcl status and optionally a borrowed vector pointer. Existing same-type writable vectors may be reused; this is not a create-only operation.

Parameters:

  • interp – [in] See Interpreter arguments.

  • name – [in] Borrowed requested name; #auto requests a generated name.

  • size – [in] Nonnegative initial length in values; zero retains an existing length.

  • vecPtrPtr – [out] Optional borrowed identity output; unchanged on error.

Returns:

Tcl creation status; callback side effects are not rolled back.

int Rbc_CreateVectorWithType(Tcl_Interp *interp, const char *name, Tcl_Size size, Rbc_VectorType type, Rbc_Vector **vecPtrPtr)
