Vector client C reference¶

The opaque types and observer declarations below come from the installed rbcVector.h. Observer functions are not entries in the public stubs table; external stub users must not assume they are available through that table. The final section contains private RBC helpers. See Vector ownership and notifications for storage, read-only state and notification reentry and client-data lifetime.

typedef struct Rbc_VectorIdStruct *Rbc_VectorId¶

Observer token attached to one vector, not a vector reference count.

Survives vector rename. Free it when detaching, including from a callback. Vector destruction frees remaining tokens after delivering DESTROY; clients must discard their saved token at that point.

Observers and range access¶

Rbc_VectorId Rbc_AllocVectorId(Tcl_Interp *interp, const char *vecName)¶

Register an observer of an existing vector without copying its values.

See also

Rbc_SetVectorChangedProc

See also

Rbc_FreeVectorId

Parameters:

  • interp – [in] Interpreter containing the vector registry.

  • vecName – [in] Borrowed name resolved by the vector name lookup rules.

Returns:

New token, initially without a callback, or NULL with a diagnostic.

void Rbc_FreeVectorId(Rbc_VectorId clientId)¶

Detach an observer, deferring reclamation while delivery retains it.

Does not destroy the vector. May be called from UPDATE or DESTROY callbacks. Destruction itself frees remaining IDs. A magic-field check is not permission to pass freed or arbitrary pointers. NULL is accepted.

Parameters:

  • clientId – [in] Allocated token, or NULL; invalid after this call.

int Rbc_GetVectorById(Tcl_Interp *interp, Rbc_VectorId clientId, Rbc_Vector **vecPtrPtr)¶

Borrow the vector associated with a client ID and refresh its range.

Neither the returned pointer nor the ID extends vector lifetime. Never call this with a token left over after vector destruction. Cached extrema are recomputed when invalidated; this is not always a constant-time lookup.

Parameters:

  • interp – [in] Interpreter used for error reporting.

  • clientId – [in] Non-NULL live token.

  • vecPtrPtr – [out] Receives the borrowed vector on success only.

Returns:

TCL_OK, or TCL_ERROR with a diagnostic for a bad/disconnected token.

void Rbc_SetVectorChangedProc(Rbc_VectorId clientId, Rbc_VectorChangedProc *proc, ClientData clientData)¶

Replace an observer’s callback and borrowed callback data.

Does not invoke the callback immediately or transfer ownership of clientData.

Parameters:

  • clientId – [in] Non-NULL live token.

  • proc – [in] Callback, or NULL to disable calls without detaching the ID.

  • clientData – [in] Borrowed data passed to proc; never freed by RBC.

char *Rbc_NameOfVectorId(Rbc_VectorId clientId)¶

Return the vector’s current registered name, not its array mapping.

Do not modify or free the returned string. Copy it if it must survive rename. A token already freed by destruction cannot be queried.

Parameters:

  • clientId – [in] Non-NULL live token.

Returns:

Borrowed name until rename/destruction, or NULL if disconnected.

int Rbc_VectorNotifyPending(Rbc_VectorId clientId)¶

Test whether an idle update notification is queued.

The nonzero result is a flag mask, not necessarily 1. It is not a test for all possible data changes, and cannot validate a freed token.

Parameters:

  • clientId – [in] Live token, or NULL.

Returns:

Nonzero for a pending notification; zero for NULL/disconnected IDs.

int Rbc_VectorGetRange(Rbc_Vector *vecPtr, double *minPtr, double *maxPtr)¶

Get cached finite extrema of a real vector, recomputing if necessary.

Empty vectors and vectors without finite values return NaN extrema.

Parameters:

  • vecPtr – [inout] Live borrowed vector; its extrema cache may be updated.

  • minPtr – [out] Receives minimum on success; must not be NULL.

  • maxPtr – [out] Receives maximum on success; must not be NULL.

Returns:

TCL_OK for a real vector; TCL_ERROR for complex storage, without an interpreter diagnostic or changes to the output parameters.

Private update helpers¶

void Rbc_VectorUpdateClients(VectorObject *vPtr)¶

Invalidate extrema and report a full/unknown data change internally.

Increments the dirty counter and follows the vector’s notification policy. Immediate policy invokes callbacks before return. Does not flush the mapped Tcl array cache or check read-only state; mutation code owns those steps.

Parameters:

  • vPtr – [inout] Live vector, already modified by the caller.

void Rbc_VectorUpdateClientsRange(VectorObject *vPtr, Tcl_Size first, Tcl_Size last)¶

Report changed existing storage using inclusive zero-based indices.

Invalid intervals become full updates. Valid intervals coalesce until delivery; real extrema are maintained incrementally when possible. Does not change length/ownership, flush array caches or enforce read-only state.

Parameters:

  • vPtr – [inout] Live vector, already modified in place.

  • first – [in] First changed storage index, independent of Tcl index offset.

  • last – [in] Last changed storage index, inclusive.

int Rbc_VectorGetChangedRange(Rbc_VectorId clientId, Tcl_Size *firstPtr, Tcl_Size *lastPtr)¶

Read the interval snapshot during this client’s UPDATE callback.

Coalescing may include unchanged values between separate modified intervals. This helper is private and has no public stub entry.

Parameters:

  • clientId – [in] Live observer token, or NULL.

  • firstPtr – [out] Optional first inclusive zero-based index.

  • lastPtr – [out] Optional last inclusive zero-based index.

Returns:

TRUE if a range is available; FALSE for a full/unknown update, DESTROY, outside delivery, or a NULL/disconnected token. Outputs are left unchanged on FALSE. Never pass a token freed by vector destruction.
