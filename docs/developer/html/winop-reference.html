Window/photo command C reference¶

See Window and photo command implementation for ownership, failure and platform boundaries. These are private implementation interfaces.

group Window and photo command internals

Private command/canvas callbacks, not installed C APIs.

Functions

static int GetRealizedWindow(Tcl_Interp *interp, const char *string, Tk_Window *tkwinPtr)¶

Resolve a Tk path and ensure its native window exists.

Borrow the interpreter and return a borrowed Tk_Window through tkwinPtr on success. Realization does not map the window. Return TCL_ERROR from path lookup without assigning the output.

static Window StringToWindow(Tcl_Interp *interp, const char *string)¶

Resolve a Tk path or legacy integer native-window identifier.

Tk toplevel paths select their wrapper through Rbc_GetRealWindowId(). Numeric input uses Tcl_GetInt, not a pointer-width parser; Windows wraps that value with Rbc_WinWindowFromHWND(). Return None on lookup or conversion failure. The result does not transfer ownership of the window.

static int ConvolveOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Convolve an existing photo into an existing destination photo.

Require a nonempty square list of finite kernel values with a finite sum. Own and free the kernel and copied color buffers locally; photo handles are borrowed. The source is copied before destination publication. Parse failures return TCL_ERROR. Photo publication uses the void color-image helper and is not an atomic transaction with rollback.

static int QuantizeOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Quantize a copied photo with a palette of one to 256 colors.

Borrow both photo handles and free both color buffers after the quantizer returns. Resize the destination to the source dimensions before parsing the optional color count; an error therefore need not leave it unchanged. Source dimensions of one pixel or less are rejected.

static int ResampleOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Resize a photo according to the destination photo dimensions.

Borrow existing photos and filter descriptors. A destination dimension of one pixel or less causes a source-size copy; equal dimensions also copy. The default filter is none. A vertical filter is parsed only when the first filter resolves to a non-NULL descriptor. Lower photo-write return values are not uniformly propagated by this legacy command.

static int RotateOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Rotate a copied photo by a finite Tcl expression angle in degrees.

Validate names, preserve the interpreter across angle evaluation, then reacquire both photo handles before accessing pixels. Reject deleted photos or destroyed Tk state; same-name replacements are used. Allocate and release source/rotated buffers locally. Photo publication is not a rollback transaction.

static int SnapOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Capture a native window into a named photo, optionally resizing it.

For a Tk path, capture the client drawable and its Tk dimensions rather than the window-manager wrapper. Numeric input uses StringToWindow() and native geometry. Borrow all windows and delegate capture and destination lookup to Rbc_SnapPhoto(); return its Tcl status. This is screen capture, not graph remapping or vector-document export.

static int SubsampleOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Resize a validated source-photo rectangle into a destination photo.

Require nonnegative origin, positive extent and a rectangle inside the source. An effectively empty destination takes the region dimensions. Default to the box filter; none selects the unfiltered resize path. Photos and filters are borrowed, and the command neither creates nor deletes the destination photo.

static int ImageOp(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch nested winop image operations using direct-operation indices.

Validate against imageOps, then pass objc - 1 and objv + 1 so shared handlers see source and destination at their original argument positions. Tables for direct and nested operations are intentionally not identical.

static int WinopCmd(ClientData clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a stateless winop request with the current Tk main window.

Validate operation and arity through winOps before calling its handler. No per-command heap object or command deletion callback is maintained.
