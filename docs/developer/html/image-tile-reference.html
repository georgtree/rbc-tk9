Image and tile C reference¶

These interfaces are private. See Image storage and tile clients for resource lifetimes.

int Rbc_GetTile(Tcl_Interp *interp, Tk_Window tkwin, const char *imageName, Rbc_Tile *tilePtr)¶

Acquire a new client token for a named Tk image.

Requires a live window. The interpreter-local server is shared by display, depth and image name, but each successful call returns its own client. On TCL_OK, the caller owns the token and must call Rbc_FreeTile before its window/client data disappear. On TCL_ERROR, the output is not assigned.

void Rbc_FreeTile(Rbc_Tile tile)¶

Release one client token and destroy the server if it was the last.

NULL is harmless. A released token is invalid; the magic check does not make stale pointers or repeated frees safe. Server teardown cancels pending idle notification. Active notification snapshots defer record reclamation.

void Rbc_SetTileChangedProc(Rbc_Tile tile, Rbc_TileChangedProc *changeProc, ClientData clientData)¶

Install or replace one client’s borrowed notification callback and data.

A NULL callback disables notification. No immediate callback is made. Notifications run after an idle pixmap update over preserved client records. Callbacks may release clients or process nested updates. Removed clients are skipped; newly added clients wait for a later update. Interpreter deletion stops the current pass. Callback data remains owned by the caller.

Pixmap Rbc_PixmapOfTile(Rbc_Tile tile)¶

Return a borrowed cached pixmap, or None for no tile.

Do not free it or retain it across a tile update/release. Image changes are processed at idle, so this is a cache query, not a forced refresh.

Tk_Image Rbc_ImageOfTile(Rbc_Tile tile)¶

Borrow the tile’s Tk image without acquiring another image reference.

Returns NULL for no tile or a deleted image. Do not call Tk_FreeImage on the result; use it only while the tile and current image state remain valid.

int Rbc_GetTilePhoto(Rbc_Tile tile, Tk_PhotoImageBlock *blockPtr)¶

Borrow photo pixel storage into a caller-owned block record.

Clears the record first. Returns false for no tile or a non-photo image; a deleted image returns true with an empty block. The pixel pointer remains Tk-owned and is invalidated by image changes or deletion. No copy is made.

Rbc_ColorImage Rbc_CreateColorImage(int width, int height)¶

Allocate an owned row-major RGBA pixel buffer and image record.

Dimensions must be nonnegative; invalid or overflowing sizes panic. Pixels start zeroed, including alpha. Release with Rbc_FreeColorImage. The returned image has no Tk image identity, reference count or change notification.

void Rbc_FreeColorImage(Rbc_ColorImage image)¶

Release both the pixel array and its owning image record.

Requires a valid non-NULL owned image. All borrowed pixel pointers become invalid. This does not delete or modify any Tk photo used to create it.

Rbc_ColorImage Rbc_PhotoToColorImage(Tk_PhotoHandle photo)¶

Copy a valid Tk photo into a newly owned RBC color image.

Copies pixels using the photo block’s pitch and channel offsets. The result is independent of later photo changes; release it with Rbc_FreeColorImage.

Rbc_ColorImage Rbc_PhotoRegionToColorImage(Tk_PhotoHandle photo, int x, int y, int width, int height)¶

Copy the clipped intersection of a photo region into an owned image.

Requires a valid photo handle. An empty intersection returns an empty image, not NULL. The result owns its pixels and must be freed with Rbc_FreeColorImage.

void Rbc_ColorImageToPhoto(Tcl_Interp *interp, Rbc_ColorImage image, Tk_PhotoHandle photo)¶

Replace a borrowed Tk photo’s size and pixels from an RBC image.

Source ownership stays with the caller; Tk copies the block synchronously. Uses TK_PHOTO_COMPOSITE_SET, including alpha. This legacy void helper ignores return codes from Tk_PhotoSetSize and Tk_PhotoPutBlock; it does not provide a reliable success/failure status to its caller.

Tile queries and origins¶

char *Rbc_NameOfTile(Rbc_Tile tile)¶

Return the borrowed image name; NULL yields an empty string.

An invalid magic value yields “not a tile”. Neither result validates a stale pointer. The server owns a live name; callers must not modify or free it.

void Rbc_SizeOfTile(Rbc_Tile tile, int *widthPtr, int *heightPtr)¶

Read cached tile dimensions without forcing an idle refresh.

Both output pointers are required. NULL or invalid tokens yield zero sizes; deleted images may retain their last cached dimensions.

void Rbc_SetTileOrigin(Tk_Window tkwin, Rbc_Tile tile, int x, int y)¶

Align a client pattern origin through its window ancestry.

Requires a live client and window. Adds position and border offsets up to the toplevel, negates the result and updates both client origin and shared server GC. Does not retain windows or change other clients stored origins.

void Rbc_SetTSOrigin(Tk_Window tkwin, Rbc_Tile tile, int x, int y)¶

Set a client origin directly in drawable coordinates.

Requires a live client and compatible window. Updates its stored origin and the shared server GC; callers must establish origins for each draw.

Tile lifecycle implementation¶

static void RedrawTile(Tk_Window tkwin, Tile *tilePtr)¶

Refresh a live tile server using a client window.

Requires a live Tk image and compatible window. Allocates a replacement pixmap before freeing the old one when size changes, redraws the image, replaces the tiled GC, records dimensions and rebuilds the photo alpha mask. Releases masks with their platform-specific allocator. The image display procedure is an external callback boundary; this helper provides no lifetime barrier around it and has no error return.

static void FreeTileRecord(DestroyData memory)¶

Reclaim a detached tile or client record after preservation ends.

Receives storage transferred through Tcl_EventuallyFree. Frees only the record: links, image and native resources must already have been released.

static void UpdateTile(ClientData clientData)¶

Refresh the cache and notify a preserved snapshot of clients.

Preserves server and interpreter, clears the pending bit, and redraws using the first client window. A deleted image instead releases only the cached pixmap. Snapshots and preserves client membership after refresh, but reads callback pointers at delivery time. Removed clients are skipped, new clients wait for another pass, and callback replacement takes effect immediately. Stops delivery if the server is destroying or interpreter is deleted. Releases every snapshot reference even after early termination. Does not save or restore interpreter result state, and refresh precedes the client snapshot.

static void ImageChangedProc(ClientData clientData, int x, int y, int width, int height, int imageWidth, int imageHeight)¶

Coalesce Tk image changes into a deferred cache update.

Ignores the changed rectangle and image dimensions. Schedules UpdateTile only when TILE_NOTIFY_PENDING is clear. Does not redraw synchronously or invoke client callbacks; server teardown must cancel the queued idle call.

static void DestroyTile(Tile *tilePtr)¶

Detach a server and release all owned resources.

Marks destruction and cancels pending idle work. Invalidates remaining client tokens, clears their links and callbacks, and defers record frees. Destroys the client chain, removes a still-linked hash entry, releases pixmap, mask, Tk image, GC and copied name, then defers the server record free. Active notification preserves storage only, not these resources. Requires a live server and is not an idempotent operation.

static Tile *CreateTile(Tcl_Interp *interp, Tk_Window tkwin, const char *imageName)¶

Acquire a Tk image and construct an unregistered tile server.

Allocates a zeroed record and acquires the image with ImageChangedProc. Acquisition failure frees the record and returns NULL with the Tk error. Success owns the copied name, image and client chain, and immediately builds native cache resources before returning. Hash registration and first-client attachment belong to CreateClient. Tk image acquisition and drawing can call image-provider code before that attachment exists.

static void DestroyClient(TileClient *clientPtr)¶

Detach one live client and destroy an unused server.

Removes its chain link first. If no clients remain, destroys the server; then clears client validity, server/link pointers and callback and defers record reclamation. Requires a valid attached client. The removed record is no longer in the server chain when last-client teardown occurs.

static TileClient *CreateClient(Tcl_Interp *interp, Tk_Window tkwin, const char *name)¶

Acquire an interpreter-local server and append a new client token.

Zeroes the complete display/depth/interned-name key, including padding. Creates a hash entry and server if absent, removing the entry on acquisition failure. Every success allocates a distinct zeroed client with a borrowed window and no callback, appends it to the server chain and returns ownership to the caller. Existing server resources are shared, not copied.

static void TileInterpDeleteProc(ClientData clientData, Tcl_Interp *interp)¶

Destroy all tile servers when interpreter associated data is removed.

The clientData argument is interpreter-owned TileInterpData, not thread local storage. Clears each server hash pointer before destroying it so hash iteration remains valid, then deletes the table and associated-data entry and frees the registry. Invalidates outstanding client tokens.

static TileInterpData *GetTileInterpData(Tcl_Interp *interp)¶

Find or create the interpreter-owned tile registry.

Lazily allocates associated data and installs TileInterpDeleteProc. Uses a fixed-size multiword key for TileKey. Returns borrowed registry storage valid until associated-data teardown; no global or cross-interpreter sharing.

struct TileInterpData¶

Interpreter-owned registry of shared tile servers.

Owns tileTable and its servers; interp is borrowed. The associated-data deletion callback destroys all registered servers before freeing this record.

struct Tile¶

Shared image cache and notification state for one tile key.

Owns name, Tk image, pixmap, mask, GC and client chain. Registry links are borrowed. Destruction releases resources immediately; Tcl preservation can defer only final record reclamation.

struct Rbc_TileClientStruct¶

Individual tile token with borrowed window and callback data.

The server chain owns membership. Origin is client-local, while native resources are shared. A detached preserved token has its magic, server, link and callback cleared before eventual reclamation.

struct TileKey¶

Composite key for interpreter-local tile sharing.

Borrows the display and interned image-name UID and records screen depth. The whole structure is zeroed before hashing because padding participates in the fixed-size multiword key.
