Component configuration C reference

These are private helpers implemented in rbcConfig.c and declared in rbcInt.h. They introduce no public stubs. See Component configuration and resources for transaction ordering, resource identity and cleanup responsibilities.

Resource initialization

char *Rbc_GetComponentResourceName(const char *name)

Copy a component name using the legacy resource-name convention.

Only the first byte is lowercased using tolower. The rest is unchanged; this is not Unicode case folding. An empty name produces an empty copy.

Parameters:

  • name – Non-NULL component name; component identity is not modified.

Returns:

Allocated copy owned by the caller; release with ckfree.

int Rbc_InitComponentOptions(Tcl_Interp *interp, Tk_Window parent, Tk_Window proxy, const char *name, const char *className, char *recordPtr, Tk_OptionTable optionTable)

Initialize a component record with its option-database identity.

A matching real child is used first, retaining its class. Otherwise reuse the proxy with the supplied name and class, or use parent when proxy is NULL. No window is created or destroyed here. The temporary proxy diagnostic path is cleared before returning. Record resources and proxy lifetime remain with the caller; this helper does not configure explicit command arguments.

Parameters:

  • interp – Interpreter receiving initialization errors.

  • parent – Owning widget window.

  • proxy – Graph-owned anonymous option window, or NULL for parent fallback.

  • name – Resource name, already normalized by the caller if required.

  • className – Component resource class used for the proxy.

  • recordPtr – Component record accepted by Tk_InitOptions.

  • optionTable – Tk option table describing the record.

Returns:

Result of Tk_InitOptions (TCL_OK or TCL_ERROR).

Rollback

int Rbc_RestoreOptionsOnError(Tcl_Interp *interp, Tk_SavedOptions *savedOptionsPtr)

Roll back options after validation of a successful Tk_SetOptions fails.

Clear borrowed argument vectors and transaction context before calling. Derived resources remain the caller’s responsibility: do not commit them before all fallible validation succeeds. Do not call after Tk_SetOptions itself fails, or call Tk_FreeSavedOptions after this helper.

Parameters:

  • interp – Interpreter holding the original validation error.

  • savedOptionsPtr – Successful option transaction to consume and restore.

Returns:

TCL_ERROR with the original result and return options preserved.

Option lookup and metadata

int Rbc_GetComponentOptionIndex(Tcl_Interp *interp, Tcl_Obj *objPtr, const Tk_OptionSpec *specs, const char *message, int *indexPtr)

Look up a custom component option using Tcl’s indexed-name matching.

Arguments are interpreter, option-name object, specification array, diagnostic label and output index. The array must contain concrete options (no synonyms), terminate with TK_OPTION_END, and outlive Tcl objects caching its entries. Unique abbreviations are accepted.

Parameters:

  • interp – [inout] Borrowed interpreter for conversion diagnostics; see Interpreter arguments.

  • objPtr – [in] Borrowed non-NULL Tcl input object, kept valid by the caller; not retained here.

  • specs – [in] Persistent Tk_OptionSpec array terminated by TK_OPTION_END, containing concrete options; must outlive objects caching indexed-name lookup.

  • message – [in] Borrowed NUL-terminated label for unknown/ambiguous-option diagnostics.

  • indexPtr – [out] Required specification index output, meaningful only on TCL_OK.

Returns:

TCL_OK with the selected index, or TCL_ERROR with a diagnostic.

Tcl_Obj *Rbc_GetComponentOptionInfo(const Tk_OptionSpec *spec, Tcl_Obj *valueObj)

Build configure metadata from one specification and its live value.

Arguments are a concrete specification with non-NULL optionName, dbName, dbClass and defValue strings, and a valid Tcl value object.

No option table or synthetic component record is allocated for this query.

Returns:

New zero-reference-count list containing option name, resource name, resource class, default and supplied value. The list retains the value; the caller retains any references it already owns.

Parameters:

  • spec – [in] Borrowed concrete specification with non-NULL optionName, dbName, dbClass and defValue strings; their text is copied.

  • valueObj – [in] Required current value; the returned list retains it without consuming references already held by the caller.

Resolve an option spelling for configuration bookkeeping.

Resolves synonyms through their clientData canonical name. Use the same specification as Tk_SetOptions; this helper does not parse option values.

Parameters:

  • objPtr – Option-name object, or NULL.

  • specs – Complete specification table, or NULL; chained tables are followed.

Returns:

Borrowed canonical name from the specification, or NULL for an empty, missing or ambiguous match. No interpreter diagnostic is produced.

Relative child lookup

Tk_Window Rbc_FindChild(Tk_Window parent, const char *name)

Resolve a relative child path beneath a borrowed parent window.

Returns a borrowed window or NULL when lookup fails. The root parent uses a single leading dot. No window is created or retained, and lookup has no result interpreter. A dotted relative name can resolve a deeper descendant.

Parameters:

  • parent – [in] Borrowed parent window, or NULL to return NULL immediately.

  • name – [in] Borrowed NUL-terminated relative child path, without a leading dot; not retained.
