Crosshair C reference¶

These private helpers borrow graph state. See Crosshair state and presentation before changing erase/update/present ordering.

Direct overlay control¶

void Rbc_EnableCrosshairs(Graph *graphPtr)¶

Restore XOR crosshairs when requested and drawable on screen.

Honors hidden state and draws only when the window is mapped, hairs are not already visible, and the hotspot is inside the plot. Does not change -hide.

Parameters:

  • graphPtr – Live graph with initialized crosshairs and current segments.

void Rbc_DisableCrosshairs(Graph *graphPtr)¶

Temporarily erase currently visible XOR crosshairs.

When not hidden, erases on a mapped window using the current GC and segments. Does not change -hide. Call before overwriting geometry in direct redraws.

Parameters:

  • graphPtr – Live graph with initialized crosshairs and their old geometry.

void Rbc_UpdateCrosshairs(Graph *graphPtr)¶

Update segment lengths from current graph plot bounds.

Leaves hotspot coordinates unchanged. Does not erase, draw or change visible state. Call only when old geometry is no longer needed to erase old pixels.

Parameters:

  • graphPtr – Graph with initialized crosshairs and prepared plot geometry.

Buffered presentation¶

int Rbc_CrosshairsNeedFullRedraw(Graph *graphPtr)¶

Test whether a plot-only frame copy could leave crosshair pixels behind.

Call before updating segments. The caller must request margin drawing as well as a full copy so the entire source frame contains initialized pixels.

Parameters:

  • graphPtr – Borrowed graph with old crosshair geometry still intact.

Returns:

Nonzero for relevant wide strokes or visible old endpoints outside the current plot; zero when no full-frame copy is needed by this test.

void Rbc_PresentGraphWithCrosshairs(Graph *graphPtr, Drawable drawable)¶

Compose crosshairs into a completed temporary frame and present once.

Updates segments, adds requested visible hairs, copies the frame to the window, then commits visible state. DRAW_MARGINS selects full-frame copying; otherwise only the plot is copied. No Tcl callbacks or event processing may intervene between geometry update and state commit. Do not separately erase or enable window hairs around this call. Does not free the pixmap.

Parameters:

  • graphPtr – Live mapped graph with current layout and copy GC.

  • drawable – Temporary compatible pixmap containing a completed frame without crosshairs; never the window, reusable backing store or export target.
