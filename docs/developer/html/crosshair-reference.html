Crosshair C reference¶

These private helpers borrow graph state. See Crosshair state and presentation before changing erase/update/present ordering.

Direct overlay control¶

void Rbc_EnableCrosshairs(Graph *graphPtr)¶

Restore XOR crosshairs when requested and drawable on screen.

Honors hidden state and draws only when the window is mapped, hairs are not already visible, and the hotspot is inside the plot. Does not change -hide.

Parameters:

  • graphPtr – Live graph with initialized crosshairs and current segments.

void Rbc_DisableCrosshairs(Graph *graphPtr)¶

Temporarily erase currently visible XOR crosshairs.

When not hidden, erases on a mapped window using the current GC and segments. Does not change -hide. Call before overwriting geometry in direct redraws.

Parameters:

  • graphPtr – Live graph with initialized crosshairs and their old geometry.

void Rbc_UpdateCrosshairs(Graph *graphPtr)¶

Update segment lengths from current graph plot bounds.

Leaves hotspot coordinates unchanged. Does not erase, draw or change visible state. Call only when old geometry is no longer needed to erase old pixels.

Parameters:

  • graphPtr – Graph with initialized crosshairs and prepared plot geometry.

Buffered presentation¶

int Rbc_CrosshairsNeedFullRedraw(Graph *graphPtr)¶

Test whether a plot-only frame copy could leave crosshair pixels behind.

Call before updating segments. The caller must request margin drawing as well as a full copy so the entire source frame contains initialized pixels.

Parameters:

  • graphPtr – Borrowed graph with old crosshair geometry still intact.

Returns:

Nonzero for relevant wide strokes or visible old endpoints outside the current plot; zero when no full-frame copy is needed by this test.

void Rbc_PresentGraphWithCrosshairs(Graph *graphPtr, Drawable drawable)¶

Compose crosshairs into a completed temporary frame and present once.

Updates segments, adds requested visible hairs, copies the frame to the window, then commits visible state. DRAW_MARGINS selects full-frame copying; otherwise only the plot is copied. No Tcl callbacks or event processing may intervene between geometry update and state commit. Do not separately erase or enable window hairs around this call. Does not free the pixmap.

Parameters:

  • graphPtr – Live mapped graph with current layout and copy GC.

  • drawable – Temporary compatible pixmap containing a completed frame without crosshairs; never the window, reusable backing store or export target.

Functions

static void TurnOffHairs(Tk_Window tkwin, Crosshairs *chPtr)¶

Erase currently visible XOR segments using their original GC.

Requires a live Tk window and crosshair record. Only draws when the window is mapped and visible is true, then clears visible. On an unmapped window it leaves visible unchanged. Does not consult or modify requested hidden state. Endpoints/GC must still describe the pixels being erased. No Tcl callbacks.

static void TurnOnHairs(Graph *graphPtr, Crosshairs *chPtr)¶

Draw requested XOR geometry when the hotspot lies inside the plot.

Borrows a live graph/window and prepared crosshair GC/segments. Draws only when mapped, not already visible, and PointInGraph accepts the hotspot; then sets visible. Does not test hidden: callers decide requested visibility. Does not remap endpoints or schedule an idle redraw. No Tcl callbacks.

static int GetCrosshairPositionFromObj(Tcl_Interp *interp, Tk_Window tkwin, Tcl_Obj *objPtr, Point2D *pointPtr)¶

Parse an optional @x,y widget-pixel position.

NULL or empty input succeeds with INT_MIN in both output coordinates, an out-of-plot sentinel. Otherwise splits at the first comma and converts both parts through Tk_GetPixelsFromObj using temporary retained Tcl objects. Accepts Tk screen-distance syntax, storing integer pixel results as doubles.

Returns TCL_OK only after both coordinates convert. On TCL_ERROR leaves pointPtr unchanged, releases both temporary objects, and reports syntax or conversion context in interp. Does not move crosshairs or invoke Tcl code.

static int ConfigureCrosshairs(Graph *graphPtr, Crosshairs *chPtr, int mask)¶

Validate derived crosshair state before changing XOR pixels.

Requires a live graph/window and Tk-parsed option fields. Stages dash, width and hotspot conversions selected by mask; TCL_ERROR leaves active GC/geometry and displayed pixels unchanged, while caller restores Tk options separately. Windows exact position-only changes delegate to MoveCrosshairs.

Otherwise prepares a replacement XOR GC, erases with old GC/endpoints, commits new state, rebuilds both segments, and draws when requested and eligible. Releases replaced GC; returns TCL_OK without scheduling a graph redraw. No Tcl callback is evaluated between erase and replacement.

static int CgetOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return one component option value.

The typed dispatcher has validated argument count. Borrows the graph-owned component and its option table, returning Tk option errors unchanged. This query does not configure resources or schedule drawing.

static int ConfigureOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query or transactionally configure crosshair options.

Three or four arguments return Tk option metadata. Updates stage Tk fields and invoke ConfigureCrosshairs to validate derived state before visual replacement. Failure restores saved options and the diagnostic; success frees saved values. Presentation is handled by the helper rather than scheduling a whole-graph redraw here.

static int OnOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Request crosshairs to be shown.

When previously hidden, attempts drawing with TurnOnHairs before clearing hidden. Actual visibility still depends on window mapping and hotspot location. Repeated on is a no-op even if requested hairs are not currently visible; display/motion paths own later presentation.

static int OffOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Request crosshairs to be hidden.

When previously requested on, erases through TurnOffHairs before setting hidden. Repeated off is a no-op. The low-level helper may leave actual visibility unchanged on an unmapped window; requested state is not a direct pixel-state assertion.

static int ToggleOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Toggle requested crosshair state and perform its visual transition.

Updates hidden first, then erases or draws through the low-level helpers. Those helpers do not consult hidden; they use actual visibility, mapping and hotspot eligibility. Does not invalidate the reusable graph backing store.

int Rbc_CrosshairsOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Validate and dispatch a crosshair subcommand.

The typed table validates operation name and argument count before calling a handler. Borrowed graph state must remain live. Dispatch itself does not update segment geometry, process events or perform buffered presentation.
