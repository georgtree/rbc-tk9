Geometry C reference¶

These declarations remain in rbcInt.h. See Geometry, clipping and simplification for conventions.

double Rbc_GetClosestPointOnSegment(const Point2D *samplePtr, const Point2D *p, const Point2D *q, Point2D *closestPtr)¶

Find the clamped nearest point on a finite segment and return distance.

Inputs and closestPtr are borrowed; closestPtr must be non-NULL. Segments of length at most DBL_EPSILON use p. Invalid inputs or rejected intermediate arithmetic return DBL_MAX without writing the result. The final hypot may still overflow for extreme finite coordinates; this is not a Tcl error API.

int Rbc_LineRectClip(const Extents2D *extsPtr, const Point2D *p, const Point2D *q, Segment2D *clippedPtr)¶

Clip a segment to inclusive extents using Liang-Barsky parameters.

Requires finite, ordered extents and finite endpoints. Returns false for invalid/disjoint input, leaving output untouched. On success, writes the clipped segment if clippedPtr is non-NULL; NULL requests visibility only. Input endpoints are not modified when output storage is separate.

Tcl_Size Rbc_PolyRectClip(const Extents2D *extsPtr, const Point2D *inputPts, Tcl_Size nInputPts, Point2D *outputPts, Tcl_Size outputCapacity)¶

Clip a polygon into a separate caller-owned output array.

Input contains exactly nInputPts vertices; the closing edge is implicit. Uses left/top and historical right+1/bottom+1 clipping boundaries. Output is explicitly closed by repeating its first vertex. outputCapacity counts all available Point2D entries, including closure. Returns the output count, or zero for empty/invalid input or insufficient capacity. Capacity failure can leave partial output; discard it. Input and output must not overlap.

int Rbc_PointInPolygon(const Point2D *samplePtr, const Point2D *points, Tcl_Size nPoints)¶

Test polygon membership by an even-odd horizontal ray crossing.

Requires at least three finite vertices and a finite sample; invalid input returns false. The closing edge is implicit. Half-open crossing comparisons do not promise that every point on an edge is inside. Does not modify input.

int Rbc_RegionInPolygon(const Extents2D *extsPtr, const Point2D *points, Tcl_Size nPoints, int enclosed)¶

Test polygon enclosure by, or overlap with, a rectangle.

With enclosed nonzero, every polygon vertex must be inside inclusive extents; this means the rectangle encloses the polygon, not the reverse. Otherwise test edge intersection and then rectangle-inside-polygon containment. Invalid extents or fewer than three finite vertices return false.

int Rbc_PointInSegments(const Point2D *samplePtr, const Segment2D *segments, Tcl_Size nSegments, double halo)¶

Return true if any segment is strictly closer than halo to the sample.

Requires a finite positive halo; zero or invalid halo, no segments or an invalid sample returns false. Uses clamped segment distance, including degenerate segments. Does not acquire or modify the borrowed arrays.

Tcl_Size Rbc_SimplifyLine(const Point2D *origPts, Tcl_Size low, Tcl_Size high, double tolerance, Tcl_Size indices[])¶

Return retained original indices for an inclusive input interval.

Caller supplies valid finite points through high and space for high-low+1 indices; no array lengths are supplied or checked here. Use a finite, nonnegative tolerance in the same coordinate units as input. The algorithm measures distance to the infinite endpoint line, or to the endpoint when endpoints coincide. Retains interval endpoints in input order, splitting only when squared distance exceeds squared tolerance. Returns zero on rejected bounds/allocation failure; discard any partial output. Input is borrowed and unchanged; temporary stack storage is released before return.

static int IsFinitePoint(const Point2D *pointPtr)¶

Test a point pointer and both coordinates.

Returns FALSE for NULL or either non-finite coordinate; otherwise TRUE. No allocation, mutation or coordinate transformation.

static int IsValidExtents(const Extents2D *extsPtr)¶

Test finite ordered rectangular extents.

Requires left <= right and top <= bottom after checking all coordinates. NULL or non-finite bounds return FALSE; zero width/height is accepted. Does not normalize reversed bounds or apply pixel-area expansion.

static int ClipTest(double ds, double dr, double *t1, double *t2)¶

Intersect a Liang-Barsky parameter interval with one boundary.

Caller supplies initialized t1/t2, normally 0/1. Negative ds can raise the entry parameter; positive ds can lower the exit parameter. A parallel edge (ds zero) rejects only when dr is negative. Returns boolean; this call leaves parameters untouched when it rejects, but earlier successful boundary calls may already have narrowed them. No allocation or independent finite checks.

static int AppendClipVertex(Point2D *points, Tcl_Size capacity, Tcl_Size *countPtr, double x, double y)¶

Append one vertex when the caller-provided buffer has room.

Requires a valid countPtr; rejects NULL points, negative count or count at or above capacity without changing storage/count. On success writes X/Y and increments count. Does not test coordinate finiteness or suppress duplicates. The clipper must discard the whole polygon on a failed append.

static double FindSplit(const Point2D points[], Tcl_Size i, Tcl_Size j, Tcl_Size *split)¶

Find the first farthest interior point for line simplification.

Requires valid source indices and caller storage for split. Returns maximum squared distance and writes its original source index; ties keep the first. Uses distance to the infinite endpoint line, not the bounded segment. If the endpoint distance is at most DBL_EPSILON, measures from the first endpoint.

NULL split returns -1. Otherwise initializes split to -1, also returning -1 for invalid pointers/ranges or no interior point. Does not know array capacity or validate every coordinate; extreme intermediate arithmetic may overflow. No allocation or input mutation.
