Axis control C reference¶

These implementation contracts cover registry lifetime, configuration entry points and command dispatch in rbcGrAxis.c. See Axis ownership and commands for ownership and error boundaries and Coordinate mapping C reference for coordinate helpers. Namespaces below disambiguate private handler names without changing linkage.

Registry and lifetime¶

group Axis registry and lifetime

Functions

static void DestroyAxis(Graph *graphPtr, Axis *axisPtr)¶

Destroy an axis and all resources it owns.

Cancels pending scrollbar notification, releases options and bindings, removes the margin link and registry entry when present, and frees styles, shadows, tick arrays, labels, formats, segments, tags and the record. Does not consult refCount; callers must ensure no consumers retain the record.

static Axis *CreateAxis(Graph *graphPtr, char *name, int margin)¶

Allocate a registered axis or revive a pending deletion.

Rejects names beginning with a dash and existing live names, returning NULL with an interpreter error. A new record owns a copied name and label chain but is not yet configured or linked to a margin. Revival returns the same record, clears deletePending and invalidates notified limits; it preserves references and existing resources.

static int NameToAxis(Graph *graphPtr, const char *name, Axis **axisPtrPtr)¶

Look up a live named axis without retaining it.

Returns TCL_OK and a borrowed pointer. Missing and delete-pending axes return TCL_ERROR, set the interpreter result, and clear the output pointer.

static int GetAxis(Graph *graphPtr, const char *axisName, Rbc_Uid classUid, Axis **axisPtrPtr)¶

Look up an axis and optionally acquire a typed reference.

A NULL classUid performs a borrowed lookup. Otherwise establishes the logical X/Y class when unused or untyped, rejects a conflicting class, and increments refCount on success. Match each acquired reference with FreeAxis. The output pointer is assigned only on success.

static void FreeAxis(Graph *graphPtr, Axis *axisPtr)¶

Release one acquired axis reference.

Requires a positive reference count. Destroys the record when the count reaches zero and deletion is pending; an unreferenced live axis remains registered.

int Rbc_GetAxisFromObj(Graph *graphPtr, Tcl_Obj *objPtr, Rbc_Uid classUid, int allowEmpty, Axis **axisPtrPtr)¶

Resolve an optional Tcl axis name with the requested reference policy.

A NULL or empty object returns a NULL axis only when allowEmpty is true; otherwise it reports TCL_ERROR. Nonempty names delegate to GetAxis, including its typed-reference ownership and output- on-success rules.

void Rbc_FreeAxisReference(Graph *graphPtr, Axis *axisPtr)¶

Release an optional retained axis reference.

Accepts NULL. A non-NULL argument must represent an acquired reference; release may destroy a delete-pending record.

void Rbc_DestroyAxes(Graph *graphPtr)¶

Tear down the complete graph axis registry.

Destroys records regardless of reference counts, then deletes registry and tag tables and axis chains. Clears each record hash pointer before destruction to keep hash iteration valid. Consumers must have been detached by graph teardown; this is not ordinary axis deletion.

int Rbc_DefaultAxes(Graph *graphPtr)¶

Create and configure the four initial margin axes.

Creates x, y, x2 and y2 with one reference each and the appropriate logical class. Polar axes start hidden before database options are applied. Success links each configured record to its chain. Failure returns TCL_ERROR with partial initialization left for graph teardown.

Configuration entry points¶

group Axis configuration entry points

Functions

static int InitAxisOptions(Graph *graphPtr, Axis *axisPtr)¶

Initialize Tk options through the named Axis component.

Returns TCL_OK if already initialized or successfully initialized. On initialization failure, frees partially installed Tk resources and the option table. The component resource name is temporary; the Axis retains the option table.

static void ResetAxisOptionContext(Axis *axisPtr)¶

Clear borrowed configuration arguments and the option mask.

Does not free the caller-owned object vector or alter committed option values.

static int ConfigureAxisOptions(Graph *graphPtr, Axis *axisPtr, Tcl_Size objc, Tcl_Obj *const objv[], int *maskPtr)¶

Apply one axis option transaction and construct derived state.

Requires initialized options and an even object count. Borrows objv only during ConfigureAxis, clearing that context before rollback or return. On failure restores Tk-managed options; on success releases saved options, marks configuration notification pending, and optionally returns the changed mask. Returns a Tcl status.

static int ConfigureNewAxis(Graph *graphPtr, Axis *axisPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Initialize options and derive a usable axis configuration.

Runs configuration even for an empty option vector so database defaults reach derived fields. Returns a Tcl status; the caller owns failure cleanup. An already initialized revived axis retains its option table.

static void ReleaseAxisOptionResources(Graph *graphPtr, Axis *axisPtr)¶

Release Tk-owned option resources once.

Clears borrowed transaction context and deletes the initialized option table. Does not release derived labels, geometry, shadow colours or text-style graphics contexts; DestroyAxis owns those resources.

static void ResetTextStyles(Graph *graphPtr, Axis *axisPtr)¶

Refresh text styles and replace the axis tick graphics context.

Borrows configured fonts and colours. Allocates the new tick GC before releasing the old one; uses the existing native line-width conversion and projecting caps.

static int ConfigureAxis(Graph *graphPtr, Axis *axisPtr)¶

Validate staged options before committing derived axis resources.

Prepares limit, tick, loose-range, pixel, shadow, tag and format transactions as needed. Validates command prefixes without evaluating them. Recoverable errors free prepared resources before any commit. Success normalizes rotation, refreshes styles and title extents, marks axis and graph mapping dirty, and schedules redraw. The caller restores Tk-managed fields on error.

Commands and bindings¶

group Axis command dispatch and bindings

Functions

static int BindOp(Graph *graphPtr, Axis *axisPtr, int margin, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query or configure bindings for a selected margin axis.

Interns the axis name as a binding tag and forwards the already sliced argument vector. Returns the binding subsystem Tcl status; does not evaluate an event binding here.

static int CgetOp(Graph *graphPtr, Axis *axisPtr, int margin, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return one initialized axis option value.

Requires a live axis and initialized Tk option table. Uses the first sliced argument as the option name and returns TCL_ERROR if Tk cannot resolve it.

static int ConfigureOp(Graph *graphPtr, Axis *axisPtr, int margin, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query or configure one resolved axis.

Zero or one sliced argument returns Tk option metadata. Option/value pairs use ConfigureAxisOptions. Success additionally invalidates backing and margins for an onscreen axis. This transaction covers one axis, not a multi-axis command.

static int UseOp(Graph *graphPtr, Axis *axisPtr, int margin, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query or replace the axes displayed on a margin.

Queries return chain order. Replacement chooses logical class using inversion and rejects trackgraph Y arrangement, which belongs to tracks. Validates every replacement name and type before changing any chain. Failure leaves all margins unchanged. Success moves existing links as needed and schedules full layout and redraw.

static int BindVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

List interned axis tags or access one tag binding.

With no tag argument returns the tag table in hash order. Otherwise interns the supplied tag and forwards remaining arguments; the tag need not name an existing axis.

static int CreateVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create or revive a named axis and apply its options.

Returns the axis name on success. Configuration failure destroys only a newly allocated record. Failed revival restores pending deletion and the previous notification validity while preserving the record and its consumers; ConfigureNewAxis rolls back its option transaction.

static int CgetVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Resolve a named axis and delegate its option query.

Uses a borrowed live lookup and passes the option suffix to CgetOp. Returns the lookup or option- query Tcl status.

static int ConfigureVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Apply a shared option suffix to one or more named axes.

Validates names before the first option beginning with a dash, then configures them sequentially. Earlier successful axes are not rolled back if a later configuration fails. Query results are replaced by each successive axis result.

static int DeleteVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Mark named axes for deletion and destroy unreferenced records.

Rejects track-owned axes until detached. Marks an active formatter traversal invalid before deletion. Referenced records remain allocated but disappear from live name lookup. Processes names sequentially, so earlier deletions survive a later error.

static int GetOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Report the current axis name or picked detail.

Checks the binding context before interpreting the picked object as an axis. Returns a value only for current or detail with an eligible picked axis; otherwise returns TCL_OK without setting a new result.

static int NamesVirtualOp(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

List live axis names matching any supplied glob pattern.

Skips delete-pending records, returns each matching name once and preserves hash traversal order, not display order. No patterns means all live names.

int Rbc_VirtualAxisOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch the named-axis command family.

Validates operation and argument counts with the shared operation table, then forwards the complete widget command vector. Handlers resolve names and apply their own lifetime and transaction rules.

int Rbc_AxisOp(Graph *graphPtr, int margin, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a margin-axis operation.

Validates operation and argument counts, selects the first eligible axis from the margin chain and passes the suffix after the operation. UseOp can query or replace the chain; other handlers require an appropriate selected axis.

static ClientData MakeAxisTag(Graph *graphPtr, char *tagName)¶

Intern a binding tag in the graph axis tag table.

Returns a borrowed stable hash key. Its storage belongs to the graph and is released with the tag table, not by individual binding operations.

void Rbc_AppendAxisBindingTags(Graph *graphPtr, Axis *axisPtr, Rbc_List list)¶

Append axis name, class and configured tags in binding order.

Borrows the graph, axis and destination list. Interned keys remain owned by the graph tag table. The list is appended to rather than cleared; configured tags follow the name and class.

Option transaction internals¶

group Axis option transactions

Functions

static int IsAxisOption(Tcl_Obj *objPtr, const char *optionName)¶

Compare a validated option with its canonical name.

Uses the axis option table to resolve abbreviations and synonyms. Returns false when resolution fails. This helper does not replace Tk option validation or report an interpreter error.

static int IsAxisBindTagsOption(Tcl_Obj *objPtr)¶

Recognize the -bindtags option.

Delegates canonical-name matching to IsAxisOption after Tk has rejected unknown or ambiguous options.

static int StageAxisTags(Tcl_Interp *interp, Tcl_Obj *objPtr, AxisTagsTransaction *transactionPtr)¶

Stage a replacement binding-tag list.

Parses into a new string-list allocation before releasing the previous candidate. Success owns the new allocation and sets staged; failure preserves the prior candidate. Does not alter live tags.

static void FreeAxisTagsTransaction(AxisTagsTransaction *transactionPtr)¶

Discard an axis tags transaction.

Releases owned tag-list allocation and zeroes the complete transaction. Requires initialized or zeroed storage. Safe after commit because transferred ownership has been cleared; does not alter live axis fields.

static int PrepareAxisTagsTransaction(Graph *graphPtr, Axis *axisPtr, AxisTagsTransaction *transactionPtr)¶

Prepare the axis tags option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. On error releases all candidates owned by this transaction.

static void CommitAxisTagsTransaction(Axis *axisPtr, AxisTagsTransaction *transactionPtr)¶

Commit prepared axis tags candidates.

Transfers the staged list, clears its pointer and flag, then frees the old live list. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static void FreeAxisFormats(char **formats)¶

Release a split limit-format allocation.

Accepts NULL. Frees the single allocation, not each string separately; cannot clear the caller pointer.

static int IsAxisLimitsFormatOption(Tcl_Obj *objPtr)¶

Recognize the -limitsformat option.

Delegates canonical-name matching to IsAxisOption after Tk has rejected unknown or ambiguous options.

static int ValidateAxisLimitFormat(Tcl_Interp *interp, const char *format)¶

Validate a format string used with one double argument.

Allows literal text, escaped percent signs and at most one a/A/e/E/f/F/g/G conversion, optionally with lowercase l. Rejects dynamic width/precision, other conversion types and excessive format length, width or precision above TICK_LABEL_SIZE. Zero conversions are allowed. Returns a Tcl status; it validates argument compatibility rather than guaranteeing the rendered output fits a label buffer.

static int GetAxisLimitsFormatsFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, char ***formatsPtrPtr, int *nFormatsPtr)¶

Allocate zero, one or two validated limit formats.

Initializes outputs to NULL and zero. NULL or an empty string succeeds without allocation. Splits the Tcl list, rejects more than two entries and validates each format. Failure frees the split allocation. Success transfers one allocation containing the pointer list and strings to the caller; free it with FreeAxisFormats.

static int StageAxisLimitsFormats(Tcl_Interp *interp, Tcl_Obj *objPtr, AxisFormatTransaction *transactionPtr)¶

Stage replacement axis-limit formats.

Parses and validates the replacement before freeing previous staged formats. Success records the new allocation, count and staged flag; failure preserves the previous candidate.

static void FreeAxisFormatTransaction(AxisFormatTransaction *transactionPtr)¶

Discard an axis format transaction.

Releases owned format-list allocation and zeroes the complete transaction. Requires initialized or zeroed storage. Safe after commit because transferred ownership has been cleared; does not alter live axis fields.

static int PrepareAxisFormatTransaction(Graph *graphPtr, Axis *axisPtr, AxisFormatTransaction *transactionPtr)¶

Prepare the axis format option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. On error releases all candidates owned by this transaction.

static void CommitAxisFormatTransaction(Axis *axisPtr, AxisFormatTransaction *transactionPtr)¶

Commit prepared axis format candidates.

Transfers the staged format list and count, clears the candidate pointer/count/flag, then frees the old live allocation. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static AxisLimitOption GetAxisLimitOption(Tcl_Obj *objPtr)¶

Classify an axis limit option.

Resolves the canonical name using axisOptionSpecs and returns the corresponding enum for display and scroll minima/maxima. Returns the NONE enum for unrelated or unresolved names; performs no allocation.

static int GetAxisLimitFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, double *valuePtr)¶

Evaluate an optional finite axis-limit expression.

NULL or an empty object selects VALUE_UNDEFINED. Otherwise calls Tcl_ExprDoubleObj and rejects nonfinite results. Returns a Tcl status. Expression evaluation may execute Tcl substitutions; it is not a literal-only conversion and does not itself preserve graph or axis lifetime. The output is usable only on success.

static AxisPixelOption GetAxisPixelOption(Tcl_Obj *objPtr)¶

Classify an axis pixel option.

Resolves the canonical name using axisOptionSpecs and returns the corresponding enum for border width, line width and scroll increment. Returns the NONE enum for unrelated or unresolved names; performs no allocation.

static int StageAxisPixelOption(Graph *graphPtr, Tcl_Obj *objPtr, AxisPixelOption option, AxisPixelTransaction *transactionPtr)¶

Stage one validated pixel-distance value.

Border and line widths must be nonnegative; scroll increment must be positive. Uses Tk-window scaling through Rbc_GetPixelsFromObj. Success updates the selected scalar and mask only; an invalid internal enum panics.

static int PrepareAxisPixelTransaction(Graph *graphPtr, Axis *axisPtr, AxisPixelTransaction *transactionPtr)¶

Prepare the axis pixel option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. Contains only scalar candidates; no allocation cleanup is required on error.

static void CommitAxisPixelTransaction(Axis *axisPtr, AxisPixelTransaction *transactionPtr)¶

Commit prepared axis pixel candidates.

Copies only masked values into borderWidth, lineWidth and scrollUnits, then clears the mask. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static int StageAxisLimit(Tcl_Interp *interp, Tcl_Obj *objPtr, AxisLimitOption option, AxisLimitTransaction *transactionPtr)¶

Stage one display or scroll limit.

Evaluates the candidate before writing the selected scalar and setting its mask bit. Failure leaves the candidate unchanged. An invalid internal enum panics. Cross-field and logarithmic range validation belong to preparation.

static int PrepareAxisLimitTransaction(Graph *graphPtr, Axis *axisPtr, AxisLimitTransaction *transactionPtr)¶

Prepare the axis limit option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. Contains only scalar candidates; no allocation cleanup is required on error. Starts with current live limits, checks final display and scroll ordering, and requires defined limits to be positive for log scaling even when only logScale changed.

static void CommitAxisLimitTransaction(Axis *axisPtr, AxisLimitTransaction *transactionPtr)¶

Commit prepared axis limit candidates.

Copies only masked requested/scroll limits into the live axis, then clears the mask. Validated but unstaged values remain untouched. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static void FreeAxisTicks(Ticks *ticksPtr)¶

Release one explicit tick allocation.

Accepts NULL. Frees the allocation without modifying the caller pointer.

static AxisTickOption GetAxisTickOption(Tcl_Obj *objPtr)¶

Classify an axis tick option.

Resolves the canonical name using axisOptionSpecs and returns the corresponding enum for major and minor tick lists. Returns the NONE enum for unrelated or unresolved names; performs no allocation.

static int IsAxisLooseOption(Tcl_Obj *objPtr)¶

Recognize the -loose option.

Delegates canonical-name matching to IsAxisOption after Tk has rejected unknown or ambiguous options.

static int GetAxisLooseFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, int *looseMinPtr, int *looseMaxPtr)¶

Parse one or two tick-range policies.

Accepts Tcl booleans or the exact string always. One entry applies to both ends; two entries specify minimum then maximum. Returns TCL_ERROR for invalid list length or entries without assigning the output pair. Allocates no retained storage.

static int StageAxisLoose(Tcl_Interp *interp, Tcl_Obj *objPtr, AxisLooseTransaction *transactionPtr)¶

Stage minimum and maximum tick-range policies.

Parses the complete one/two-entry value before updating the scalar pair and setting staged. Failure preserves earlier candidates; no owned allocation is created.

static int PrepareAxisLooseTransaction(Graph *graphPtr, Axis *axisPtr, AxisLooseTransaction *transactionPtr)¶

Prepare the axis loose option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. Contains only scalar candidates; no allocation cleanup is required on error.

static void CommitAxisLooseTransaction(Axis *axisPtr, AxisLooseTransaction *transactionPtr)¶

Commit prepared axis loose candidates.

Copies the staged minimum/maximum policies and clears staged. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static int GetTicksByteCount(Tcl_Size nTicks, size_t *sizePtr)¶

Compute the allocation size for a variable-length tick array.

Rejects negative counts and size_t overflow using offsetof(Ticks, values). Writes the byte count only on TCL_OK. Does not impose MAXTICKS or report an interpreter error; the caller applies those policies.

static int GetAxisTicksFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, Ticks **ticksPtrPtr)¶

Allocate explicit ticks from a list of finite expressions.

NULL or an empty list returns TCL_OK with a NULL output. Rejects more than MAXTICKS entries, overflow, allocation failure and invalid/nonfinite expressions. Evaluates entries in input order with Tcl_ExprDoubleObj; no sorting or deduplication is performed. Frees partial storage on failure and leaves the output NULL. Successful nonempty storage belongs to the caller. Expression evaluation can execute Tcl substitutions; this helper supplies no graph lifetime guard.

static int StageAxisTicks(Tcl_Interp *interp, Tcl_Obj *objPtr, AxisTickOption option, AxisTickTransaction *transactionPtr)¶

Stage a major or minor explicit tick allocation.

Parses and allocates the replacement before releasing an earlier candidate for that option. NULL is a valid staged candidate selecting automatic ticks. Success sets the mask; failure retains previous candidates. Invalid internal enums free the new allocation and panic.

static void FreeAxisTickTransaction(AxisTickTransaction *transactionPtr)¶

Discard an axis tick transaction.

Releases owned major and minor tick allocations and zeroes the complete transaction. Requires initialized or zeroed storage. Safe after commit because transferred ownership has been cleared; does not alter live axis fields.

static int PrepareAxisTickTransaction(Graph *graphPtr, Axis *axisPtr, AxisTickTransaction *transactionPtr)¶

Prepare the axis tick option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. On error releases all candidates owned by this transaction.

static void CommitAxisTickTransaction(Axis *axisPtr, AxisTickTransaction *transactionPtr)¶

Commit prepared axis tick candidates.

Transfers masked candidates into t1Ptr/t2Ptr, updates AXIS_CONFIG_MAJOR/MINOR according to non-NULL candidates, releases old arrays and clears transferred pointers and mask. A staged NULL restores automatic tick generation. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

static void FreeAxisShadow(Shadow *shadowPtr)¶

Release an owned shadow colour and reset its fields.

The Shadow record must be valid, with an owned Tk colour or NULL. Releases the colour reference, then clears colour and offset. Does not free the Shadow record itself.

static AxisShadowOption GetAxisShadowOption(Tcl_Obj *objPtr)¶

Classify an axis shadow option.

Resolves the canonical name using axisOptionSpecs and returns the corresponding enum for limits, tick and title shadows. Returns the NONE enum for unrelated or unresolved names; performs no allocation.

static int StageAxisShadow(Graph *graphPtr, Tcl_Obj *objPtr, AxisShadowOption option, AxisShadowTransaction *transactionPtr)¶

Stage one owned shadow colour and offset.

Acquires and validates a new shadow before releasing an earlier candidate for the same option. Success transfers the new colour reference into the transaction and sets its mask. Invalid internal enums release the new colour and panic.

static void FreeAxisShadowTransaction(AxisShadowTransaction *transactionPtr)¶

Discard an axis shadow transaction.

Releases owned three shadow colour references and zeroes the complete transaction. Requires initialized or zeroed storage. Safe after commit because transferred ownership has been cleared; does not alter live axis fields.

static int PrepareAxisShadowTransaction(Graph *graphPtr, Axis *axisPtr, AxisShadowTransaction *transactionPtr)¶

Prepare the axis shadow option family.

Initializes fresh transaction storage; do not pass an existing owning transaction. Examines the borrowed even-length option vector, identifies explicit options, and on first configuration parses effective defaults only for options not explicitly overridden. Processes every explicit occurrence in caller order, so a bad earlier value cannot be hidden by a later valid one. Returns a Tcl status without committing live derived fields. On error releases all candidates owned by this transaction.

static void CommitAxisShadowTransaction(Axis *axisPtr, AxisShadowTransaction *transactionPtr)¶

Commit prepared axis shadow candidates.

Transfers masked colours and offsets into the three text styles, clears transferred candidate fields, releases old colours and clears the mask. Unstaged options are unchanged. Performs no parsing, callback evaluation or recoverable validation; the caller must have prepared all option families first.

struct AxisLimitTransaction¶

Scalar requested/scroll candidates, initialized from live values; stagedMask selects fields to commit.

struct AxisTickTransaction¶

Owns major/minor tick allocations until commit.

A masked NULL candidate requests automatic ticks.

struct AxisLooseTransaction¶

Scalar minimum/maximum policies; staged distinguishes no change from a parsed pair.

struct AxisPixelTransaction¶

Scalar pixel candidates; stagedMask identifies parsed fields and no heap cleanup is needed.

struct AxisShadowTransaction¶

Owns staged Tk colour references and offsets until commit; unmasked entries are zero initialized.

struct AxisTagsTransaction¶

Owns one staged string-list allocation until commit; staged distinguishes no change from an empty list.

struct AxisFormatTransaction¶

Owns one split-list allocation with at most two formats until commit; count and staged accompany it.
