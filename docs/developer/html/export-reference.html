Export orchestration C reference

These interfaces are private. See Export orchestration and document ownership for ownership, format policy and the distinction between ending export mode and restoring screen layout.

Document context

void Rbc_ExportInit(Rbc_ExportContext *exportPtr, Rbc_ExportBackend backend, Tcl_Interp *interp, Tk_Window tkwin, int decorations)

Initialize fresh caller-owned export storage.

Zero the record, borrow interp and tkwin, and select the embedded DString as the append destination. Call only on an uninitialized or already freed record; this does not release an earlier document. Font embedding starts disabled. The caller supplies backend state and any alternate buffer after this call.

Parameters:

  • exportPtr – [out] Caller-owned fresh or previously freed record; existing resources are not released.

  • backend – [in] Document backend selected for subsequent renderer dispatch.

  • interp – [in] Interpreter borrowed for the entire export; see Interpreter arguments.

  • tkwin – [in] Window borrowed for screen metrics and resources throughout export.

  • decorations – [in] Whether traversal includes decorative backgrounds, borders and separators.

int Rbc_ExportError(Rbc_ExportContext *exportPtr, const char *message)

Retain the first export failure without replacing later diagnostics.

Parameters:

  • exportPtr – Initialized, borrowed context.

  • message – Borrowed static string; it is neither copied nor freed.

Returns:

TCL_ERROR. This helper does not set the interpreter result.

void Rbc_ExportFree(Rbc_ExportContext *exportPtr)

Release document-local font data and the embedded DString.

struct Rbc_GraphExportFormat
#include <rbcGraph.h>

Static private policy for a named SVG/PDF graph export component.

Strings and option specifications are borrowed for the command lifetime. All option entries must be concrete TK_OPTION_PIXELS or TK_OPTION_BOOLEAN values stored as native Graph ints; offsets are trusted, not range checked. documentProc returns a new object at reference count zero on success and leaves delivery, geometry restoration and context cleanup to the caller. freeProc releases backend-owned state only, may be NULL, and must accept a context with no backend allocation. Shared cleanup releases fonts/storage. Encoding and translation select Tcl channel policy for file delivery.
