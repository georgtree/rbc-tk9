Export orchestration C reference¶

These interfaces are private. See Export orchestration and document ownership for ownership, format policy and the distinction between ending export mode and restoring screen layout.

Document context¶

void Rbc_ExportInit(Rbc_ExportContext *exportPtr, Rbc_ExportBackend backend, Tcl_Interp *interp, Tk_Window tkwin, int decorations)¶

Initialize fresh caller-owned export storage.

Zero the record, borrow interp and tkwin, and select the embedded DString as the append destination. Call only on an uninitialized or already freed record; this does not release an earlier document. Font embedding starts disabled. The caller supplies backend state and any alternate buffer after this call.

int Rbc_ExportError(Rbc_ExportContext *exportPtr, const char *message)¶

Retain the first export failure without replacing later diagnostics.

Parameters:

  • exportPtr – Initialized, borrowed context.

  • message – Borrowed static string; it is neither copied nor freed.

Returns:

TCL_ERROR. This helper does not set the interpreter result.

void Rbc_ExportFree(Rbc_ExportContext *exportPtr)¶

Release document-local font data and the embedded DString.

Does not free the caller’s context, backendData, or an alternate buffer. The format owner must release backend resources separately. No renderer context may still be using these resources.

void Rbc_ExportAppend(Rbc_ExportContext *exportPtr, ...)¶

Append a NULL-terminated sequence of C strings to the current buffer.

The initialized context borrows buffer; callers must keep that DString alive. This helper neither checks nor clears an existing export error.

void Rbc_ExportFormat(Rbc_ExportContext *exportPtr, const char *format, ...)¶

Append printf-formatted text to the current document buffer.

Uses temporary heap storage when the local formatting buffer is too small. A formatting failure records a static export error; it does not set the Tcl result. The caller must check the context’s error before delivering output.

Graph command and traversal¶

int Rbc_InitGraphExportOptions(Graph *graphPtr, const Rbc_GraphExportFormat *format)¶

Initialize the named SVG/PDF option-database component.

Borrow the graph and format policy. Specifications must store concrete pixel or boolean values in native Graph integer fields, without retained Tk resources. The temporary option table is freed on success and failure.

Returns:

TCL_OK, or TCL_ERROR for invalid options or negative dimensions. Failure is graph-initialization failure, not a rollback transaction.

int Rbc_GraphExportOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[], const Rbc_GraphExportFormat *format)¶

Dispatch SVG/PDF cget, configure and output operations.

The enclosing widget command must preserve graph lifetime across callbacks. Requires objv[2] to exist and contain the operation. Option parsing stages all values before committing; successful output options stay configured even if rendering or file delivery later fails. Output remaps at export size, restores screen layout when callback state permits, and then delivers the complete document. Backend and shared context cleanup run on every path.

Returns:

TCL_OK or TCL_ERROR with an interpreter diagnostic.

void Rbc_ExportBeginGraph(Graph *graphPtr)¶

Mark a graph as exporting, using requested size for unset dimensions.

Requires a live Tk window. Does not perform layout or preserve old dimensions. Pair with Rbc_ExportEndGraph on all paths; this flag is not a nesting counter.

void Rbc_ExportEndGraph(Graph *graphPtr)¶

Clear export mode and schedule screen remapping if the window survives.

With a live window, replace graph dimensions by actual Tk dimensions, replace flags with MAP_WORLD and schedule redraw. Does not remap immediately or restore a saved flag set. With a destroyed window, only clear GRAPH_EXPORT.

int Rbc_ExportGraph(Graph *graphPtr, Rbc_ExportContext *exportPtr)¶

Traverse mapped graph components into an initialized document context.

Borrow both arguments; the caller owns layout, GRAPH_EXPORT state, graph lifetime, document framing and final delivery. Each temporary renderer context is ended here. Track components retain their own scope and clipping. Crosshairs are not exported. No screen geometry restoration is performed.

Returns:

TCL_OK, or TCL_ERROR on invalid callback state or a recorded export error. Successful traversal does not imply successful format finalization.
