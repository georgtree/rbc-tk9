Legend C reference¶

These private interfaces borrow graph, legend and track records. See Legend ownership and layout for ownership and ordering, and Binding dispatch and picking for event routing.

Mapping and scheduling¶

void Rbc_MapLegend(Legend *legendPtr, int width, int height)¶

Compute entry and total dimensions for one legend.

Resets cached dimensions before measuring eligible labeled elements. Hidden legends or unusable dimensions produce an empty layout. Single-row layouts use individual entry widths; multi-row layouts use uniform cells. Does not paint; placement is handled separately by the legend origin calculation.

Parameters:

  • legendPtr – Borrowed initialized legend and its owning graph.

  • width – Available plot width; an external window can override it.

  • height – Available plot height; an external window can override it.

void Rbc_MapTrackLegends(Graph *graphPtr)¶

Map local legends after full track rectangles have been laid out.

Uses full world width and height and sets each legend origin. Local legends do not contribute graph margins. Does not draw or schedule redisplay.

Parameters:

  • graphPtr – Borrowed graph with current track geometry.

void Rbc_RedrawExternalLegend(Graph *graphPtr)¶

Schedule the global external legend’s independent idle redraw.

Does nothing for an absent, resource-released or non-window legend. Coalesces pending idle work; does not draw synchronously or remap the graph.

Parameters:

  • graphPtr – Borrowed graph whose global legend may be absent.

Cleanup¶

void Rbc_ReleaseLegendTkResources(Graph *graphPtr)¶

Release global and local legend options while the Tk window is live.

Cancels pending legend redraws, frees text-style resources and the separately owned shadow color, then frees Tk options and their table. Leaves legend records and binding tables for final destruction. Repeated release is guarded.

Parameters:

  • graphPtr – Owning graph with valid track list and Tk window context.

void Rbc_DestroyTrackLegend(Graph *graphPtr, RbcTrack *track)¶

Destroy one local legend and clear its owning track pointer.

Cancels idle work and removes the legend’s tag bindings, but retains the shared track-legend binding table. Release Tk resources before window loss.

Parameters:

  • graphPtr – Owning graph; shared local binding table must still be live.

  • track – Track whose optional legend is destroyed.
