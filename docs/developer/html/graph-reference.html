Graph lifecycle C reference¶

These are private interfaces. Shared contracts live at their header declarations; static lifecycle helpers are documented next to their definitions. This section covers lifecycle callbacks, option transactions, command routing and screen composition helpers.

Shared entry points¶

void Rbc_EventuallyRedrawGraph(Graph *graphPtr)¶

Coalesce a graph redraw request into the Tcl idle queue.

If its window exists and REDRAW_PENDING is clear, queue DisplayGraph, set REDRAW_PENDING and request external-legend redraw. An unmapped window can still be queued. During axis formatting, mark the current layout invalid. Does not set geometry or backing-store dirty flags: callers set those separately. Window destruction cancels pending graph display callbacks.

Parameters:

  • graphPtr – [inout] Non-NULL graph record, valid throughout the call.

int Rbc_LayoutGraph(Graph *graphPtr)¶

Update pending axis ranges, margins and mapped component geometry.

Axis label callbacks may execute Tcl and destroy or reconfigure the widget. Stop immediately on error before using cached component pointers. This is not a transaction: some layout work may already have occurred. Small plot ranges can leave mapping pending even when TCL_OK is returned. Does not draw, schedule a redraw, or acquire a Tcl_Preserve scope for the caller.

Parameters:

  • graphPtr – [inout] Borrowed graph, kept alive by the caller.

Returns:

TCL_OK on completion; TCL_ERROR on recursive layout or callback cancellation, with an interpreter diagnostic and RBC GRAPH CALLBACK code.

int Rbc_GraphCallbackValid(Graph *graphPtr)¶

Test window existence and axis-format cancellation state.

This is not a general pointer-validity or component-lifetime test. A Tcl_Preserve scope can retain the graph record after its Tk resources have been released; it cannot make a destroyed widget usable again.

Parameters:

  • graphPtr – [in] Non-NULL graph whose storage is still alive.

Returns:

TRUE if the window exists and axisFormatInvalid is false; otherwise FALSE with an interpreter diagnostic and RBC GRAPH CALLBACK error code.

void Rbc_DrawGraph(Graph *graphPtr, Drawable drawable, int backingStore)¶

Paint mapped graph content and decorations into a borrowed drawable.

Does not perform layout or present the frame with crosshairs. May allocate or replace the backing pixmap and consume REDRAW_BACKING_STORE. Polar label formatting can cancel drawing; callers must check Rbc_GraphCallbackValid() before presenting the drawable. The caller retains graph lifetime across callbacks. Partial drawing on cancellation is not rolled back.

Parameters:

  • graphPtr – [inout] Live graph with current layout and drawing resources.

  • drawable – [in] Compatible window or pixmap in widget coordinates.

  • backingStore – [in] Nonzero to reuse/update the graph-owned plot pixmap.

Internal lifecycle callbacks¶

static void GraphEventProc(ClientData clientData, XEvent *eventPtr)¶

Translate Tk events into redraw requests and deferred destruction.

Expose/resize use ancestry-settled idle drawing; focus uses ordinary idle drawing. DestroyNotify releases window-dependent resources before clearing tkwin, deletes the widget command, cancels both display idle callbacks and schedules DestroyGraph through Tcl_EventuallyFree.

Parameters:

  • clientData – [in] Graph record registered with Tk_CreateEventHandler.

  • eventPtr – [in] Borrowed event; never retained.

static void GraphInstCmdDeleteProc(ClientData clientData)¶

Release Tk-dependent resources and destroy a command’s live window.

No-op once tkwin is NULL. Clear the borrowed window cursor before releasing option resources, then clear tkwin before Tk_DestroyWindow can reenter the destruction path. DestroyNotify schedules final record disposal.

Parameters:

  • clientData – [in] Graph record owned by the widget lifecycle.

static void DestroyGraph(DestroyData dataPtr)¶

Dispose of the graph record after outstanding preserves are released.

Destroy components in dependency order (markers/elements before tracks, axes and pens), then bindings, legend, drawing resources and the record. Normal window destruction has already released Tk-dependent options and cancelled idle work. The option cleanup fallback requires a valid tkwin. Does not accept NULL and must not be called on an actively used graph.

Parameters:

  • dataPtr – [in] Graph record transferred to this Tcl_FreeProc.

static void DisplayGraphFrame(ClientData clientData)¶

Build one screen frame after the idle request is consumed.

Clear REDRAW_PENDING even when drawing is deferred for vector notifications or skipped during axis formatting. Sample Tk dimensions and lay out before testing whether the window is mapped. Buffered drawing composes crosshairs before presentation; direct drawing uses their erase/update/enable cycle. Successful frames queue view-change events and update margin/view callbacks.

Parameters:

  • clientData – [in] Graph retained by the DisplayGraph wrapper.

static void DisplayGraph(ClientData clientData)¶

Run idle drawing with graph/interpreter lifetime and result protection.

Preserve both records and save the interpreter state around DisplayGraphFrame. Restore the interpreter state before releasing the records; do not use them after release. Preservation protects storage, not Tk resources or components that callbacks may destroy. Frame code must still validate callback state.

Parameters:

  • clientData – [in] Graph record belonging to the pending idle request.

Widget option transactions¶

static int GetGraphOptionFromObj(Tcl_Obj *objPtr, const GraphOptionName *optionMap, size_t nOptions)¶

Classify a canonical graph option through a private map.

Borrows the object and map. Unknown or ambiguous names, and options absent from the map, return zero; this helper does not report an interpreter error.

static int IsGraphOption(Tcl_Obj *objPtr, const char *optionName)¶

Compare an option spelling with one canonical graph option.

Resolves aliases and unambiguous abbreviations through graphOptionSpecs. Returns false if resolution fails; neither argument is retained.

static GraphPixelOption GetGraphPixelOption(Tcl_Obj *objPtr)¶

Identify a retained graph distance option.

Returns GRAPH_PIXEL_OPTION_NONE for other or unresolved options. The classification is used both for explicit-override masks and ordered parsing.

static Tcl_Obj *GetGraphPixelObject(Graph *graphPtr, GraphPixelOption option)¶

Borrow the retained Tcl object for a graph distance.

Does not change its reference count. The option must be a valid distance selector; invalid selectors panic rather than returning a recoverable error.

static int StageGraphPixelOption(Graph *graphPtr, Tcl_Obj *objPtr, GraphPixelOption option, GraphPixelTransaction *transactionPtr)¶

Parse one distance into a candidate transaction.

Uses the graph window for unit conversion. All distances except highlight thickness require nonnegative values; highlight thickness uses Tk conversion directly. On success sets the selected field and mask bit; on conversion error leaves that candidate unchanged and returns TCL_ERROR.

static int PrepareGraphPixelTransaction(Graph *graphPtr, GraphPixelTransaction *transactionPtr)¶

Prepare distance values without changing live numeric fields.

Requires an even borrowed option vector in the graph context. Zeroes the transaction, parses unoverridden retained defaults on first configuration, then parses every explicit occurrence in caller order. An invalid earlier occurrence fails even if a later occurrence is valid. Partial candidates on error own no resources and can be discarded.

static void CommitGraphPixelTransaction(Graph *graphPtr, GraphPixelTransaction *transactionPtr)¶

Publish only staged graph distances.

Copies selected integers into graph and margin fields, then clears the mask. No conversion, geometry request or redraw occurs here.

static GraphPaddingOption GetGraphPaddingOption(Tcl_Obj *objPtr)¶

Identify retained X or Y plot padding.

Returns GRAPH_PADDING_OPTION_NONE for other or unresolved options. The input object remains caller-owned.

static Tcl_Obj *GetGraphPaddingObject(Graph *graphPtr, GraphPaddingOption option)¶

Borrow the retained Tcl object for plot padding.

Returns the X or Y object without retaining it. Invalid selectors panic.

static int StageGraphPaddingOption(Graph *graphPtr, Tcl_Obj *objPtr, GraphPaddingOption option, GraphPaddingTransaction *transactionPtr)¶

Parse one plot-padding candidate.

Rbc_GetPadFromObj validates using the graph window. On success stores the padding and sets its mask bit; on error reports TCL_ERROR without publishing any live padding. The selector must be X or Y.

static int PrepareGraphPaddingTransaction(Graph *graphPtr, GraphPaddingTransaction *transactionPtr)¶

Prepare both plot-padding fields in caller order.

Zeroes the transaction and requires an even borrowed option vector. First configuration parses defaults only for axes without an explicit override. Every explicit occurrence is validated, including superseded ones. Partial candidates on failure require no resource cleanup.

static void CommitGraphPaddingTransaction(Graph *graphPtr, GraphPaddingTransaction *transactionPtr)¶

Publish staged plot padding and clear its mask.

Unstaged axes keep their current padding. This helper does not request layout or redraw.

static int GetGraphBarModeFromObj(Tcl_Interp *interp, Tcl_Obj *objPtr, BarMode *modePtr)¶

Parse a graph-wide bar mode with Tcl abbreviation rules.

Normal and infront map to MODE_INFRONT. Writes the destination only on success; invalid or ambiguous names return TCL_ERROR with a diagnostic.

static int StageGraphBarMode(Graph *graphPtr, Tcl_Obj *objPtr, GraphBarModeTransaction *transactionPtr)¶

Validate and retain one candidate bar mode.

Updates the transaction only after successful conversion. Neither the input object nor a resource is retained; the live mode is unchanged.

static int PrepareGraphBarModeTransaction(Graph *graphPtr, GraphBarModeTransaction *transactionPtr)¶

Prepare the graph-wide mode from defaults and explicit options.

Zeroes the transaction. On first configuration, uses the retained default only when no explicit mode occurs. Parses all explicit occurrences in order and stops at the first error; the borrowed option vector must be even.

static void CommitGraphBarModeTransaction(Graph *graphPtr, GraphBarModeTransaction *transactionPtr)¶

Publish a staged bar mode.

Leaves the live mode unchanged when unstaged and clears the staged flag after copying. No mapping or drawing is performed.

static void FreeGraphShadow(Shadow *shadowPtr)¶

Release an owned title-shadow color and reset its value.

Accepts a non-NULL Shadow record whose color may be NULL. Clears both color and offset, allowing repeated cleanup of the same record.

static int StageGraphShadow(Graph *graphPtr, Tcl_Obj *objPtr, GraphShadowTransaction *transactionPtr)¶

Acquire a replacement title shadow before discarding a candidate.

On parse failure returns TCL_ERROR and keeps the prior candidate. On success releases any previously staged shadow, owns the new color in the transaction and marks it staged. The live title style is not changed.

static void FreeGraphShadowTransaction(GraphShadowTransaction *transactionPtr)¶

Discard an uncommitted shadow candidate.

Releases its color when staged and zeroes the complete transaction. Safe for a zero-initialized or already committed transaction.

static int PrepareGraphShadowTransaction(Graph *graphPtr, GraphShadowTransaction *transactionPtr)¶

Prepare an owned shadow candidate from retained options.

Requires a fresh transaction and an even borrowed argument vector. First configuration uses the default only if not overridden. Processes explicit occurrences in order. On any conversion error releases all staged ownership and returns TCL_ERROR; success leaves cleanup or commit to the caller.

static void CommitGraphShadowTransaction(Graph *graphPtr, GraphShadowTransaction *transactionPtr)¶

Transfer the shadow candidate to the live title style.

An unstaged transaction is a no-op. Otherwise moves ownership to the graph, disarms the transaction and releases the old live shadow color.

static int StageGraphTile(Graph *graphPtr, Tcl_Obj *objPtr, GraphTileTransaction *transactionPtr)¶

Acquire a candidate tile, including an explicit empty tile.

A NULL or empty object stages NULL. A nonempty name acquires a tile client. Acquisition failure keeps the prior candidate. Success frees any earlier candidate and transfers ownership to the transaction, not the graph.

static void FreeGraphTileTransaction(GraphTileTransaction *transactionPtr)¶

Release any uncommitted tile client and zero the transaction.

Safe for a zero-initialized or committed transaction. Does not release the graph live tile.

static int PrepareGraphTileTransaction(Graph *graphPtr, GraphTileTransaction *transactionPtr)¶

Prepare a tile client from retained defaults and explicit options.

Requires a fresh transaction and an even borrowed option vector. Parses the initial default only if not overridden, then every explicit occurrence in order. Failure releases staged ownership; success requires commit or cleanup by the caller.

static void CommitGraphTileTransaction(Graph *graphPtr, GraphTileTransaction *transactionPtr)¶

Install the tile candidate and its graph-change callback.

Moves ownership to the graph and disarms the transaction before freeing the previous live tile. A staged NULL clears the tile; an unstaged transaction does nothing.

static int InitGraphOptions(Graph *graphPtr)¶

Initialize Tk-managed widget options and their database defaults.

Uses the actual widget window rather than a named component. Repeated calls after success are harmless. On Tk_InitOptions failure undefines the window cursor before freeing partially initialized options and the table. Success marks resources live but does not construct derived RBC fields.

static void ResetGraphOptionContext(Graph *graphPtr)¶

Clear borrowed configuration arguments and the active option mask.

Does not decrement object references: the argument vector is caller-owned. Used before configuration and before restoring or releasing options.

static int ConfigureGraphOptions(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[], int *maskPtr)¶

Apply Tk options and validate derived graph resources.

Requires initialized options and an even option/value vector. Exposes the borrowed original arguments only during ConfigureGraph, forcing initialization masks on the first call. Derived conversion failure clears that context and restores Tk saved options. Success frees saved options, marks the graph configured and optionally returns the Tk change mask. A successful explicit Polar aspect disables automatic aspect; a renderer change invalidates mapping and backing pixels. Rollback concerns option resources, not all auxiliary notification state touched by validation.

static int ConfigureNewGraph(Graph *graphPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Initialize widget defaults and perform the first derived configuration.

Always calls ConfigureGraphOptions, including with zero arguments. Polar uses automatic data-unit aspect only when the option database supplies no aspect; a successful explicit aspect overrides that policy. Returns TCL_ERROR on initialization or configuration failure; creation owns graph cleanup.

static void ReleaseGraphOptionResources(Graph *graphPtr)¶

Release Tk-owned options while the graph window remains valid.

No-op before initialization or after release. Clears borrowed transaction context, frees options and deletes the table. Derived GCs, shadow and tile remain owned by the graph destruction path.

static int ConfigureGraph(Graph *graphPtr)¶

Validate retained graph values, then commit derived resources.

Requires initialized options and active configuration context. Validates track options, renderer availability and finite aspect, bar width and baseline, then prepares distance, padding, mode, shadow and tile candidates. Reportable conversion errors precede commits; owned candidates are freed on failure. After commit normalizes nonpositive bar width, updates geometry and GCs, reconfigures text and crosshairs, invalidates affected caches and schedules redraw. Tk option rollback belongs to ConfigureGraphOptions; auxiliary track notification bookkeeping is not part of these candidate transactions.

Commands and screen composition¶

static int XAxisOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch the X margin-axis operation.

Uses the bottom margin normally and the left margin when inverted. Borrows the original argument vector and returns Rbc_AxisOp status unchanged; axis lookup, mutation and result construction belong to that dispatcher.

static int X2AxisOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch the secondary X margin-axis operation.

Uses the top margin normally and the right margin when inverted. Borrows the original argument vector and returns Rbc_AxisOp status unchanged; axis lookup, mutation and result construction belong to that dispatcher.

static int YAxisOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch the Y margin-axis operation.

Uses the left margin normally and the bottom margin when inverted. Borrows the original argument vector and returns Rbc_AxisOp status unchanged; axis lookup, mutation and result construction belong to that dispatcher.

static int Y2AxisOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch the secondary Y margin-axis operation.

Uses the right margin normally and the top margin when inverted. Borrows the original argument vector and returns Rbc_AxisOp status unchanged; axis lookup, mutation and result construction belong to that dispatcher.

static int BarOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a bar operation through the shared element interface.

Passes rbcBarElementUid as the element class with the original borrowed arguments. Returns the element dispatcher status unchanged; does not acquire an element reference or perform drawing itself.

static int StripOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a strip operation through the shared element interface.

Passes rbcStripElementUid as the element class with the original borrowed arguments. Returns the element dispatcher status unchanged; does not acquire an element reference or perform drawing itself.

static int LineOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a line operation through the shared element interface.

Passes rbcLineElementUid as the element class with the original borrowed arguments. Returns the element dispatcher status unchanged; does not acquire an element reference or perform drawing itself.

static int ElementOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a default element operation through the shared element interface.

Passes graphPtr->classUid as the element class with the original borrowed arguments. Returns the element dispatcher status unchanged; does not acquire an element reference or perform drawing itself.

static int ConfigureOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Query option metadata or configure the graph.

With two arguments returns all Tk option descriptions; with three returns one description. Longer calls delegate option/value pairs to ConfigureGraphOptions. Requires initialized options; returns TCL_ERROR on lookup or configuration failure.

static int CgetOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Return one Tk-managed option value.

Requires initialized options and dispatcher-validated arity. Installs the value as the interpreter result, or propagates a Tk lookup error. Does not convert retained values into derived graph fields.

static int ExtentsOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Report cached plot, margin or legend geometry.

Accepts Tcl unambiguous abbreviations. Plot area and legend return x, y, width and height; other selectors return one integer. Plot dimensions use inclusive endpoints. Does not perform layout; invalid selectors return TCL_ERROR rather than unconditional success.

static int InsideOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Test a window point against the graph plotting extents.

Converts both coordinates through Tk screen-distance parsing and returns a Tcl boolean. Conversion errors propagate. Uses current graph extents without laying out pending geometry; it does not select an individual track.

static int InvtransformOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Map a window point to the first logical X/Y axis pair.

Evaluates both coordinates as Tcl expressions, synchronizes element vectors and resets dirty ranges, then returns two doubles. Does not perform full margin layout. Checks widget validity after each expression before accessing graph resources, and rejects nonfinite input coordinates.

static int TransformOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Map a data point to rounded integer window coordinates.

Evaluates Tcl expressions, synchronizes element vectors and resets dirty ranges before selecting the first logical X/Y axis pair. Checks validity after each expression and rejects nonfinite input or out-of-range rounded output before integer conversion. Does not perform full layout. Trackgraphs are rejected by the enclosing dispatcher.

static int SnapGraph(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Render the graph to a photo or a Windows metafile target.

Parses paired format and integer size options; sizes below two use the current Tk window dimension. Temporarily assigns graph dimensions, requests layout and draws without the element backing store. Photo output owns a temporary pixmap and releases it after capture or callback cancellation. Windows output owns a recording DC and metafile; CLIPBOARD requests transfer of the metafile to the system. The enclosing SnapOp restores screen dimensions and invalidates temporary geometry on every return, including capture errors.

static int SnapOp(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Capture a snapshot and restore screen geometry on every return path.

Keep pre-existing dirty and idle-request flags. Restoration preserves the capture error when capture failed, and reports layout failure otherwise. A deleted window is never used for restoration or redraw scheduling.

static Rbc_GraphOpProc *GetGraphOpFromObj(Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Resolve a widget operation and validate its argument count.

Uses the shared operation-table dispatcher at argument one. Returns a borrowed static procedure pointer, or NULL with a Tcl diagnostic. Does not execute the operation or retain any arguments.

int Rbc_GraphInstCmdProc(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Dispatch a graph widget command under graph preservation.

Rejects widget-wide transforms for trackgraphs and recursive snapshot or document output during axis formatting. Preserves the Graph allocation across the selected handler, then releases it and returns the handler status. Preservation does not keep the Tk window or separately owned components alive; handlers crossing Tcl callbacks still need validity checks.

static int NewGraph(Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[], Rbc_Uid classUid)¶

Create a widget and return its Tk pathname.

Requires a pathname argument, then delegates construction to CreateGraph. On failure propagates TCL_ERROR; on success installs a new pathname string as the result. The created graph belongs to the widget lifecycle.

static int GraphObjCmd(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create a graph widget through the common constructor.

Passes rbcLineElementUid to NewGraph and returns its Tcl status unchanged. The clientData argument is unused; construction owns the new widget resources.

static int BarchartObjCmd(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create a barchart widget through the common constructor.

Passes rbcBarElementUid to NewGraph and returns its Tcl status unchanged. The clientData argument is unused; construction owns the new widget resources.

static int StripchartObjCmd(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create a stripchart widget through the common constructor.

Passes rbcStripElementUid to NewGraph and returns its Tcl status unchanged. The clientData argument is unused; construction owns the new widget resources.

static int PolarObjCmd(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create a polar widget through the common constructor.

Passes rbcPolarElementUid to NewGraph and returns its Tcl status unchanged. The clientData argument is unused; construction owns the new widget resources.

static void FillMarginRectangle(Graph *graphPtr, Drawable drawable, int x, int y, int width, int height)¶

Fill one positive-sized margin rectangle.

Borrows the drawable and graph resources. Uses the tile when present, otherwise the margin fill GC, through the screen renderer. Nonpositive width or height is a no-op; this helper does not set tile origin.

static void DrawMargins(Graph *graphPtr, Drawable drawable)¶

Paint margins, the plot border, margin legend, title and axes.

Sets tile origin to the widget origin, fills four surrounding rectangles, then draws decorations in that order. Uses current mapped geometry and borrowed resources. Opens and closes a screen-text context for the title; does not recompute layout or present the drawable.

static void DrawPlotRegion(Graph *graphPtr, Drawable drawable)¶

Compose the cacheable plot layer in drawing order.

Clears the inclusive plot rectangle, draws track separators and grids, then Polar or Smith labels. After checking callback validity, draws under markers, lowered local/global legends, axis limits and ordinary elements. Borrows the drawable and mapped geometry. A void return does not indicate callback success; callers must check Rbc_GraphCallbackValid.

static int UpdateMarginTraces(Graph *graphPtr)¶

Publish cached margin dimensions to global Tcl variables.

Writes left/right widths and top/bottom heights for configured variables. Copies names and sizes before invoking traces so configuration changes cannot invalidate borrowed option strings. Stops writes and returns false if a trace destroys the widget or cancels layout. Assignment errors remain ignored for compatibility. The display wrapper preserves graph and interpreter storage.

static int TrackgraphObjCmd(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Create a trackgraph widget through the common constructor.

Passes trackGraphUid to NewGraph and returns its Tcl status unchanged. The clientData argument is unused; construction owns the new widget resources.

Construction and redraw support¶

static void FreeGraphRedrawSettle(Graph *graphPtr)¶

Release the pending ancestry-sampling record.

Frees the owned sample array and record, then clears redrawSettle. A NULL record is harmless. Does not cancel an idle call or clear REDRAW_PENDING; the caller must handle scheduling state separately.

static void SettleGraphRedraw(ClientData clientData)¶

Wait for two unchanged ancestry samples before presenting a frame.

Requires the graph-owned redrawSettle record installed by EventuallyRedrawSettledGraph. Samples window identity, position, size and border from the widget through its toplevel; reallocates samples when the ancestry length changes. Changed geometry resets the stable-pass count. Requeues itself until two unchanged passes, then frees samples and delegates to DisplayGraph, which consumes REDRAW_PENDING. A dead window frees samples and clears the pending flag without drawing. Does not enter an event loop.

static void EventuallyRedrawSettledGraph(Graph *graphPtr)¶

Replace ordinary idle drawing with ancestry-settled drawing.

Does nothing for a dead window or an already active settle request. Cancels a pending DisplayGraph call, allocates a fresh sampling record, sets REDRAW_PENDING and schedules SettleGraphRedraw. Also requests external legend redraw. Callers set geometry and drawing invalidation flags themselves.

static void GraphWorldChanged(ClientData clientData)¶

Refresh derived font resources after a Tk world change.

Ignores dead or not-yet-configured graphs. Resets title style and height, notifies axes, legends, markers, line and bar elements of font changes, then invalidates geometry and backing pixels and schedules redraw. Does not reparse option objects or deliberately evaluate application scripts.

static void TileChangedProc(ClientData clientData, Rbc_Tile tile)¶

Request margin redisplay when the graph tile changes.

The tile argument is unused. For a live window sets REDRAW_WORLD and schedules drawing; a dead window is ignored. Does not rebuild a GC or replace the tile client, whose ownership belongs to graph configuration.

static void AdjustAxisPointers(Graph *graphPtr)¶

Associate logical axis chains with physical margins.

Borrows the four existing chains. Normal order maps X/Y/X2/Y2 to bottom/left/top/right; inversion maps them to left/bottom/right/top. Does not change chain contents, axis classes, reference counts or axis sites, and does not itself invalidate geometry.

static int InitPens(Graph *graphPtr)¶

Initialize the pen registry and create default active pens.

Creates activeLine and activeBar in that order. Returns TCL_ERROR if either creation fails, retaining any already-created pen for graph teardown. Must run once on a new graph; does not roll back the registry locally.

static Graph *CreateGraph(Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[], Rbc_Uid classUid)¶

Allocate a graph widget and install its components and lifecycle.

Requires a pathname at objv[1]. Creates the Tk window, zeroed Graph, registries and display lists after creating the anonymous option proxy. Trackgraphs retain a distinct Tk class and trackGraph flag but use the line element class. Installs window instance data, class procedures, widget command and event handler before component configuration. Creates pens, axes, exporters, crosshairs, legend and grid before applying widget options, and creates bindings last. Success returns a widget-owned Graph; failure returns NULL with the interpreter error and destroys the window. Anonymous-window failure destroys the parent before any Graph storage is allocated and preserves the original interpreter error; later failures use the installed event handler.

int Rbc_GraphInit(Tcl_Interp *interp)¶

Intern component class identifiers and register graph constructors.

Creates graph, barchart, stripchart, polar and trackgraph Tcl commands in the interpreter. Initializes class identifiers including the contour identifier, but does not register a contour widget constructor. Returns TCL_OK; no graph widget is created here.

Graph *Rbc_GetGraphFromWindowData(Tk_Window tkwin)¶

Find graph instance data on a window or its ancestors.

Walks Tk_Parent until non-NULL RBC window instance data is found. Returns a borrowed Graph pointer, or NULL when the chain is empty. Does not retain the graph or verify a component class; callers must supply a window chain whose RBC instance data follows the graph convention.

struct GraphGeometrySample¶

One borrowed window identity and its sampled integer geometry.

The window handle is compared with the current ancestry, not retained or dereferenced through this record. The settle owner owns the sample array.

struct GraphRedrawSettle¶

Graph-owned state for coalescing geometry-manager idle work.

Owns count sample records; stablePasses counts consecutive unchanged samples. REDRAW_PENDING represents the scheduled work separately.
