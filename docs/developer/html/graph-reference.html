Graph lifecycle C reference¶

These are private interfaces. Shared contracts live at their header declarations; static lifecycle helpers are documented next to their definitions. This section covers lifecycle callbacks, option transactions, command routing and screen composition helpers.

Widget ownership and layout records¶

typedef struct GraphStruct Graph¶
struct GraphStruct¶

Shared widget owner for graph, bar, strip, polar and track plots.

Graph is the typedef for this record. It owns component registries, layout and screen caches. Tcl callbacks can destroy the Tk window before deferred record cleanup; borrowed interp/display pointers do not extend their lifetime.

Shared entry points¶

void Rbc_EventuallyRedrawGraph(Graph *graphPtr)¶

Coalesce a graph redraw request into the Tcl idle queue.

If its window exists and REDRAW_PENDING is clear, queue DisplayGraph, set REDRAW_PENDING and request external-legend redraw. An unmapped window can still be queued. During axis formatting, mark the current layout invalid. Does not set geometry or backing-store dirty flags: callers set those separately. Window destruction cancels pending graph display callbacks.

Parameters:

  • graphPtr – [inout] Non-NULL graph record, valid throughout the call.

int Rbc_LayoutGraph(Graph *graphPtr)¶

Update pending axis ranges, margins and mapped component geometry.

Axis label callbacks may execute Tcl and destroy or reconfigure the widget. Stop immediately on error before using cached component pointers. This is not a transaction: some layout work may already have occurred. Small plot ranges can leave mapping pending even when TCL_OK is returned. Does not draw, schedule a redraw, or acquire a Tcl_Preserve scope for the caller.

Parameters:

  • graphPtr – [inout] Borrowed graph, kept alive by the caller.

Returns:

TCL_OK on completion; TCL_ERROR on recursive layout or callback cancellation, with an interpreter diagnostic and RBC GRAPH CALLBACK code.

int Rbc_GraphCallbackValid(Graph *graphPtr)¶

Test window existence and axis-format cancellation state.

This is not a general pointer-validity or component-lifetime test. A Tcl_Preserve scope can retain the graph record after its Tk resources have been released; it cannot make a destroyed widget usable again.

Parameters:

  • graphPtr – [in] Non-NULL graph whose storage is still alive.

Returns:

TRUE if the window exists and axisFormatInvalid is false; otherwise FALSE with an interpreter diagnostic and RBC GRAPH CALLBACK error code.

void Rbc_DrawGraph(Graph *graphPtr, Drawable drawable, int backingStore)¶

Paint mapped graph content and decorations into a borrowed drawable.

Does not perform layout or present the frame with crosshairs. May allocate or replace the backing pixmap and consume REDRAW_BACKING_STORE. Polar label formatting can cancel drawing; callers must check Rbc_GraphCallbackValid() before presenting the drawable. The caller retains graph lifetime across callbacks. Partial drawing on cancellation is not rolled back.

Parameters:

  • graphPtr – [inout] Live graph with current layout and drawing resources.

  • drawable – [in] Compatible window or pixmap in widget coordinates.

  • backingStore – [in] Nonzero to reuse/update the graph-owned plot pixmap.

Internal lifecycle callbacks¶

static void GraphEventProc(ClientData clientData, XEvent *eventPtr)¶

Translate Tk events into redraw requests and deferred destruction.

Expose/resize use ancestry-settled idle drawing; focus uses ordinary idle drawing. DestroyNotify releases window-dependent resources before clearing tkwin, deletes the widget command, cancels both display idle callbacks and schedules DestroyGraph through Tcl_EventuallyFree.

Parameters:

  • clientData – [in] Graph record registered with Tk_CreateEventHandler.

  • eventPtr – [in] Borrowed event; never retained.

static void GraphInstCmdDeleteProc(ClientData clientData)¶

Release Tk-dependent resources and destroy a command’s live window.

No-op once tkwin is NULL. Clear the borrowed window cursor before releasing option resources, then clear tkwin before Tk_DestroyWindow can reenter the destruction path. DestroyNotify schedules final record disposal.

Parameters:

  • clientData – [in] Graph record owned by the widget lifecycle.

static void DestroyGraph(DestroyData dataPtr)¶

Dispose of the graph record after outstanding preserves are released.

Destroy components in dependency order (markers/elements before tracks, axes and pens), then bindings, legend, drawing resources and the record. Normal window destruction has already released Tk-dependent options and cancelled idle work. The option cleanup fallback requires a valid tkwin. Does not accept NULL and must not be called on an actively used graph.

Parameters:

  • dataPtr – [in] Graph record transferred to this Tcl_FreeProc.

static void DisplayGraphFrame(ClientData clientData)¶

Build one screen frame after the idle request is consumed.

Clear REDRAW_PENDING even when drawing is deferred for vector notifications or skipped during axis formatting. Sample Tk dimensions and lay out before testing whether the window is mapped. Buffered drawing composes crosshairs before presentation; direct drawing uses their erase/update/enable cycle. Successful frames queue view-change events and update margin/view callbacks.

Parameters:

  • clientData – [in] Graph retained by the DisplayGraph wrapper.

static void DisplayGraph(ClientData clientData)¶

Run idle drawing with graph/interpreter lifetime and result protection.

Preserve both records and save the interpreter state around DisplayGraphFrame. Restore the interpreter state before releasing the records; do not use them after release. Preservation protects storage, not Tk resources or components that callbacks may destroy. Frame code must still validate callback state.

Parameters:

  • clientData – [in] Graph record belonging to the pending idle request.

static int StageGraphPixelOption(Graph *graphPtr, Tcl_Obj *objPtr, GraphPixelOption option, GraphPixelTransaction *transactionPtr)¶

Parse one distance into a candidate transaction.

Uses the graph window for unit conversion. All distances except highlight thickness require nonnegative values; highlight thickness uses Tk conversion directly. On success sets the selected field and mask bit; on conversion error leaves that candidate unchanged and returns TCL_ERROR.

Parameters:

  • graphPtr – [in] Borrowed widget-owned graph; required configuration or mapping state is described above.

  • objPtr – [in] Borrowed proposed option value; parsed before replacing the candidate.

  • option – [in] Valid selector identifying the distance or padding field to access.

  • transactionPtr – [inout] Initialized candidate record updated only after successful parsing; retains prior candidate on failure.

static int PrepareGraphPixelTransaction(Graph *graphPtr, GraphPixelTransaction *transactionPtr)¶

Prepare distance values without changing live numeric fields.

Requires an even borrowed option vector in the graph context. Zeroes the transaction, parses unoverridden retained defaults on first configuration, then parses every explicit occurrence in caller order. An invalid earlier occurrence fails even if a later occurrence is valid. Partial candidates on error own no resources and can be discarded.

Parameters:

  • graphPtr – [in] Borrowed widget-owned graph; required configuration or mapping state is described above.

  • transactionPtr – [out] Caller-owned fresh candidate record, initialized here; success requires commit or cleanup as described above.

static void CommitGraphPixelTransaction(Graph *graphPtr, GraphPixelTransaction *transactionPtr)¶

Publish only staged graph distances.

Copies selected integers into graph and margin fields, then clears the mask. No conversion, geometry request or redraw occurs here.

Parameters:

  • graphPtr – [inout] Borrowed widget-owned graph; required configuration or mapping state is described above.

  • transactionPtr – [inout] Prepared candidate record consumed into live fields and disarmed; record storage remains caller-owned.

static int PrepareGraphShadowTransaction(Graph *graphPtr, GraphShadowTransaction *transactionPtr)¶

Prepare an owned shadow candidate from retained options.

Requires a fresh transaction and an even borrowed argument vector. First configuration uses the default only if not overridden. Processes explicit occurrences in order. On any conversion error releases all staged ownership and returns TCL_ERROR; success leaves cleanup or commit to the caller.

static void CommitGraphShadowTransaction(Graph *graphPtr, GraphShadowTransaction *transactionPtr)¶

static int StageGraphTile(Graph *graphPtr, Tcl_Obj *objPtr, GraphTileTransaction *transactionPtr)¶

Acquire a candidate tile, including an explicit empty tile.

A NULL or empty object stages NULL. A nonempty name acquires a tile client. Acquisition failure keeps the prior candidate. Success frees any earlier candidate and transfers ownership to the transaction, not the graph.

Parameters:

  • objPtr – [in] Borrowed proposed image name; NULL or an empty object explicitly stages no tile.

  • transactionPtr – [inout] Initialized candidate record updated only after successful parsing; retains prior candidate on failure.

Initialize Tk-managed widget options and their database defaults.

Uses the actual widget window rather than a named component. Repeated calls after success are harmless. On Tk_InitOptions failure undefines the window cursor before freeing partially initialized options and the table. Success marks resources live but does not construct derived RBC fields.

Parameters:

The checksum XORs ten little-endian 16-bit words, excluding the checksum itself; no unaligned integer reads occur. Returns TCL_OK or TCL_ERROR with an interpreter diagnostic.

Parameters:

  • interp – [inout] Borrowed result interpreter; see Interpreter arguments.

  • tkwin – [in] Borrowed live window supplying screen pixel and millimeter dimensions.

  • width – [in] Positive snapshot width in pixels.

  • height – [in] Positive snapshot height in pixels.

  • mfhPtr – [out] Required packed header storage, assigned only on success.

static int CreateAPMetaFile(Tcl_Interp *interp, HANDLE hMetaFile, HDC hDC, APMHEADER *mfhPtr, const char *fileName)¶

Convert a borrowed enhanced metafile and write a placeable WMF file.

Validates both native conversion calls and the global-memory lock before opening the destination. Owns and releases the temporary memory and file; does not consume the metafile or reference DC. Conversion failure leaves an existing destination untouched. Write failure may leave a partial file. Returns TCL_OK after both writes, or TCL_ERROR with a native diagnostic.

Parameters:

  • interp – [inout] Borrowed result interpreter; see Interpreter arguments.

  • hMetaFile – [in] Borrowed non-NULL enhanced metafile to convert.

  • hDC – [in] Borrowed reference DC used for MM_ANISOTROPIC conversion.

  • mfhPtr – [in] Borrowed initialized packed placeable header.

  • fileName – [in] Borrowed NUL-terminated native ANSI pathname for CreateFileA.
