Vector command C reference¶

Selected private handlers and helpers from rbcVecCmd.c. See Vector instance commands and binary input for dispatch, partial updates and callback limitations.

group Vector instance command paths

Selected private mutation and input helpers; see the developer manual for partial-update and callback lifetime limitations.

Functions

static int AppendOp(VectorObject *vPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Append vector ranges or Tcl lists in argument order.

Vector lookup precedes list conversion. Earlier arguments remain appended if a later argument fails. Reports the appended range when length grew, including the error path; otherwise successful calls report a full update. Flushes the mapped cache when configured. Notification may execute callbacks.

static Tcl_Size ParseFormat(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const *objv, void *dstPtr)¶

Select a supported native scalar type from a format and byte width.

Floating, signed and unsigned formats resolve against native C sizeof values. Returns the consumed argument count, or -1 on error. This is host representation, not a portable serialized type description; conversion to double may lose integer precision.

static Tcl_Size ParseAt(void *clientData, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const *objv, void *dstPtr)¶

Parse a binary-input starting storage position.

Uses vector index conversion, allowing positions from zero through length inclusive. Returns the consumed argument count, or -1 on error. Index expressions may evaluate Tcl.

static int BinreadOp(VectorObject *vPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Read native-format channel scalars into vector storage.

Retains a readable channel, temporarily sets binary translation, and restores the saved translation if the caller has not closed the channel. Real values use one scalar, complex values two interleaved scalars. A positive count performs one read; zero reads chunks until EOF or a zero-byte read. Rejects incomplete values rather than buffering partial records. Completed chunks remain on error and trigger cache flushing/notification while preserving the original error state. Success reports logical value count. Checks destination lifetime/read-only state and channel registration after reflected reads. The dispatcher retains the vector.

static int SetOp(VectorObject *vPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Replace values from a vector range or Tcl list.

Stages vector ranges (including self-copy) or converted list values before replacing storage. Failed conversion does not write destination data. Tcl callbacks retain their own side effects. Flushes/notifies only a still-live committed object; callbacks cannot redirect the operation by recreating a name.

static int SortOp(VectorObject *vPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Sort real values and apply their permutation to companion vectors.

Retains resolved destination identities and validates all keys before any write. Reuses one scratch array to apply the permutation without callbacks; only then flushes and notifies surviving objects. Notifications may alter or destroy committed vectors, but never expose a partially applied permutation.

static int AppendVector(VectorObject *destPtr, VectorObject *srcPtr)¶

Append a selected vector range without Tcl-list conversion.

Requires matching real/complex types. Saves source selection before resize and uses memmove against current storage, permitting self-append. Checks length/byte arithmetic. Returns a Tcl status; does not flush or notify.

static int AppendList(VectorObject *vPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Stage list values before appending the completed list.

Converts a complete list into temporary storage and rechecks lifetime and writable state after conversion. Appends to the current length, accounting for callback edits. Conversion failure does not append a partial list. Does not flush or notify; the instance dispatcher retains the destination.

static int CopyValues(VectorObject *vPtr, char *byteArr, enum NativeFormats fmt, int size, Tcl_Size length, int swap, Tcl_Size *indexPtr)¶

Convert a binary scalar buffer into real vector storage.

Checks writable state, range and size arithmetic, extends storage as needed, and advances indexPtr. Optional byte swapping modifies the input buffer in place per scalar. Returns a Tcl status; does not flush or notify.

static int CopyComplexValues(VectorObject *vPtr, char *byteArr, enum NativeFormats fmt, int size, Tcl_Size length, int swap, Tcl_Size *indexPtr)¶

Convert interleaved binary components into complex storage.

Requires a complex vector. Checks writable state and size arithmetic; extends storage and advances indexPtr by logical values. Swaps bytes within each scalar component, never exchanging real and imaginary components. Modifies the input buffer when swapping; does not flush or notify.

static int CopyList(VectorObject *vPtr, Tcl_Size objc, Tcl_Obj *const objv[])¶

Convert a complete Tcl list before replacing vector storage.

Returns a Tcl status. Conversion failure leaves destination values/length unchanged except for the callbacks’ own changes. Transfers staged storage on success, with lifetime/read-only checks before commit. Does not notify; callers retain the destination and interpreter through callbacks.
