Native backend C reference¶

These declarations in rbcRenderNative.h are private backend services. Components use rbcRender.h instead. See Native renderer internals for platform behavior and ownership that cannot be inferred from a function signature.

Trace batches¶

Rbc_NativeTrace *Rbc_NativeBeginTrace(Graph*, Drawable, GC)¶

Allocate a reusable native polyline batch.

Borrows graph, drawable and configured GC until Rbc_NativeEndTrace. Owns point workspace; Windows also acquires a DC and selects owned pen/brush resources for the batch. Geometry supplied to subsequent calls is consumed synchronously. This is a backend service, not a component constructor.

Returns:

Owned context, or NULL when request capacity or allocation prevents it.

void Rbc_NativeEndTrace(Rbc_NativeTrace*)¶

Release a native trace batch; NULL is accepted.

Windows restores the previously selected pen/brush before deleting the batch-owned objects and releasing its DC state. Frees context/workspace without freeing the borrowed GC, drawable or graph.

Clip stacks¶

Rbc_NativeClip *Rbc_NativeCreateClip(Graph*, Drawable, GC, int)¶

Create a native rectangular clip stack without pushing a clip.

Borrows graph, base drawable and any supplied copy GC. A missing copy GC is acquired lazily and owned by the stack. A nonzero final argument permits platform DC clipping; otherwise use scratch targets. Keep graph dimensions stable while the stack is live: scratch pixmaps are cached per nesting depth.

Returns:

Owned stack, to be released with Rbc_NativeDestroyClip.

void Rbc_NativePushClip(Rbc_NativeClip*, int, int, int, int)¶

Push an intersection with the parent clip and graph drawable bounds.

Arguments after the stack are x, y, width and height in absolute widget pixels. Nonpositive sizes create an empty frame. Query Rbc_NativeClipDrawable after every push; None means empty or failed output, and drawing must be skipped. Every push still requires a pop. A scratch target is seeded from its parent and preserves absolute coordinates.

void Rbc_NativePopClip(Rbc_NativeClip*)¶

Finish the active clip and restore its parent target.

Copies the visible scratch rectangle back, or restores/releases platform DC state. An empty stack is a no-op. Frame/workspace allocations are retained for reuse until destruction; borrowed drawables are not freed.

void Rbc_NativeDestroyClip(Rbc_NativeClip*)¶

Unwind and free a live native clip stack.

Pops remaining frames (committing their output), frees all cached scratch pixmaps and frame records, and releases only an internally acquired copy GC. Requires a non-NULL stack and live borrowed graph/display resources.

Shared drawing implementation¶

The source contracts below describe conversion, temporary storage, GC mutations and fallback behavior. These helpers consume mapped geometry; they do not own component resources or perform graph layout.

group Shared native drawing helpers

Private backend services operating on already mapped geometry.

Functions

static void DrawSegments(Display *display, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size nSegments)¶

Draw independent segments in bounded X requests.

Borrows the display, drawable, GC and input array. Ignores absent display/ segments or nonpositive counts. Allocates one request-sized XSegment buffer; clips endpoints to signed-short protocol bounds before truncating to short. Returns without drawing if capacity or allocation fails; frees workspace. This protocol clipping does not replace the owning component plot clip.

static void Fill3DRectangle(Tk_Window tkwin, Drawable drawable, Tk_3DBorder border, int x, int y, int width, int height, int borderWidth, int relief)¶

Fill a rectangle with the historical native relief adjustment.

Borrows the window and border. For raised/sunken borders wider than one pixel and rectangles larger than two pixels, draws the outer four lines, shrinks the rectangle and delegates the remainder to Tk. X11 uses the default GC for one outer shade; Windows uses the corresponding border GC. Does not allocate or release the borrowed border GCs.

void Rbc_NativeText(Tk_Window tkwin, Drawable drawable, const char *string, TextStyle *style, int x, int y)¶

Draw text through the existing Tk-based text service.

Borrows string and style for the call. Retains native font selection, rotation, anchors, padding and active/disabled styling in Rbc_DrawText. No text resource is retained by this wrapper.

void Rbc_NativeTextLayout(Tk_Window tkwin, Drawable drawable, TextLayout *layout, TextStyle *style, int x, int y)¶

Draw an already constructed text layout.

Borrows layout and style; delegates to Rbc_DrawTextLayout without rebuilding or freeing the cached layout.

void Rbc_NativeTextSize(Tk_Window tkwin, Drawable drawable, const char *string, TextStyle *style, int x, int y, Dim2D *size)¶

Draw text and return its rotated dimensions.

Delegates to Rbc_DrawText2 using borrowed text/style and caller-provided size storage. Axis-limit placement uses these dimensions for later labels.

void Rbc_NativeBitmap(Graph *graphPtr, Drawable drawable, const Rbc_RenderRectangle *r, const Rbc_RenderBitmapStyle *style)¶

Paint a mapped bitmap and optional background polygon.

Borrows mapped rectangle and style resources. Converts the supplied bounded background point array to short coordinates and fills it as Convex. Installs the bitmap mask and destination-relative clip origin on the private bitmap GC, then copies plane one. Leaves that clip state installed; does not retain or free bitmap/mask resources. Caller must honor the fixed outline capacity.

void Rbc_NativeImage(Drawable drawable, Tk_Image image, int x, int y)¶

Redraw a complete Tk image at a mapped position.

Queries the borrowed image size and delegates image-type drawing and alpha handling to Tk_RedrawImage. Does not scale, retain or free the image.

void Rbc_NativeCopyArea(Tk_Window tkwin, Drawable source, Drawable destination, GC gc, int srcX, int srcY, unsigned int width, unsigned int height, int dstX, int dstY)¶

Copy a native drawable rectangle using the supplied GC.

Borrows both drawables, window and GC; passes source/destination coordinates and unsigned dimensions to XCopyArea. Does not change the supplied GC or introduce a separate plot clip.

void Rbc_NativePixmap(Graph *graphPtr, Drawable drawable, Pixmap pixmap, GC gc, const Rbc_RenderRectangle *r)¶

Copy a pixmap from its origin into a mapped rectangle.

Borrows graph, pixmap and GC. Uses rectangle dimensions and destination position with Rbc_NativeCopyArea; the pixmap is neither scaled nor freed.

void Rbc_NativeBorder(Tk_Window tkwin, Drawable drawable, Tk_3DBorder border, int x, int y, int width, int height, int borderWidth, int relief, int fill)¶

Draw or fill a native relief border.

The fill flag chooses Fill3DRectangle; otherwise uses Rbc_Draw3DRectangle. Borrows window/border and preserves the two paths’ different fill semantics. Decorations may use this service even when element geometry uses Cairo.

void Rbc_NativeRectangle(Tk_Window tkwin, Drawable drawable, GC gc, Rbc_Tile tile, int x, int y, int width, int height)¶

Fill a native rectangle with a tile or the supplied GC.

A non-NULL borrowed tile takes precedence and uses Rbc_TileRectangle with its existing origin. Otherwise calls XFillRectangle after converting sizes to unsigned integers. Callers supply valid nonnegative dimensions.

void Rbc_NativeFocus(Tk_Window tkwin, Drawable drawable, GC gc, int width)¶

Draw the Tk focus highlight.

Borrows the live window and configured GC; delegates width handling and painting to Tk_DrawFocusHighlight.

void Rbc_NativeSegments(Graph *graphPtr, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size count)¶

Draw graph segments through the shared bounded segment helper.

Borrows graph, drawable, GC and mapped segments. DrawSegments owns temporary conversion storage and handles protocol clipping and request batching.

static int Round(double x)¶

Round a representable symbol coordinate away from zero at ties.

Adds or subtracts one half before conversion to int. Requires a finite value whose adjusted result fits int; this is not a general range check.

void Rbc_NativeSymbolPoints(Graph *graphPtr, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, int size, Tcl_Size nSymbolPts, const Point2D *symbolPts)¶

Draw mapped symbol centers using native shape batches.

Borrows graph, points and style resources; shape-specific temporary buffers and scaled bitmaps are released before return. For size below three, draws all centers as points with fillGC and bypasses symbol type/interval handling. Larger symbols use circle/square platform batches, segment crosses, polygon templates or scaled bitmaps. Interval-aware branches advance style->counter for examined centers, including skipped ones. Bitmap symbols mutate outline GC clip state. Requires valid mapped coordinates and a nonnegative count.

void Rbc_NativeFillPolygon(Graph *graphPtr, Drawable drawable, GC gc, Rbc_Tile tile, Pixmap stipple, const Point2D *points, Tcl_Size count)¶

Fill a tiled or stippled native polygon.

Rejects absent points, unavailable tile pixmaps and unsupported point counts. Owns temporary short-coordinate points. A tile takes precedence and its origin is reset through Rbc_SetTileOrigin before drawing. Otherwise a non-None stipple selects Complex XFillPolygon using the already configured GC. With neither tile nor stipple this helper intentionally draws nothing.

void Rbc_NativeBars(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, const Rbc_RenderRectangle *rectangles, Tcl_Size nRects)¶

Fill mapped bar rectangles, then draw relief borders.

Borrows graph, style and rectangles. Positive fillOpacity enables native filling; this helper does not alpha-blend fractional opacity. Packs eligible rectangles into request-sized XRectangle batches, flushing before wider int-argument fallback calls. Attempts platform border batching before per-rectangle relief fallback. Allocation/capacity failure in the fill path returns before borders. Requires valid mapped geometry and configured GCs.

void Rbc_NativeArcStroke(Graph *graphPtr, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size count)¶

Join contiguous arc segments into native polylines.

Requires nonnegative count, valid mapped segments and representable sizes. Zero count is a no-op. Exact endpoint equality joins adjacent segments; gaps start separate XDrawLines calls. Owns point and per-run XPoint buffers, with short-coordinate conversion. Outer allocation failure skips all drawing; per-run failure skips that run. Unlike DrawSegments, does not protocol-clip or split a run to the X request-size limit.

Drawable Rbc_NativeClipDrawable(Rbc_NativeClip *clip)¶

Return the active clip target or the base drawable.

Requires a live non-NULL stack. None means the active frame is empty or failed; callers must skip drawing but still pop that frame. The target is borrowed and must not outlive its frame/stack.

void Rbc_NativeScreenSegments(Tk_Window tkwin, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size count)¶

Draw independent native segments without a Graph argument.

Uses the borrowed window display and the same DrawSegments conversion, protocol clipping, temporary storage and request batching as graph segments.

void Rbc_NativeArrowHead(Graph *graphPtr, Drawable drawable, GC gc, const Point2D *arrow)¶

Scan-convert a five-vertex arrowhead at integer pixel centers.

Borrows the mapped arrow and GC. Keeps doubles until selecting covered pixels; rounding vertices first distorts narrow diagonal necks. Half-open edges count shared vertices once. Clips spans to graph and signed-short bounds, then sends batches of at most 128 one-pixel-high rectangles. Requires finite geometry; the enclosing renderer retains track clipping.

void Rbc_NativeTextBackground(Graph *graphPtr, Drawable drawable, GC gc, const Point2D *outline, const Point2D *anchor)¶

Fill a four-corner text background polygon.

Borrows outline, anchor and GC. Adds the anchor before short conversion and fills with Convex/CoordModeOrigin. Requires four mapped outline points; does not impose a plot clip or retain point storage.

void Rbc_NativeLegendLine(Graph *graphPtr, Drawable drawable, GC gc, int x, int y, int size)¶

Draw a two-row legend line sample.

Uses two independent XDrawLine requests, preserving the original dash restart on each row. Borrows graph, target and configured GC.

void Rbc_NativeLegendBar(Graph *graphPtr, Drawable drawable, GC gc, int x, int y, int size)¶

Draw a square legend fill sample with a local pattern origin.

Sets the borrowed GC tile/stipple origin to the sample position, fills the square, then resets that origin to zero. Does not restore a nonzero previous origin; callers must use the established legend GC contract.

void Rbc_NativeBitmapRun(Graph *graphPtr, Drawable drawable, Pixmap bitmap, GC gc, int width, int height, const Rbc_RenderPosition *positions, Tcl_Size count)¶

Draw a run of opaque bitmap copies with platform fallback.

Ignores absent positions or nonpositive counts. Tries the platform opaque batch first, then clears GC clip mask/origin and replays all positions with XCopyPlane if declined. Requires unmasked GXcopy-compatible input so replay after partial optimized failure is safe. Borrows all resources and leaves fallback GC clipping cleared; do not use for masked or XOR runs.

struct NativeClipFrame¶

Reusable clip depth with absolute bounds and optional scratch target.

Previous/next link owned frames. Parent/drawable are borrowed targets; scratch is owned until stack destruction. Platform state follows the allocation.

struct Rbc_NativeClip¶

Native clip stack borrowing a graph and base drawable.

Owns cached frames and only a lazily acquired copy GC. Active identifies the current depth; dimensions and borrowed resources stay valid until destruction.
