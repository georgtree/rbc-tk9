Shared and X11 native backend C reference¶

These declarations in rbcRenderNative.h are private backend services. Components use rbcRender.h instead. See Native renderer internals for platform behavior and ownership that cannot be inferred from a function signature.

The entries retain implementation-specific parameter contracts. Inputs described as borrowed must remain live through the call, or through batch destruction when retained by a constructor. Counts and dimensions are documented individually; short-coordinate conversion is not a general overflow check.

Trace batches¶

The X11 constructor and destructor contracts are included with the platform implementation below. See Native renderer internals for the shared lifetime contract and Windows acquisition/restoration requirements. Start with rbcNativeX11.Rbc_NativeBeginTrace(), submit rbcNativeX11.Rbc_NativePolyline(), and release with rbcNativeX11.Rbc_NativeEndTrace(). Independent strips use rbcNativeX11.Rbc_NativeStrips() without a retained trace context.

Clip stacks¶

Rbc_NativeClip *Rbc_NativeCreateClip(Graph *graphPtr, Drawable drawable, GC copyGC, int useDC)¶

Create a native rectangular clip stack without pushing a clip.

Borrows graph, base drawable and any supplied copy GC. A missing copy GC is acquired lazily and owned by the stack. A nonzero final argument permits platform DC clipping; otherwise use scratch targets. Keep graph dimensions stable while the stack is live: scratch pixmaps are cached per nesting depth.

Returns:

Owned stack, to be released with Rbc_NativeDestroyClip.

Parameters:

  • graphPtr – [in] Borrowed owning graph, kept alive until the returned context is released.

  • drawable – [in] Borrowed target, kept valid until the returned context is released.

  • copyGC – [in] Borrowed copy GC, or NULL to acquire one lazily and let the stack own it.

  • useDC – [in] Nonzero permits platform DC clipping; zero selects scratch targets.

void Rbc_NativePushClip(Rbc_NativeClip *clip, int x, int y, int width, int height)¶

Push an intersection with the parent clip and graph drawable bounds.

Arguments after the stack are x, y, width and height in absolute widget pixels. Nonpositive sizes create an empty frame. Query Rbc_NativeClipDrawable after every push; None means empty or failed output, and drawing must be skipped. Every push still requires a pop. A scratch target is seeded from its parent and preserves absolute coordinates.

Parameters:

  • clip – [inout] Live non-NULL clip stack with its borrowed resources intact.

  • x – [in] Absolute left edge in widget pixels.

  • y – [in] Absolute top edge in widget pixels.

  • width – [in] Clip width; nonpositive values create an empty frame.

  • height – [in] Clip height; nonpositive values create an empty frame.

void Rbc_NativePopClip(Rbc_NativeClip *clip)¶

Finish the active clip and restore its parent target.

Copies the visible scratch rectangle back, or restores/releases platform DC state. An empty stack is a no-op. Frame/workspace allocations are retained for reuse until destruction; borrowed drawables are not freed.

Parameters:

  • clip – [inout] Live non-NULL clip stack with its borrowed resources intact.

void Rbc_NativeDestroyClip(Rbc_NativeClip *clip)¶

Unwind and free a live native clip stack.

Pops remaining frames (committing their output), frees all cached scratch pixmaps and frame records, and releases only an internally acquired copy GC. Requires a non-NULL stack and live borrowed graph/display resources.

Parameters:

  • clip – [in] Live non-NULL clip stack; destroyed by this call.

static void DrawSegments(Display *display, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size nSegments)¶

Draw independent segments in bounded X requests.

Borrows the display, drawable, GC and input array. Ignores absent display/ segments or nonpositive counts. Allocates one request-sized XSegment buffer; clips endpoints to signed-short protocol bounds before truncating to short. Returns without drawing if capacity or allocation fails; frees workspace. This protocol clipping does not replace the owning component plot clip.

Parameters:

  • display – [in] Borrowed live display, or NULL to skip drawing.

  • drawable – [in] Borrowed destination drawable compatible with the window/display; no ownership is transferred.

  • gc – [in] Borrowed configured GC compatible with the destination drawable.

  • segments – [in] Borrowed array of nSegments double-coordinate segments, or NULL to skip drawing.

  • nSegments – [in] Segment count; nonpositive counts draw nothing.

static void Fill3DRectangle(Tk_Window tkwin, Drawable drawable, Tk_3DBorder border, int x, int y, int width, int height, int borderWidth, int relief)¶

Fill a rectangle with the historical native relief adjustment.

Borrows the window and border. For raised/sunken borders wider than one pixel and rectangles larger than two pixels, draws the outer four lines, shrinks the rectangle and delegates the remainder to Tk. X11 uses the default GC for one outer shade; Windows uses the corresponding border GC. Does not allocate or release the borrowed border GCs.

Parameters:

  • drawable – [in] Borrowed destination drawable compatible with the window/display; no ownership is transferred.

  • border – [in] Borrowed Tk 3D border on the window display; border GCs are neither retained nor freed.

  • x – [in] Left destination coordinate in pixels; coordinate arithmetic must remain representable.

  • y – [in] Top destination coordinate in pixels; coordinate arithmetic must remain representable.

  • width – [in] Positive rectangle width in pixels; endpoint arithmetic must remain representable.

  • height – [in] Positive rectangle height in pixels; endpoint arithmetic must remain representable.

  • borderWidth – [in] Positive requested bevel width in pixels, bounded before use by the caller.

  • relief – [in] Tk relief passed to the final Tk fill; raised/sunken may receive the historical outer-layer adjustment.

void Rbc_NativeSymbolPoints(Graph *graphPtr, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, int size, Tcl_Size nSymbolPts, const Point2D *symbolPts)¶

Draw mapped symbol centers using native shape batches.

Borrows graph, points and style resources; shape-specific temporary buffers and scaled bitmaps are released before return. For size below three, draws all centers as points with fillGC and bypasses symbol type/interval handling. Larger symbols use circle/square platform batches, segment crosses, polygon templates or scaled bitmaps. Interval-aware branches advance style->counter for examined centers, including skipped ones. Bitmap symbols mutate outline GC clip state. Requires valid mapped coordinates and a nonnegative count.

Parameters:

  • graphPtr – [in] Borrowed owning graph; its display and drawing resources must remain live during the call.

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • style – [inout] Borrowed symbol style; interval-aware branches advance its counter for examined centers.

  • size – [in] Mapped symbol size in pixels; sizes below three select the point-only path.

  • nSymbolPts – [in] Nonnegative number of mapped symbol centers.

  • symbolPts – [in] Borrowed mapped center array with nSymbolPts entries.

void Rbc_NativeFillPolygon(Graph *graphPtr, Drawable drawable, GC gc, Rbc_Tile tile, Pixmap stipple, const Point2D *points, Tcl_Size count)¶

Fill a tiled or stippled native polygon.

Rejects absent points, unavailable tile pixmaps and unsupported point counts. Owns temporary short-coordinate points. A tile takes precedence and its origin is reset through Rbc_SetTileOrigin before drawing. Otherwise a non-None stipple selects Complex XFillPolygon using the already configured GC. With neither tile nor stipple this helper intentionally draws nothing.

Parameters:

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • gc – [in] Borrowed configured drawing GC, including raster operation, clip and style.

  • tile – [in] Optional borrowed tile taking precedence; its origin is reset for the graph before drawing.

  • stipple – [in] Non-None enables the configured GC polygon fill when no tile is supplied; None alone does not select solid filling.

  • points – [in] Borrowed mapped polygon vertices with count entries.

  • count – [in] Number of input records, not bytes.

void Rbc_NativeBars(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, const Rbc_RenderRectangle *rectangles, Tcl_Size nRects)¶

Fill mapped bar rectangles, then draw relief borders.

Borrows graph, style and rectangles. Positive fillOpacity enables native filling; this helper does not alpha-blend fractional opacity.   • rectangles – [in] Borrowed mapped rectangle array with the supplied rectangle count.

  • nRects – [in] Number of rectangle records, not bytes.

void Rbc_NativeArcStroke(Graph *graphPtr, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size count)¶

Join contiguous arc segments into native polylines.

Requires nonnegative count, valid mapped segments and representable sizes. Zero count is a no-op. Exact endpoint equality joins adjacent segments; gaps start separate XDrawLines calls. Owns point and per-run XPoint buffers, with short-coordinate conversion. Outer allocation failure skips all drawing; per-run failure skips that run. Unlike DrawSegments, does not protocol-clip or split a run to the X request-size limit.

Parameters:

  • graphPtr – [in] Borrowed owning graph; its display and drawing resources must remain live during the call.

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • gc – [in] Borrowed configured drawing GC, including raster operation, clip and style.

  • segments – [in] Borrowed mapped arc segments; consecutive equal endpoints join a run. Caller bounds each run for native conversion/request limits.

  • count – [in] Nonnegative number of Segment2D records, not endpoints.

Allocate X11 trace state and point workspace together.

Allocate a reusable native polyline batch.

Borrows graph, drawable and configured GC. Reserves request capacity minus one as the base chunk size, plus one continuation endpoint slot. Returns NULL for insufficient capacity, size overflow or allocation failure. Release the owned allocation with Rbc_NativeEndTrace.

Allocate X11 trace state and point workspace together.

Borrows graph, drawable and configured GC until Rbc_NativeEndTrace. Owns point workspace; Windows also acquires a DC and selects owned pen/brush resources for the batch. Geometry supplied to subsequent calls is consumed synchronously. This is a backend service, not a component constructor.

Parameters:

  • graphPtr – [in] Borrowed owning graph, kept alive until the returned context is released.

  • drawable – [in] Borrowed target, kept valid until the returned context is released.

  • gc – [in] Borrowed configured GC, kept valid until the returned batch is released.

Returns:

Owned context, or NULL when request capacity or allocation prevents it.

void Rbc_NativeEndTrace(Rbc_NativeTrace *ctx)¶

Free the X11 trace allocation.

Release a native trace batch; NULL is accepted.

Accepts NULL. Does not free the borrowed graph, drawable or GC and does not flush or synchronize the X server.

Free the X11 trace allocation.

Windows restores the previously selected pen/brush before deleting the batch-owned objects and releasing its DC state. Frees context/workspace without freeing the borrowed GC, drawable or graph.

Parameters:

  • ctx – [in] Owned trace context consumed by this call; NULL is accepted.

void Rbc_NativeCircles(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int radius)¶

Draw selected circle symbols in X11 arc batches.

Owns one XArc array sized for all input centers, then submits request-sized chunks with fill before outline per chunk. Positive interval advances the style counter for every examined center. Converts centers to short before subtracting radius; diameter becomes unsigned short. Nonpositive count, size overflow, allocation failure or unusable request capacity skips output. Borrows style GCs and requires mapped coordinates and valid radius.

Parameters:

  • display – [in] Borrowed display owning the drawable and GC resources.

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • style – [inout] Borrowed symbol style; interval-aware branches advance its counter for examined centers.

  • nSymbolPts – [in] Nonnegative number of mapped symbol centers.

  • symbolPts – [in] Borrowed mapped center array with nSymbolPts entries.

  • radius – [in] Circle radius in pixels; caller supplies representable center/radius arithmetic.

void Rbc_NativeSquares(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int r)¶

Draw selected square symbols in X11 rectangle batches.

Owns a temporary array sized for all centers, then emits bounded requests with fill before outline per chunk. Positive interval advances the mutable style counter for every center examined. Subtracts radius before short conversion, unlike circles; diameter becomes unsigned short. Nonpositive count, size overflow, allocation failure or unusable capacity skips output.

Parameters:

  • display – [in] Borrowed display owning the drawable and GC resources.

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • style – [inout] Borrowed symbol style; interval-aware branches advance its counter for examined centers.

  • nSymbolPts – [in] Nonnegative number of mapped symbol centers.

  • symbolPts – [in] Borrowed mapped center array with nSymbolPts entries.

  • r – [in] Square half-size in pixels; caller supplies representable center/radius arithmetic.

Validate a single X11 polygon request length.

void Rbc_NativePolygonSymbols(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, const XPoint *polygons, Tcl_Size count, int stride, int vertices)¶

Fill all polygon symbols, then draw all outlines.

Borrows preconverted polygons and style GCs. Stride includes the closing point and is used for both fill and line requests. Twelve-vertex templates use Complex fill; others use Convex. Interval selection was performed by the shared caller. Does not allocate, clip or split individual polygons.

Parameters:

  • display – [in] Borrowed display owning the drawable and GC resources.

  • drawable – [in] Borrowed destination drawable in mapped pixel coordinates.

  • style – [in] Borrowed symbol style and GCs; caller has already selected the symbol intervals.

  • polygons – [in] Borrowed packed XPoint polygons, with stride points per polygon.

  • count – [in] Nonnegative number of packed polygon records.

  • stride – [in] Points per polygon record, including its repeated closing vertex.

  • vertices – [in] Distinct vertices per polygon; twelve selects the concave plus/cross fill policy.

Invoke a native run callback synchronously on its original target.

Calls proc only when data is non-NULL and count is positive. Borrows data and drawable, with no wrapper or DC acquisition. A valid callback is required for nonempty runs; it must not retain temporary drawing resources.

  • count – [in] Number of run items; nonpositive counts suppress drawing.

  • proc – [in] Required synchronous callback for a nonempty run; must not retain the target or destroy drawing resources.
