EPS canvas C reference

See EPS canvas item implementation for ownership, failure and platform boundaries. These are private implementation interfaces.

group EPS canvas item internals

Private command/canvas callbacks, not installed C APIs.

Functions

static char *SkipBlanks(EpsParseInfo *piPtr)

Locate the first non-whitespace byte in the current parser line.

Returns a borrowed pointer into piPtr->line, possibly its terminating NUL. Uses unsigned-byte character classification and does not modify the buffer, read the stream or advance nextPtr.

Parameters:

  • piPtr – [in] Borrowed parser record whose current line is inspected without advancing state.

static int ReadPsLine(EpsParseInfo *piPtr)

Read one bounded chunk of the PostScript stream.

Borrow the FILE in piPtr and update bytesRead, lineNumber and line. A nonzero maxBytes limits the PostScript section; zero reads to EOF. Return FALSE at the limit or when fgets fails. Long physical lines may be split into chunks; this is not an arbitrary-length line reader.

Parameters:

  • piPtr – [inout] Caller-owned parser state with the current line and borrowed input stream.

static void AppendPsLine(Tcl_DString *dStringPtr, const char *line)

Retain a string chunk with exactly one required trailing newline.

static void ReadEPSI(EpsItem *epsPtr, EpsParseInfo *piPtr)

Decode an optional one-bit or eight-bit EPSI preview.

Requires the current line to contain the recognized BeginPreview header. Accepts positive dimensions through SHRT_MAX and depths 1 or 8; parses but does not enforce the declared line count. Allocates a zeroed image and consumes the required hex bytes. Eight-bit samples become opaque inverted grayscale in bottom-to-top row order. One-bit rows consume high bits first with byte padding per row; zero bits become opaque white and set bits retain the zeroed pixel. Installs the owned image and consumed-line metadata on success. Decode failure frees the temporary and clears line markers, without rewinding input or reporting a Tcl error. Caller supplies an item ready to receive preview ownership.

Parameters:

  • epsPtr – [inout] Canvas-owned EPS item; stream, preview and text ownership changes are described above.

  • piPtr – [inout] Caller-owned parser state with the current line and borrowed input stream.
