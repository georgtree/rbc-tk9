Renderer C reference

These declarations are private implementation interfaces, not installed APIs. Callers must obey the capabilities of the constructor they selected; generic operation names do not imply that every context implements them.

Parameter directions follow C calling conventions. Context arguments refer to a specific constructor family; mutable context state does not imply ownership of borrowed graph, document, image or font resources. See Rendering architecture and contracts for batch lifetimes and scope pairing.

Screen adapters and Cairo attempts have different result contracts. Native one-shot adapters retain the supplied GC behavior, including the explicitly documented origin/clip mutations. Cairo attempt helpers return a fallback flag; context constructors return an owned context or their documented failure value. See Native renderer internals and Cairo surfaces and drawing contexts for call sequences and coordinate conventions.

Component-facing interface

Private graph rendering interface used by mapped components.

Geometry is in mapped widget/display coordinates, not axis data coordinates. Contexts and their borrowed resources must stay on the owning Tk thread. A constructor defines the supported operations; unsupported callbacks are not automatic fallbacks. Check nullable constructor results before drawing. End each allocated context exactly once with Rbc_RenderEnd(). Document tokens, drawables, GCs and component-owned resources remain borrowed.

This header is not installed and does not define the public vector ABI. See license.terms for redistribution terms.

struct NativeRenderContext

Shared storage for native screen adapter families.

core is the dispatch prefix. Trace, clip and polygon-batch records are owned; window, drawable, GC, symbol style, tile, stipple and mapped arrays are borrowed. nativeBarStyle is a shallow value copy, not ownership of its referenced resources. Only the selected constructor’s fields are meaningful. Some one-shot callers place this record on the stack and must never pass it to Rbc_RenderEnd.
