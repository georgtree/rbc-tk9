Cairo backend C reference

These static helpers belong to rbcRenderCairo.c. They are not component APIs. The documentation preprocessor enables RBC_HAVE_CAIRO to extract this group; it does not change the configured library build or require Cairo to build docs. See Cairo surfaces and drawing contexts for platform-specific target lifetime, path consumption and pattern ownership. The parameter contracts describe backend state, not permission to call a helper on an arbitrary renderer context. In particular, fill callbacks require initialized fill style, and cleanup consumes its context.

Start with BeginRenderTarget() for setup, StrokeRenderPath() for stroke composition, and CreateRenderPhoto() for copied pixel storage. Component code should use the interface in Renderer C reference instead of calling these static functions.

group Cairo backend internals

Private context and image-conversion services, compiled with Cairo enabled.

Functions

static void CairoClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)

Save graphics state and intersect with a rectangular clip.

Nonpositive dimensions become an empty rectangle. Coordinates use the current transform; the common dispatcher owns clip depth. Cairo clipping consumes the current path, so callers must finish pending geometry before pushing a clip.

Parameters:

  • ctx – [inout] Live Cairo-backed context with initialized graphics state; no ownership transfer.

  • x – [in] Destination X coordinate in display units.

  • y – [in] Destination Y coordinate in display units.

  • width – [in] Rectangle width in pixels; nonpositive clip dimensions select an empty rectangle.

  • height – [in] Rectangle height in pixels; nonpositive clip dimensions select an empty rectangle.

static void CairoClipEnd(Rbc_RenderContext *ctx)

Restore the state saved by one clip push.

static Rbc_RenderContext *BeginRenderTarget(Graph *graphPtr, Drawable drawable, const XColor *colorPtr, double width, const Rbc_Dashes *dashesPtr, const XColor *offColorPtr, int targetWidth, int targetHeight, int left, int top, int right, int bottom)

Create a Cairo context for an explicitly sized native target and clip.

Borrows graph/drawable, copies stroke colors and dash values, and owns the resulting surface reference and cairo_t. The four final integers are inclusive clip edges; target dimensions describe the underlying drawable. Establishes the clip before the half-pixel translation. Windows can reference the current marker-pass image, otherwise it acquires/saves a display DC; X11 creates an Xlib surface wrapper. Printing/metafile Windows targets decline Cairo. Finish successful contexts with Rbc_RenderEnd while borrowed resources and any enclosing marker pass remain alive. No native retry occurs here.

Returns:

Owned context, or NULL after cleanup if input or setup is unsupported.

Parameters:

  • graphPtr – [in] Borrowed owning graph, kept alive until context release; must select Cairo.

  • drawable – [in] Borrowed non-None destination kept valid until context release and within any enclosing marker pass.

  • colorPtr – [in] Required borrowed Tk color; channel values are copied.

  • width – [in] Finite positive stroke width in display units, not destination width.

  • dashesPtr – [in] Optional borrowed dash specification copied into the context; NULL selects solid.

  • offColorPtr – [in] Optional borrowed off-dash color copied into the context when used.

  • targetWidth – [in] Positive destination width in pixels.

  • targetHeight – [in] Positive destination height in pixels.

  • left – [in] Inclusive left target clip edge in pixels.

  • top – [in] Inclusive top target clip edge in pixels.

  • right – [in] Inclusive right target clip edge in pixels.

  • bottom – [in] Inclusive bottom target clip edge in pixels.

Copy a Tk photo block into an owned repeating Cairo pattern.

Flush, release and report completion errors.

Requires a live context and interpreter after common clip unwinding. Captures context status, then surface status if needed, frees owned resources, and reports a background Tcl exception with interpreter state restored. This is terminal cleanup, not a request to replay native drawing.
