Cairo backend C reference¶

These static helpers belong to rbcRenderCairo.c. They are not component APIs. The documentation preprocessor enables RBC_HAVE_CAIRO to extract this group; it does not change the configured library build or require Cairo to build docs. See Cairo surfaces and drawing contexts for platform-specific target lifetime.

group Cairo backend internals

Private context and image-conversion services, compiled with Cairo enabled.

Functions

static void CairoClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)¶

Save graphics state and intersect with a rectangular clip.

Nonpositive dimensions become an empty rectangle. Coordinates use the current transform; the common dispatcher owns clip depth. Cairo clipping consumes the current path, so callers must finish pending geometry before pushing a clip.

static void CairoClipEnd(Rbc_RenderContext *ctx)¶

Restore the state saved by one clip push.

Requires a matching CairoClipBegin through common dispatch. This does not decrement common clip depth itself and cannot restore a consumed path.

static void FreeRenderContext(Rbc_RenderContext *ctx)¶

Release a fully or partially initialized Cairo context.

Destroys owned pattern, cairo_t and surface reference, then restores saved Windows DC state and releases its acquisition record. Finally frees the context. Does not flush/report drawing errors; CairoEnd provides that normal-completion behavior. Borrowed graph and component resources survive.

Parameters:

  • ctx – Non-NULL owned context whose optional fields were zero-initialized.

static cairo_antialias_t GetAntialias(int mode)¶

Translate an RBC antialias mode to Cairo.

Known modes map directly; unrecognized values select Cairo default. This is a mapping helper, not option validation.

static void SetStrokeColor(cairo_t *cr, const XColor *colorPtr)¶

Set an opaque RGB source from a borrowed Tk color.

Requires a non-NULL color. Channels are normalized from 16-bit values; Cairo copies the numeric source, so the color pointer is not retained.

static void StrokeRenderPath(Rbc_RenderContext *ctx)¶

Stroke and consume the current path using the context’s dash policy.

Double-dash mode first paints a solid off-color stroke while preserving the path, then applies foreground dashes and consumes the path. Owns no additional resources. This is not an XOR/raster-operation adapter.

Parameters:

  • ctx – Live Cairo context with initialized stroke colors and dashes.

static Rbc_RenderContext *BeginRenderTarget(Graph *graphPtr, Drawable drawable, const XColor *colorPtr, double width, const Rbc_Dashes *dashesPtr, const XColor *offColorPtr, int targetWidth, int targetHeight, int left, int top, int right, int bottom)¶

Create a Cairo context for an explicitly sized native target and clip.

Borrows graph/drawable, copies stroke colors and dash values, and owns the resulting surface reference and cairo_t. The four final integers are inclusive clip edges; target dimensions describe the underlying drawable. Establishes the clip before the half-pixel translation. Windows can reference the current marker-pass image, otherwise it acquires/saves a display DC; X11 creates an Xlib surface wrapper. Printing/metafile Windows targets decline Cairo. Finish successful contexts with Rbc_RenderEnd while borrowed resources and any enclosing marker pass remain alive. No native retry occurs here.

Returns:

Owned context, or NULL after cleanup if input or setup is unsupported.

static void CairoPolyline(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Build and stroke a connected trace.

Counts below two do nothing. Borrows mapped points and preserves joins within the trace. StrokeRenderPath consumes the path, including its optional off-color pass; callers must not leave unrelated pending geometry.

static void CairoArcPath(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Replace the path with a normalized mapped ellipse arc.

Builds the arc under a temporary translate/scale, then restores the transform before painting. Full sweeps close without a radial edge; partial sectors add the center and chords close directly. The caller supplies common-dispatch-validated geometry.

static void CairoArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Stroke the normalized arc with current dash policy.

Replaces and consumes the current path. The temporary ellipse transform affects geometry only, preserving screen-space line widths and dash lengths.

static void CairoFillArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Fill a normalized closed arc with the configured style.

Temporarily cancels the half-pixel center translation and selects even-odd fill. A retained bitmap pattern takes precedence over solid opacity. Common dispatch excludes open arcs; a solid style requires its borrowed foreground to remain live.

static void CairoLineStyle(Rbc_RenderContext *ctx, int capStyle, int joinStyle)¶

Translate native cap and join constants to Cairo state.

Round and projecting caps map to round and square; other caps use butt. Round and bevel joins map directly, with miter as the fallback. Does not change dash state or pending geometry.

static void CairoDashBackground(Rbc_RenderContext *ctx, const XColor *color)¶

Update the off-color underlay without changing dashes.

Enables double-dash only when dashes exist and a color is supplied, copying that color by value. NULL disables the underlay; unlike initial construction, this helper does not collapse equal colors to a solid stroke.

static void CairoSegments(Rbc_RenderContext *ctx, const Segment2D *segments, Tcl_Size count)¶

Stroke independent segment subpaths in bounded batches.

Ordinary strokes flush every 8192 segments and at completion. Double-dash strokes flush after each segment to preserve painter order at intersections. Input geometry is borrowed, and each flush consumes the path.

static void AppendRenderSymbol(cairo_t *cr, const Rbc_RenderShape *shape, const Point2D *center)¶

Append one independent symbol without painting it.

Borrows shape and center. Circles start a new subpath; segment shapes use pairs and ignore an unmatched final point; other nonempty shapes close a polygon. Does not clear existing shapes, set paint or allocate caller-owned storage.

static uint32_t RenderAreaPixel(const XColor *color)¶

Convert a borrowed Tk color to an opaque ARGB32 pixel.

NULL becomes transparent zero. Color channels use rounded division by 257, not truncation; opaque channels require no additional premultiplication.

static cairo_pattern_t *CreateRenderStipple(Graph *graphPtr, Pixmap stipple, const XColor *foreground, const XColor *background)¶

Copy a named bitmap into an owned repeating pattern.

Reads XYPixmap bits before destination-context acquisition and maps them to foreground/background ARGB pixels. Releases the temporary XImage and local surface reference. Returns a nearest-filtered pattern owned by the caller, or NULL after cleanup on failure; NULL colors create transparent pixels.

static void CairoFillRectangles(Rbc_RenderContext *ctx, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Fill rectangle batches with optional group opacity.

Temporarily cancels pixel-center translation and uses winding fill. Nonpositive rectangles are skipped and paths flush every 8192 input entries. Opacity applies once to the composed group, including stipple paint, rather than separately at every overlap. Restores graphics state after consuming the path.

static void FillRenderArea(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count, cairo_pattern_t *pattern)¶

Fill a borrowed polygon in pixel-boundary coordinates.

Requires at least three readable points and no unrelated pending geometry. Cancels the half-pixel translation, selects even-odd fill and optionally sets a borrowed pattern. This helper does not save or restore graphics state: callers must bracket it or end the context afterward.

static cairo_pattern_t *CreateRenderBitmap(Graph *graphPtr, Pixmap bitmap, Pixmap mask, int width, int height, const XColor *foreground, const XColor *background)¶

Copy mapped bitmap and optional mask into an owned pattern.

Caller supplies positive dimensions and pixmaps readable over that rectangle. When mask equals bitmap, one XImage serves both roles and is freed once. Distinct readbacks and the local surface are cleaned up on failure. Returns a nearest-filtered, nonrepeating pattern or NULL; source pixmaps remain borrowed.

static void CairoFillPolygon(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Fill a polygon using retained solid or stipple style.

Common dispatch guarantees at least three points. Solid opacity is applied only without a stipple; the retained pattern already owns its pixel alpha. Saves and restores state around FillRenderArea, but consumes the path.

static cairo_pattern_t *CreateRenderPhoto(const Tk_PhotoImageBlock *block)¶

Copy a Tk photo block into an owned repeating Cairo pattern.

Validates RGB offsets. A distinct valid alpha offset selects alpha; otherwise pixels are opaque. Premultiplies RGB with rounded division by 255. The pattern retains its copied surface; no source pixel pointer escapes. Does not validate the caller’s allocation size or retain the Tk photo itself.

Parameters:

  • block – Borrowed readable block with valid dimensions, pitch and storage.

Returns:

Owned nearest-filtered ARGB32 pattern, or NULL on invalid channel layout or failed surface/pattern creation. Caller destroys a returned pattern.

static void CairoEnd(Rbc_RenderContext *ctx)¶

Flush, release and report completion errors.

Requires a live context and interpreter after common clip unwinding. Captures context status, then surface status if needed, frees owned resources, and reports a background Tcl exception with interpreter state restored. This is terminal cleanup, not a request to replay native drawing.
