Cairo backend C reference¶

These static helpers belong to rbcRenderCairo.c. They are not component APIs. The documentation preprocessor enables RBC_HAVE_CAIRO to extract this group; it does not change the configured library build or require Cairo to build docs. See Cairo surfaces and drawing contexts for platform-specific target lifetime.

group Cairo backend internals

Private context and image-conversion services, compiled with Cairo enabled.

Functions

static void FreeRenderContext(Rbc_RenderContext *ctx)¶

Release a fully or partially initialized Cairo context.

Destroys owned pattern, cairo_t and surface reference, then restores saved Windows DC state and releases its acquisition record. Finally frees the context. Does not flush/report drawing errors; CairoEnd provides that normal-completion behavior. Borrowed graph and component resources survive.

Parameters:

  • ctx – Non-NULL owned context whose optional fields were zero-initialized.

static void StrokeRenderPath(Rbc_RenderContext *ctx)¶

Stroke and consume the current path using the context’s dash policy.

Double-dash mode first paints a solid off-color stroke while preserving the path, then applies foreground dashes and consumes the path. Owns no additional resources. This is not an XOR/raster-operation adapter.

Parameters:

  • ctx – Live Cairo context with initialized stroke colors and dashes.

static Rbc_RenderContext *BeginRenderTarget(Graph *graphPtr, Drawable drawable, const XColor *colorPtr, double width, const Rbc_Dashes *dashesPtr, const XColor *offColorPtr, int targetWidth, int targetHeight, int left, int top, int right, int bottom)¶

Create a Cairo context for an explicitly sized native target and clip.

Borrows graph/drawable, copies stroke colors and dash values, and owns the resulting surface reference and cairo_t. The four final integers are inclusive clip edges; target dimensions describe the underlying drawable. Establishes the clip before the half-pixel translation. Windows can reference the current marker-pass image, otherwise it acquires/saves a display DC; X11 creates an Xlib surface wrapper. Printing/metafile Windows targets decline Cairo. Finish successful contexts with Rbc_RenderEnd while borrowed resources and any enclosing marker pass remain alive. No native retry occurs here.

Returns:

Owned context, or NULL after cleanup if input or setup is unsupported.

static cairo_pattern_t *CreateRenderPhoto(const Tk_PhotoImageBlock *block)¶

Copy a Tk photo block into an owned repeating Cairo pattern.

Validates RGB offsets. A distinct valid alpha offset selects alpha; otherwise pixels are opaque. Premultiplies RGB with rounded division by 255. The pattern retains its copied surface; no source pixel pointer escapes. Does not validate the caller’s allocation size or retain the Tk photo itself.

Parameters:

  • block – Borrowed readable block with valid dimensions, pitch and storage.

Returns:

Owned nearest-filtered ARGB32 pattern, or NULL on invalid channel layout or failed surface/pattern creation. Caller destroys a returned pattern.
