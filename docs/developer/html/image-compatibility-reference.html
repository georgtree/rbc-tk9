Image compatibility C reference¶

These functions are defined by RBC in rbcImage.c and declared privately in rbcImage.h, including those whose names start with Tk_. See Temporary images and private Tk adapters for lifetime and private-layout requirements.

int Tk_ImageIsDeleted(Tk_Image tkImage)¶

Inspect whether a retained image instance has lost its image manager.

Require a non-NULL, unfreed Tk_Image. Return true for a NULL master pointer or NULL master type. This RBC-defined helper reads copied private Tk layout; it cannot validate an arbitrary or already-freed pointer.

Tk_ImageMaster Tk_ImageGetMaster(Tk_Image tkImage)¶

Return the borrowed master pointer from a retained, non-NULL Tk image.

No reference is acquired. The result may be NULL; callers must establish validity before passing it to further Tk or RBC operations. This helper is implemented by RBC using copied private Tk structure layout.

Tk_ImageType *Tk_ImageGetType(Tk_Image tkImage)¶

Return a borrowed image-type pointer using RBC’s private-layout adapter.

Require a retained non-NULL instance with a non-NULL master. A deleted master’s type may be NULL. Do not free or modify the returned descriptor.

Pixmap Tk_ImageGetPhotoPixmap(Tk_Image photoImage)¶

Borrow the native display pixmap of a live photo instance, or return None for a different live image type.

Require non-NULL instance, master and type. This is RBC’s private-layout accessor, not a retained pixel snapshot. Do not free the pixmap or retain it across image changes.

GC Tk_ImageGetPhotoGC(Tk_Image photoImage)¶

Borrow the display GC of a live photo instance, or return NULL for another live type.

Require non-NULL instance, master and type. Do not free or mutate the returned Tk-owned GC. This RBC helper relies on private photo layout.

const char *Rbc_NameOfImage(Tk_Image tkImage)¶

Return the borrowed Tk name of an image with a valid master.

No name copy or lifetime reference is acquired. Do not free the result; copy it before an operation that can invalidate the image or master.

Tk_Image Rbc_CreateTemporaryImage(Tcl_Interp *interp, Tk_Window tkwin, ClientData clientData)¶

Create a named photo through Tcl and acquire an image instance for tkwin.

Borrow interp, tkwin and clientData; the installed change callback is a no-op. Return a caller-owned token paired with Rbc_DestroyTemporaryImage(), or NULL on failure. The Tcl result object is retained while Tk_GetImage consumes its name. If instance acquisition fails, the named image is deleted through Tk’s C API while preserving the acquisition error. Evaluates the image command in the current context and does not preserve caller lifetime or interpreter result across callbacks.

int Rbc_DestroyTemporaryImage(Tcl_Interp *interp, Tk_Image tkImage)¶

Delete a temporary image through Tk’s C API and consume its instance.

NULL is a successful no-op. Otherwise require a retained token. Already deleted images still have their instance released. Always returns TCL_OK; cleanup preserves interpreter state and does not evaluate the image command. Tk deletion may notify other image clients. Callers must detach the token from owner fields before calling and provide their own owner lifetime guard.
