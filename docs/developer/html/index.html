RBC Developer Manual¶

This manual describes the C implementation for contributors. It is separate from the Tcl command reference generated by Ruff. The interfaces described here are private unless explicitly identified as part of the installed vector API.

The manual covers graph rendering, the common widget lifecycle and vector ownership, binding dispatch and picking, component configuration, coordinate mapping, element data ownership, and marker lifecycle. Architecture and header chapters provide context; C references are extracted from maintained source comments by Doxygen and included by Breathe. Additional numerical operations and individual backend algorithms remain future chapters.
