RBC Developer Manual¶

This manual describes the C implementation for contributors. It is separate from the Tcl command reference generated by Ruff. The interfaces described here are private unless explicitly identified as part of the installed vector API.

The manual covers widget and component lifecycles, vectors and numerical operations, configuration and bindings, mapping and layout, native and document renderers, image processing, shared Tk services, standalone window/photo commands and EPS canvas items. Architecture and header chapters provide context; C references are extracted from maintained source comments by Doxygen and Breathe.

Coverage remains selective. A reference entry documents a reviewed contract, not a claim that every function in its module has been audited or made callback safe. Chapters identify current limitations separately from intended guarantees.
