Image transform C reference¶

These private declarations are in rbcImage.h. Color rotation is implemented in rbcImage.c; bitmap transforms have Windows and X11 implementations in rbcWinImage.c and rbcUnixImage.c. See Color-image rotation and bitmap transforms.

Rbc_ColorImage Rbc_RotateColorImage(Rbc_ColorImage image, double theta)¶

Return a newly owned color image rotated counterclockwise in display space.

Borrow image and accept a finite angle in degrees, normalized modulo 360. Non-finite angles panic. Empty input is copied without swapping dimensions. Right angles copy pixels exactly; other angles use three filtered shears after a quadrant rotation, with transparent white background. The result never aliases image, even at zero degrees; free with Rbc_FreeColorImage().

Pixmap Rbc_RotateBitmap(Tk_Window tkwin, Pixmap bitmap, int width, int height, double theta, int *widthPtr, int *heightPtr)¶

Create an owned one-bit pixmap containing the rotated source bitmap.

Borrow the Tk window and source bitmap, whose positive dimensions must match the supplied sizes. Require a finite angle in degrees and non-NULL dimension output pointers. On success assign output sizes and return a new pixmap for Tk_FreePixmap(). None reports a detected failure; do not rely on output dimensions after failure, since Windows and X11 initialize them differently. Rotation uses discrete sampling, not the color-image shear filter.

Pixmap Rbc_ScaleBitmap(Tk_Window tkwin, Pixmap srcBitmap, int srcWidth, int srcHeight, int scaledWidth, int scaledHeight)¶

Create an owned one-bit pixmap scaled to the requested dimensions.

Borrow the window and source bitmap. Require positive source and destination sizes and a source bitmap matching its declared dimensions. Release a returned pixmap with Tk_FreePixmap(). X11 copies nearest-neighbour samples; Windows uses StretchBlt and does not propagate its status. A non-None return is not a portable guarantee that every native drawing operation succeeded.

Pixmap Rbc_ScaleRotateBitmapRegion(Tk_Window tkwin, Pixmap srcBitmap, int srcWidth, int srcHeight, int regionX, int regionY, int regionWidth, int regionHeight, int virtWidth, int virtHeight, double theta)¶

Create only a region of a virtually scaled, rotated one-bit bitmap.

Borrow window and source bitmap. The region coordinates refer to the virtual rotated destination, whose dimensions are virtWidth and virtHeight. Require positive dimensions, a finite degree angle and a region contained in that virtual image, with representable coordinate sums. Right-angle paths assume these bounds rather than checking each source sample. Return an owned pixmap of regionWidth by regionHeight, or None for a detected failure. Free with Tk_FreePixmap(); no source or window ownership is transferred.

Color rotation implementation¶

These CPU-side helpers implement exact quadrant copies and the residual three-shear path. Native bitmap transforms use separate implementations.

static void ShearY(Rbc_ColorImage src, Rbc_ColorImage dest, int y, int offset, double frac, Pix32 bgColor)¶

Shift and filter one source row into a destination row.

Despite its name, this helper moves pixels horizontally at fixed row y. Borrows distinct images; y must exist in both. Initializes the entire destination row to bgColor, then processes all source pixels, including clipped ones, to retain the preceding fractional contribution. offset supplies the integer displacement and frac must lie in [0,1). Writes only in-range destination pixels and a final residual pixel when visible. Uses 14-bit fixed-point straight RGBA arithmetic with byte clamping. Caller ensures offset plus source width remains representable as int. Does not allocate, resize, or validate the row index or fraction.

static void ShearX(Rbc_ColorImage src, Rbc_ColorImage dest, int x, int offset, double frac, Pix32 bgColor)¶

Shift and filter one source column into a destination column.

Despite its name, this helper moves pixels vertically at fixed column x. Borrows distinct images; x must exist in both. Initializes the complete destination column to bgColor. offset is the integer displacement and frac must lie in [0,1). Accumulates the preceding fractional contribution even while destination coordinates are clipped, and emits the final residual pixel if visible. Filters straight RGBA with 14-bit fixed-point weights and clamps channels. Requires representable offset plus source height. Does not allocate or validate the column index or fraction.

static int GetRotationDimension(double value)¶

Validate and truncate a nonnegative rotation extent.

Returns int truncation of a finite value in [0, INT_MAX]. Invalid or unrepresentable values panic. Does not round upward or add padding; callers include any extra space in their dimension formula.

static int GetShearOffset(double value)¶

Floor a fractional displacement before checked integer conversion.

Returns floor(value) as an int, including for negative displacements. Non-finite or out-of-range results panic. The caller derives the fractional remainder by subtracting this result from the original value.

static Rbc_ColorImage Rotate45(Rbc_ColorImage src, double theta, Pix32 bgColor)¶

Rotate a borrowed image by a residual angle using three filtered shears.

theta is in radians and must lie in [-pi/4, pi/4]; this helper does not normalize or validate that interval. Uses horizontal, vertical, horizontal passes based on tan(theta/2) and sin(theta). Allocates two intermediates and the final image, releasing each intermediate after its last use. bgColor supplies padding and boundary contributions for every pass. Returns independent owned storage released with Rbc_FreeColorImage. Dimension/offset conversion panics on unrepresentable geometry. The construction follows Alan W. Paeth, A Fast Algorithm for General Raster Rotation, Graphics Gems, pp. 179-195. It is not a single-pass inverse-mapped rotation; intermediate clamping affects pixel results.

static Rbc_ColorImage CopyColorImage(Rbc_ColorImage src)¶

Duplicate an entire RGBA image into independent storage.

Borrows a valid source, checks its pixel count, allocates an equal-size image and copies complete Pix32 values including alpha. Empty dimensions are retained. Returns ownership to the caller, which frees the result with Rbc_FreeColorImage. Does not modify or share source pixel storage.

static Rbc_ColorImage Rotate90(Rbc_ColorImage src)¶

Copy pixels into a counterclockwise quarter-turn image.

Borrows source storage and allocates a destination with exchanged width and height. Maps (x,y) to (y,sourceWidth-x-1), copying all RGBA bytes exactly. No interpolation or background blending occurs. Caller owns the result and releases it with Rbc_FreeColorImage.

static Rbc_ColorImage Rotate180(Rbc_ColorImage src)¶

Copy pixels into a half-turn image with unchanged dimensions.

Borrows source storage and maps (x,y) to (width-x-1,height-y-1) in a newly allocated image. Copies complete RGBA values with no interpolation. Caller owns the independent result and frees it with Rbc_FreeColorImage.

static Rbc_ColorImage Rotate270(Rbc_ColorImage src)¶

Copy pixels into a clockwise quarter-turn image.

Borrows source storage and allocates a destination with exchanged width and height. Maps (x,y) to (sourceHeight-y-1,x), copying complete pixels. No interpolation occurs. Caller owns the independent result and frees it with Rbc_FreeColorImage.
