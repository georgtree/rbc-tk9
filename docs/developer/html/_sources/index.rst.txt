RBC Developer Manual
====================

This manual describes the C implementation for contributors. It is separate
from the Tcl command reference generated by Ruff. The interfaces described here
are private unless explicitly identified as part of the installed vector API.

The first documented subsystem is graph rendering. The architecture and header
chapters provide context; the reference is extracted from the current C headers
by Doxygen and included by Breathe. Widget lifecycle, vector internals, binding
and picking, and individual backend algorithms remain future chapters.
