Document renderer C reference¶

These are private implementation contracts, not installed C APIs. Component callers use Renderer C reference; these helpers borrow export state and have backend-specific preconditions. See Document renderer primitives.

Shared export support¶

group Export backend support

Private helpers shared by document renderers; not installed C APIs.

Functions

Rbc_RenderContext *Rbc_RenderCreatePostscript(Rbc_ExportContext*)¶

Allocate a zeroed PostScript renderer borrowing an initialized token.

Requires backendData to hold a live PsToken. Owns only the returned context; release through Rbc_RenderEnd. Does not begin a page, load the prolog or own the export buffer.

Rbc_RenderContext *Rbc_RenderCreateSvg(Rbc_ExportContext*)¶

Allocate a zeroed SVG renderer borrowing an export token.

Installs the SVG operation table without beginning or finalizing a document. The token outlives the context; release through Rbc_RenderEnd.

Rbc_RenderContext *Rbc_RenderCreatePdf(Rbc_ExportContext*)¶

Allocate a zeroed PDF renderer borrowing an initialized export token.

The PDF builder must already be attached before drawing. Installs operations but does not initialize fonts, serialize the page or own document resources. Release through Rbc_RenderEnd.

void Rbc_RenderPostscriptStroke(Rbc_RenderContext*, const XColor*, int, const Rbc_Dashes*, int, int)¶

Emit PostScript line attributes and remember whether dashes are enabled.

Requires a PostScript context. Delegates width/color/dash conversion to the token and borrows input resources. Dash-background procedure setup is separate.

void Rbc_RenderPostscriptSymbol(Rbc_RenderContext*, const Rbc_RenderSymbolStyle*)¶

Define a legacy PostScript symbol batch and its size correction.

Requires a valid symbol type, live graph and valid bitmap resources when selected. Defines DrawSymbolProc in the document dictionary, chooses a prolog macro, and emits outline width/dashes. Finish this batch before another context redefines that procedure.

void Rbc_RenderPostscriptBarSymbol(Rbc_RenderContext*, const Rbc_RenderFillStyle*, int)¶

Define the unscaled square procedure used for bar legend samples.

Requires a PostScript fill context and live graph for stipples. Borrows style resources, emits DrawSymbolProc and records size. Retains the legacy solid/stipple fallback and ignores image-tile opacity.

void Rbc_RenderExportEnd(Rbc_RenderContext*)¶

Free only the allocated renderer context.

Called after common Rbc_RenderEnd unwinds explicit clips. Does not balance a separately opened plot scope or free the borrowed export token, graph, styles, tiles, document resources or output buffer. Requires non-NULL context.

void Rbc_RenderExportLineStyle(Rbc_RenderContext*, int, int)¶

Cache PDF/SVG cap and join settings for later drawing.

Requires an export context using the shared state layout. Emits nothing and does not affect existing output; PostScript has its own immediate setter.

void Rbc_RenderExportDashBackground(Rbc_RenderContext*, const XColor*)¶

Copy an optional PDF/SVG dash-background color.

NULL disables the background. Stores the XColor value, not a borrowed color pointer, and emits nothing immediately.

Rbc_ColorImage Rbc_RenderExportRasterImage(Rbc_ExportContext*, Tk_Image)¶

Capture a Tk image over black and white to reconstruct RGBA.

Requires a live export window and valid Tk image on its owning thread. Deleted, empty or NULL images return NULL without recording an error. Allocation/capture failures record an export error. Owns temporary pixmap, GC and captures; frees all intermediates and returns one caller-owned Rbc_ColorImage on success. Release it with Rbc_FreeColorImage. Alpha is inferred from the maximum channel difference and RGB is unpremultiplied; this is a raster approximation, not access to original image pixels. Tk image display procedures run synchronously; the helper does not itself guard against arbitrary custom-image callback destruction.

int Rbc_RenderExportSymbolRound(double)¶

Round a finite symbol measurement halfway away from zero.

Requires the adjusted value to fit int. Preserves legacy export size corrections; does not provide overflow checking.

PDF drawing callbacks¶

group PDF drawing backend

Private renderer callbacks; components use the common renderer interface.

Functions

static void PdfClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)¶

Save graphics state and intersect a rectangular clip.

Coordinates are mapped display pixels. Emits q/re/W/n; PdfClipEnd must balance the save. Common renderer clip-depth tracking owns pairing, not this callback.

static void PdfClipEnd(Rbc_RenderContext *ctx)¶

Restore one rectangular clipping scope.

Emits Q only. Requires a matching begin; does not inspect or change common clip depth.

static void PdfColor(Rbc_ExportContext *token, const XColor *color, int stroke)¶

Select DeviceRGB stroke or fill color.

Converts 16-bit XColor components to unit values. A NULL color leaves the current color unchanged; this helper does not save graphics state.

static void PdfPath(Rbc_ExportContext *token, const Point2D *points, Tcl_Size count, int close)¶

Append a polygonal path without painting it.

Borrows count points in mapped pixels and optionally emits h. The caller supplies valid geometry, chooses the fill rule and owns graphics-state scope.

static void PdfRectangle(Rbc_ExportContext *token, double x, double y, double width, double height, const XColor *color)¶

Paint a positive-size solid rectangle in an isolated scope.

NULL color or nonpositive dimensions produce no output. Uses nonstroking RGB and restores the previous graphics state.

static void PdfArcPath(Rbc_ExportContext *token, const Rbc_RenderArcGeometry *arc)¶

Append an elliptical arc using cubic Bezier pieces.

Requires normalized finite geometry with nonzero extent from the renderer dispatcher. Each piece spans at most 90 degrees. Negates angles for screen Y, closes full ellipses and chords, and adds the center for partial pieslices. Does not paint or change the transformation matrix.

static void PdfStrokeStyle(Rbc_RenderContext *ctx, int background)¶

Emit cached stroke color, width, cap, join and dashes.

The background pass selects the off-color and an empty dash pattern with zero offset. The foreground pass uses the bounded dash array and its offset. The caller saves/restores graphics state.

static void PdfPolyline(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Stroke a connected path, optionally over a solid dash background.

No foreground color or fewer than two points is a no-op. Each pass reconstructs the whole path and has its own q/Q scope; the input array remains borrowed.

static void PdfSegments(Rbc_RenderContext *ctx, const Segment2D *segments, Tcl_Size count)¶

Stroke independent segments in their original painter order.

Each segment delegates to PdfPolyline, including its background and foreground passes, before the next segment. Does not combine the batch into one shared path.

static void PdfArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Stroke normalized arc geometry with the cached line style.

No foreground color is a no-op. Rebuilds the arc for each dash-background/foreground pass and balances graphics state for each pass.

static void PdfBitmapRuns(Rbc_ExportContext *token, XImage *bits, XImage *mask, const XColor *color)¶

Convert set bitmap pixels into filled horizontal rectangles.

Borrows a valid XImage and optional same-sized mask. Emits runs where both images are set; NULL color produces no output. Uses the current transform and graphics scope, paints once with f, and does not release either image.

static int PdfPhotoResource(Rbc_ExportContext *token, const Tk_PhotoImageBlock *block)¶

Copy a Tk photo block into PDF RGB and optional alpha resources.

Returns an image object ID, or zero for empty/invalid input. Invalid size/storage records an export error. Requires valid Tk channel offsets and row layout. Copies RGB bytes row by row and creates an 8-bit grayscale SMask only if any alpha is nonopaque. Frees temporary DStrings; does not retain the borrowed block or pixel pointer.

static void PdfImageUse(Rbc_ExportContext *token, int id, double x, double y, int width, int height)¶

Place an image resource using top-left display coordinates.

A zero resource ID is a no-op. Emits a locally saved matrix with negative image height to correct raster orientation, then invokes the image XObject.

static int PdfColorImageResource(Rbc_ExportContext *token, Rbc_ColorImage image)¶

Adapt a packed RBC color image to the photo resource writer.

Borrows the image, checks that row pitch fits int, and describes Pix32 channel offsets without copying the source first. Resource construction copies the pixels. Returns zero and records an export error for excessive pitch; does not free the image.

static unsigned int PdfPattern(Rbc_RenderContext *ctx, const XColor *foreground)¶

Create or reuse this fill context’s colored tiling pattern.

Uses a borrowed tile for backgroundOnly fills, otherwise a stipple bitmap. Tile photos use their pixel block; other Tk images use raster capture. Stipples become bitmap runs over an optional background. Restores token->buffer after constructing temporary pattern content and releases temporary images. The pattern matrix includes page scale/Y reversal; tile origin also accounts for graph ancestry. Caches the resource ID until the tile setter invalidates it. Zero means no pattern; the enclosing export error remains authoritative.

static int PdfFillStyle(Rbc_RenderContext *ctx)¶

Prepare nonstroking opacity and solid or patterned fill state.

Returns false for nonpositive opacity, missing solid color or unavailable pattern. Opacity below one uses an ExtGState ca resource. Pattern creation precedes path construction so resource emission cannot consume the drawing path. The caller provides a q/Q scope; this helper is not a Tcl status API.

static void PdfFillPolygon(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Fill a closed polygon with the even-odd rule.

Establishes fill resources before appending borrowed geometry. Always balances its local graphics save, including when the style produces no fill.

static void PdfFillRectangles(Rbc_RenderContext *ctx, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Fill each supplied rectangle in a separate graphics scope.

Uses the cached fill style, with shared pattern resource reuse across the batch. Geometry is already mapped; no outline or clipping calculation is performed here.

static void PdfFillArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Fill normalized ellipse, chord or sector geometry.

Prepares fill state before constructing the path and uses even-odd fill. The caller selects a fillable arc style; the helper balances graphics state even if filling is disabled.

static void PdfText(Rbc_RenderContext *ctx, char *string, TextStyle *style, double x, double y)¶

Emit anchored, rotated text using document-local font resources.

Owns and frees a temporary TextLayout. Resolves glyphs before output to widen zero-width Tk measurements when a fallback has positive advance, then recomputes justification. Emits shadow before foreground, selecting active color when requested. Each glyph uses Tk prefix advance plus fallback corrections; genuine zero-width glyphs retain their position. Font/width errors are recorded on the export; this void emitter does not return a completed-document status.

static void PdfPhoto(Rbc_RenderContext *ctx, Tk_PhotoHandle photo, double x, double y)¶

Read a borrowed Tk photo and place its copied PDF resource.

A missing/unreadable photo records an export error. Does not destroy the photo or retain its pixel block.

static void PdfTkImage(Rbc_RenderContext *ctx, Tk_Image image, double x, double y)¶

Rasterize a non-photo Tk image and emit its PDF resource.

Owns the capture returned by Rbc_RenderExportRasterImage and frees it after resource creation. A NULL capture emits no image; consult the export error for failed captures.

static void PdfWindow(Rbc_RenderContext *ctx, Tk_Window window, double x, double y)¶

Capture a mapped window at its current screen dimensions.

Unmapped or empty windows are omitted. Owns and frees the captured color image; capture failure records an export error. The caller decides whether window export is enabled. This captures pixels, not a reconstructed widget or new clipping container.

static void PdfBitmapMask(Rbc_RenderContext *ctx, Display *display, Pixmap bitmap, double x, double y, int width, int height, const XColor *color, int background)¶

Paint a positioned one-bit mask as vector rectangles.

Missing bitmap/color or nonpositive dimensions are ignored. Acquires and destroys an XImage; failure records an export error. The background selector is unused because the explicit color determines painting. Translation is confined to a q/Q scope.

static void PdfBackgroundPolygon(Rbc_RenderContext *ctx, const XColor *color, const Point2D *points, Tcl_Size count)¶

Paint a solid even-odd background polygon.

NULL color is a no-op. Borrows mapped points and isolates the RGB fill in a saved graphics scope.

static void PdfPolygon(Rbc_ExportContext *token, const Point2D *points, Tcl_Size count, const XColor *color, double opacity)¶

Adapt border polygon output to a temporary export state.

Creates a stack-local state borrowing the token and delegates to PdfBackgroundPolygon. The opacity parameter is currently ignored; border callers pass opaque color.

static void PdfBorder(Rbc_RenderContext *ctx, Tk_3DBorder border, double x, double y, int width, int height, int borderWidth, int relief, int fill)¶

Approximate Tk relief using solid rectangles and a polygon.

Obtains border colors after forcing lazy light-GC allocation. Optionally fills the interior, then emits raised/sunken/solid edges; groove and ridge recurse into two half-width borders. Flat, nonpositive or undersized borders omit the edges. Borrows the Tk border; does not allocate replacement colors.

static void PdfClearRectangle(Rbc_RenderContext *ctx, double x, double y, int width, int height)¶

Paint an opaque white rectangle.

Clearing document output means white paint, not erasing to transparency. Nonpositive dimensions are ignored by PdfRectangle.

static void PdfBackgroundRectangles(Rbc_RenderContext *ctx, const XColor *color, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Paint background rectangles in order.

NULL color selects opaque white; otherwise uses the supplied RGB color. Borrows the batch and does not retain geometry.

static void PdfPlotBegin(Rbc_RenderContext *ctx, Tk_Font font, double x, double y, int width, int height, const XColor *background)¶

Paint the plot background and open its clipping scope.

NULL background selects white. Ignores the font argument because text resolves its own resources. Emits q/re/W/n after painting; PdfPlotEnd balances this separate plot scope.

static void PdfPlotEnd(Rbc_RenderContext *ctx)¶

Close the saved plot clipping scope.

Requires a matching PdfPlotBegin. This Q is separate from common renderer clip-depth unwinding.

static void PdfSymbolPoints(Rbc_RenderContext *ctx, const Point2D *centers, Tcl_Size count)¶

Paint symbol centers with legacy size corrections and painter order.

Bar samples delegate to rectangle fills. Bitmap symbols acquire their source/mask once per batch, require matching mask dimensions when used, and release both XImages on completion or failure. Each center has a local transform; bitmap aspect ratio is preserved. Geometric symbols fill before outlining, skinny symbols only stroke, and cross variants rotate the plus geometry. Borrows style colors and handles throughout the call.

PostScript drawing callbacks¶

group PostScript drawing backend

Private renderer callbacks; components use the common renderer interface.

Functions

static void PostScriptClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)¶

Open a saved rectangular PostScript clip.

Emits gsave and a closed path followed by clip/newpath. Common renderer depth tracking owns pairing; PostScriptClipEnd closes this scope.

static void PostScriptClipEnd(Rbc_RenderContext *ctx)¶

Restore one rectangular PostScript clipping scope.

Emits grestore without changing common clip depth. Requires a matching begin.

static void PostScriptPolyline(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Stroke a connected path in bounded PostScript batches.

Fewer than two points is a no-op. Splits at 1500 path components and restarts at the shared vertex. Invokes the current DashesProc before each foreground stroke; caller ordering must preserve that document-level definition.

static void PostScriptSegments(Rbc_RenderContext *ctx, const Segment2D *segments, Tcl_Size count)¶

Delegate an independent segment batch to the legacy token.

Positive counts pass borrowed mapped geometry to Rbc_2DSegmentsToPostScript. Does not own points or establish a new line style.

static void PostScriptLineStyle(Rbc_RenderContext *ctx, int capStyle, int joinStyle)¶

Emit cap and join settings immediately.

Delegates to the legacy token conversion functions. Unlike PDF/SVG setters, this mutates the output graphics state rather than a cached style record.

static void PostScriptDashBackground(Rbc_RenderContext *ctx, const XColor *color)¶

Define the document’s dash-background procedure.

For a dashed stroke with a color, defines DashesProc to paint an undashed background inside gsave/grestore. Otherwise defines an empty procedure. Dictionary definitions are not scoped by gsave: emit a batch before another context changes this definition.

static void PostScriptFillPath(Rbc_RenderContext *ctx)¶

Paint the current path using legacy fill and stipple helpers.

Paints an optional background via the prolog Fill procedure, then selects foreground. backgroundOnly returns after that selection. Otherwise paints stipple or solid fill. Borrows graph/display and style resources; does not apply fill opacity or image tiles.

static void PostScriptFillPolygon(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Close and fill a supplied polygonal path.

Delegates path creation to the legacy token and fill policy to PostScriptFillPath. The caller supplies valid mapped geometry and retains its storage.

static void PostScriptArcPath(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Build an elliptical arc while restoring display-space line units.

Requires normalized nonzero arc geometry. Saves the current matrix on the operand stack, constructs a scaled unit-circle arc, then restores the matrix without losing the path. Negated angles preserve screen-space orientation. Closes full ellipses/chords and joins partial pieslices to the center.

static void PostScriptArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Stroke an arc with the current dash-background procedure.

Builds the path and invokes DashesProc before stroke. Does not independently establish line style.

static void PostScriptFillArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Fill an arc with the legacy fill policy.

Builds normalized geometry then delegates to PostScriptFillPath; does not emit an outline.

static void PostScriptFillRectangles(Rbc_RenderContext *ctx, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Paint mapped rectangles using legacy solid/stipple behavior.

Stipple fills paint optional background then foreground, falling back to background color when foreground is absent. Solid rectangles require foreground. This path does not implement image tiles or opacity, and does not share every polygon backgroundOnly rule.

static void PostScriptSymbolPoints(Rbc_RenderContext *ctx, const Point2D *centers, Tcl_Size count)¶

Emit centers using the context’s configured prolog macro.

Requires symbol setup to have selected a valid macro and size and defined DrawSymbolProc. Emits centers in order without retaining them or redefining the procedure.

static void PostScriptText(Rbc_RenderContext *ctx, char *string, TextStyle *style, double x, double y)¶

Delegate mapped text to the legacy PostScript text writer.

Borrows the string and TextStyle. Uses token font/color maps and legacy encoding, not the PDF/SVG document font pipeline.

static void PostScriptTkImage(Rbc_RenderContext *ctx, Tk_Image image, double x, double y)¶

Retain the legacy omission of non-photo Tk images.

Intentionally emits nothing. Photo markers use PostScriptPhoto; generic Tk-image raster capture is not attempted here.

static void PostScriptPhoto(Rbc_RenderContext *ctx, Tk_PhotoHandle photo, double x, double y)¶

Delegate a non-NULL photo to the legacy image writer.

Borrows the handle and emits at the supplied mapped origin. NULL is a no-op; does not use the PDF alpha-resource path.

static void PostScriptWindow(Rbc_RenderContext *ctx, Tk_Window tkwin, double x, double y)¶

Delegate window capture to the legacy PostScript writer.

Borrows the live window. Capture behavior and errors belong to Rbc_WindowToPostScript; this adapter does not introduce a clipping container.

static void PostScriptBackgroundPolygon(Rbc_RenderContext *ctx, const XColor *color, const Point2D *points, Tcl_Size count)¶

Select background color and emit a filled polygon.

Uses the token’s background/color-map policy and borrows the mapped point array. Does not establish an independent saved graphics scope.

static void PostScriptBorder(Rbc_RenderContext *ctx, Tk_3DBorder border, double x, double y, int width, int height, int borderWidth, int relief, int fill)¶

Dispatch filled or outline-only Tk relief output.

Borrows the border and delegates to the matching legacy 3D rectangle helper. Geometry and relief are already selected by the component.

static void PostScriptClearRectangle(Rbc_RenderContext *ctx, double x, double y, int width, int height)¶

Paint a rectangle using the token’s clear-background policy.

Clearing emits paint through legacy helpers; it does not remove prior document content.

static void PostScriptBackgroundRectangles(Rbc_RenderContext *ctx, const XColor *color, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Select one background and paint a rectangle batch.

NULL color uses the clear-background policy. Otherwise selects background once, then emits all borrowed rectangles in order.

static void PostScriptPlotBegin(Rbc_RenderContext *ctx, Tk_Font font, double x, double y, int width, int height, const XColor *background)¶

Paint plot background and open its saved clipping scope.

Selects the supplied font, constructs the region and paints via prolog Fill before gsave/clip. NULL background uses the token’s clear policy. PostScriptPlotEnd balances this plot scope.

static void PostScriptPlotEnd(Rbc_RenderContext *ctx)¶

Close the saved plot clipping scope.

Emits grestore separately from the common renderer’s explicit clip-depth mechanism. Requires a matching plot begin.

static void PostScriptBitmapMask(Rbc_RenderContext *ctx, Display *display, Pixmap bitmap, double x, double y, int width, int height, const XColor *color, int background)¶

Emit a translated and Y-corrected imagemask.

Missing bitmap or nonpositive dimensions produce no output. Selects foreground/background according to the flag, emits bitmap bytes through the legacy helper and balances gsave/grestore. Borrows display, pixmap and color.
