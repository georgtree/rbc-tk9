Track ownership C reference¶

Track records and private services are declared in rbcGrTrack.h. Static configuration helpers live in rbcGrTrack.c. See Track ownership and layout for the lifecycle, Coordinate mapping C reference for viewport scopes and Scrolling C reference for scroll notification.

RbcTrack *Rbc_FindTrack(Graph *graphPtr, const char *name)¶

Return a borrowed track by exact, case-sensitive name, or NULL.

Searches the owning graph list without creating or retaining an object. Reordering preserves the pointer; deletion or graph teardown invalidates it.

void Rbc_DestroyTracks(Graph *graphPtr)¶

Release all tracks during graph teardown, before destroying axes.

Removes track bindings, local grids and legends, then releases axis references, names and records. The caller must already have disposed of dependent elements and markers and retain the component cleanup resources. Unlike command deletion, this does not validate dependencies or redraw.

Tcl_Obj **Rbc_CreateTrackComponentArgs(Tcl_Size objc, Tcl_Obj *const objv[])¶

Allocate an argument vector for nested grid or legend dispatch.

Require objc >= 5 and the widget track component name operation form. The result has objc - 2 entries and owns only a newly retained list-valued command prefix at index 1; other entries borrow input objects. Release with Rbc_FreeTrackComponentArgs() before those borrowed arguments expire.

void Rbc_FreeTrackComponentArgs(Tcl_Obj **args)¶

Release the owned command prefix and array from Rbc_CreateTrackComponentArgs().

Borrowed argument objects are not decremented. Require a non-NULL result from that allocator and release it exactly once.

Functions

static int ConfigureTrack(Graph *graphPtr, RbcTrack *track, Tcl_Size objc, Tcl_Obj *const objv[])¶

Validate option pairs and axis dependencies before committing track settings.

Borrow the graph, track and arguments. A replacement axis array is temporary until every name, ownership rule and dependent component has been checked. Acquire new axis references before releasing old ones, including axes retained in both lists. On error, discard the temporary array and retain track settings. The caller synchronizes axis display order and schedules redraw after success.

static int InitTrackOptions(Graph *graphPtr, RbcTrack *track, Tcl_Size objc, Tcl_Obj *const objv[])¶

Resolve creation defaults through the named Track option-database component.

Explicit arguments override database values before ConfigureTrack validates the effective options. Temporary option objects and the option table are released on all exits. The caller owns the unlinked track and handles failed creation; this helper does not insert it into the graph.

static int OrderTracks(Graph *graphPtr, Tcl_Obj *namesObj)¶

Validate a complete permutation, then relink existing track objects.

Reject unknown, missing or duplicate names without changing the list. On success, preserve object identity and rebuild the track Y-axis display chain, marking the graph for remapping and eventual redraw. Borrow namesObj.

static int DeleteTracks(Graph *graphPtr, Tcl_Interp *interp, Tcl_Size objc, Tcl_Obj *const objv[])¶

Validate all requested tracks before unlinking any of them.

Duplicate names are ignored. Reject tracks still referenced by elements or markers. Successful deletion releases local components, bindings and axis references, then synchronizes the axis chain and schedules redraw. The enclosing command owns graph lifetime; this is not widget teardown.
