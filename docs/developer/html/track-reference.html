Track ownership C reference

Track records and private services are declared in rbcGrTrack.h. Static configuration helpers live in rbcGrTrack.c. See Track ownership and layout for the lifecycle, Coordinate mapping C reference for viewport scopes and Scrolling C reference for scroll notification.

RbcTrack *Rbc_FindTrack(Graph *graphPtr, const char *name)

Return a borrowed track by exact, case-sensitive name, or NULL.

Searches the owning graph list without creating or retaining an object. Reordering preserves the pointer; deletion or graph teardown invalidates it.

Parameters:

  • graphPtr – [in] Borrowed graph whose track list is searched.

  • name – [in] Required NUL-terminated exact track name; not retained.

void Rbc_DestroyTracks(Graph *graphPtr)

Release all tracks during graph teardown, before destroying axes.

Removes track bindings, local grids and legends, then releases axis references, names and records. The caller must already have disposed of dependent elements and markers and retain the component cleanup resources. Unlike command deletion, this does not validate dependencies or redraw.

Parameters:

  • graphPtr – [inout] Borrowed owning graph with live component resources on its Tk thread.

Tcl_Obj **Rbc_CreateTrackComponentArgs(Tcl_Size objc, Tcl_Obj *const objv[])

Allocate an argument vector for nested grid or legend dispatch.

Require objc >= 5 and the widget track component name operation form. The result has objc - 2 entries and owns only a newly retained list-valued command prefix at index 1; other entries borrow input objects. Release with Rbc_FreeTrackComponentArgs() before those borrowed arguments expire.

Parameters:

  • objc – [in] Number of input objects; must be at least five.

  • objv – [in] Borrowed full widget track component name operation argument array; keep its objects alive until the adapter is freed.
