SVG backend C reference

These static helpers belong to rbcRenderSvg.c. They borrow the export token; component callers use the renderer interface. See SVG definitions and image encoding.

Use SvgStrokeAttributes() and SvgFillPattern() for paint-state contracts, SvgString() for text escaping, and SvgPhotoBlock() for raster encoding. PNG helpers count bytes; geometry helpers count vertices, segments or rectangles. Emission is append-only and document errors remain separate from a helper’s return value.

group SVG backend internals

Private append-only output helpers borrowing the current export context.

Functions

static void SvgClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)

Emit a rectangular clip definition and open its clipped group.

Allocates an identifier from the document counter, not heap-owned clip geometry. SvgClipEnd emits the matching group close. Common renderer depth tracking owns pairing and unwind; this helper does not update depth.

Parameters:

  • ctx – Live SVG context borrowing the export token.

  • x – Mapped clip origin X.

  • y – Mapped clip origin Y.

  • width – Clip width supplied by the common clip dispatcher.

  • height – Clip height supplied by the common clip dispatcher.

static void SvgClipEnd(Rbc_RenderContext *ctx)

Close one rectangular clip group.

Common renderer clip-depth tracking owns pairing. This appends a closing tag only; it neither updates depth nor closes the separate plot scope.

Parameters:

  • ctx – [inout] Live Svg context with a matching rectangular clip scope; common depth is not changed here.

static void SvgString(Rbc_ExportContext *token, const char *string, Tcl_Size length)

Append XML-escaped Tcl UTF text to the current export buffer.
