SVG backend C reference¶

These static helpers belong to rbcRenderSvg.c. They borrow the export token; component callers use the renderer interface. See SVG definitions and image encoding.

group SVG backend internals

Private append-only output helpers borrowing the current export context.

Functions

static void SvgClipBegin(Rbc_RenderContext *ctx, int x, int y, int width, int height)¶

Emit a rectangular clip definition and open its clipped group.

Allocates an identifier from the document counter, not heap-owned clip geometry. SvgClipEnd emits the matching group close. Common renderer depth tracking owns pairing and unwind; this helper does not update depth.

Parameters:

  • ctx – Live SVG context borrowing the export token.

  • x – Mapped clip origin X.

  • y – Mapped clip origin Y.

  • width – Clip width supplied by the common clip dispatcher.

  • height – Clip height supplied by the common clip dispatcher.

static void SvgClipEnd(Rbc_RenderContext *ctx)¶

Close one rectangular clip group.

Common renderer clip-depth tracking owns pairing. This appends a closing tag only; it neither updates depth nor closes the separate plot scope.

static void SvgString(Rbc_ExportContext *token, const char *string, Tcl_Size length)¶

Append XML-escaped Tcl UTF text to the current export buffer.

Escapes the five XML metacharacters and checks decoded characters for disallowed controls, surrogate values and selected XML noncharacters. Records an export error on invalid content; already appended output is not rolled back. This is not an arbitrary binary-data encoder. Retains no input.

Parameters:

  • token – Borrowed initialized export context.

  • string – Borrowed readable Tcl UTF string.

  • length – Byte length, or negative for a NUL-terminated string.

static void SvgColor(Rbc_ExportContext *token, const XColor *color)¶

Append an SVG paint value.

A NULL borrowed color emits none. Otherwise the high eight bits of each Tk 16-bit RGB channel form a hexadecimal color; no alpha or allocation is involved.

static void SvgStrokeAttributes(Rbc_RenderContext *ctx, int underlay)¶

Append stroke attributes from retained export state.

The underlay uses the off-color and omits dashes. The foreground uses the configured color, width, cap, join and bounded zero-terminated dash array. Both explicitly disable fill.

static void SvgPolyline(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Emit a connected stroke, optionally over a solid dash background.

Counts below two emit nothing. Each pass repeats the borrowed mapped points without rounding. The solid underlay precedes the dashed foreground; geometry is not retained.

static void SvgSegments(Rbc_RenderContext *ctx, const Segment2D *segments, Tcl_Size count)¶

Emit independent segments through the polyline adapter.

Each borrowed segment becomes a two-point polyline, with its own underlay/foreground passes. This preserves per-segment painter order rather than batching all underlays first.

static void SvgPolygon(Rbc_ExportContext *token, const Point2D *points, Tcl_Size count, const XColor *color, double opacity)¶

Emit a solid even-odd polygon.

Fewer than three points emit nothing. Coordinates and opacity are supplied by the caller; NULL color means no paint. This does not add an outline, clamp opacity or retain geometry.

static void SvgFillPolygon(Rbc_RenderContext *ctx, const Point2D *points, Tcl_Size count)¶

Fill a polygon with the configured solid or pattern style.

Uses black when no foreground is supplied. Stipples and tiles use the context-local pattern definition without applying solid-fill opacity. A zero pattern identifier skips emission.

static void SvgArcPath(Rbc_ExportContext *token, const Rbc_RenderArcGeometry *arc)¶

Append the opening path element and ellipse arc geometry.

Requires normalized mapped geometry from common arc dispatch. Screen Y is inverted relative to mathematical angles. Full revolutions use two arcs and close without a radial seam; partial chord and sector paths close according to style. The caller appends paint attributes and the element terminator.

static void SvgArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Stroke normalized arc geometry with optional dash underlay.

Repeats the path for the solid off-color and dashed foreground when needed. Geometry remains borrowed; common dispatch validates and normalizes the arc before this callback.

static void SvgFillArc(Rbc_RenderContext *ctx, const Rbc_RenderArcGeometry *arc)¶

Fill a closed normalized arc using solid paint or a pattern.

Common dispatch excludes open arcs. Pattern definitions own their paint and do not receive solid- fill opacity. A missing pattern skips the path; solid paint uses the configured foreground directly.

static void SvgRectangle(Rbc_ExportContext *token, double x, double y, int width, int height, const XColor *color)¶

Append an unoutlined solid rectangle.

Nonpositive dimensions emit nothing. Double origins are preserved, dimensions are integers and NULL color emits none. No clipping or opacity is added here.

static void SvgFillRectangles(Rbc_RenderContext *ctx, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Emit configured rectangle fills in input order.

Skips nonpositive dimensions. Each rectangle may be wrapped in an opacity group and may reuse the context pattern. Pattern failure balances the current group before stopping the batch; previous output is retained.

static void SvgBitmapRuns(Rbc_ExportContext *token, XImage *bits, XImage *mask, const XColor *color)¶

Encode set bitmap pixels as horizontal vector runs.

Borrows readable XImages; a supplied mask must cover the same dimensions. NULL color emits nothing. Each row is scanned into unit-height closed subpaths, intersecting bits with the optional mask. Images remain owned by the caller.

static int SvgDefineBitmapSymbol(Rbc_RenderContext *ctx)¶

Read and define one reusable bitmap symbol.

Borrows Tk bitmap handles and owns temporary XImage readbacks. An explicit mask is read only with a fill color and must match bitmap dimensions. Records readback errors, releases images on all acquired paths and caches the document ID and dimensions on success.

static void SvgPngWord(unsigned char *bytes, unsigned int value)¶

Write one unsigned word in PNG network byte order.

The caller supplies four writable bytes. This only encodes the low 32 bits; it allocates nothing and performs no length validation.

static void SvgPngChunk(Tcl_DString *png, const char *type, const unsigned char *data, Tcl_Size length)¶

Append one PNG chunk including its CRC.

The caller supplies a four-byte chunk type, nonnegative 32-bit-representable length and readable data for nonempty payloads. The checksum covers type and data. The destination DString remains caller-owned.

static void SvgBase64(Rbc_ExportContext *token, const unsigned char *bytes, Tcl_Size length)¶

Append padded base64 without line breaks.

Borrows length readable bytes and writes directly to the export buffer in four-character groups. Empty input appends nothing; it neither retains data nor adds a URI prefix.

static void SvgPhotoBlock(Rbc_ExportContext *token, const Tk_PhotoImageBlock *block, double x, double y)¶

Encode a borrowed Tk photo block as an inline PNG image.

Empty dimensions emit nothing. Checks pixel storage and size limits; assumes RGB offsets/storage are supplied by a valid image producer. Copies straight-alpha RGBA scanlines, compresses with Tcl zlib and appends base64 PNG. A distinct valid alpha offset is used, otherwise alpha is opaque. Temporary Tcl objects and PNG storage are released; interpreter state is restored after compression. Failures record an export error, without rolling back output.

Parameters:

  • token – Borrowed export context and interpreter.

  • block – Readable Tk photo block with valid RGB channel offsets.

  • x – Image origin in mapped SVG coordinates.

  • y – Image origin in mapped SVG coordinates.

static void SvgColorImage(Rbc_ExportContext *token, Rbc_ColorImage image, double x, double y)¶

Adapt borrowed Pix32 storage to the PNG encoder.

Checks that the packed row pitch fits int, then describes actual channel offsets in a temporary Tk photo block. Encoding is synchronous; the caller retains ownership of the color image.

static void SvgTkImage(Rbc_RenderContext *ctx, Tk_Image image, double x, double y)¶

Capture a generic Tk image and encode it as PNG.

Uses the shared export raster service, which records capture failures. A successful temporary color image is freed after synchronous encoding, including when encoding records an error.

static unsigned int SvgFillPattern(Rbc_RenderContext *ctx, const XColor *foreground)¶

Define or reuse this context’s SVG tile/stipple pattern.

The cache is context-local and assumes an unchanged style. Tiles use photo pixels or captured image pixels; stipples use monochrome readback. Definitions append directly to the document and use its resource counter. A nonzero ID does not clear or exclude an encoding error recorded on token.

Parameters:

  • ctx – Live SVG context with configured fill style and graph.

  • foreground – Borrowed color used for stipple foreground runs.

Returns:

Cached/new pattern ID, or zero for unavailable/empty pattern data.

static void SvgSymbolPoints(Rbc_RenderContext *ctx, const Point2D *centers, Tcl_Size count)¶

Emit bar, bitmap or geometric symbols at borrowed centers.

Bar samples use translated rectangle fills. Bitmap samples lazily define one resource and preserve aspect ratio. Geometric symbols retain shape-specific sizing and rounding; skinny plus/cross symbols have no fill. Caller-provided symbol state remains unchanged.

static void SvgEmbeddedText(Rbc_RenderContext *ctx, char *string, TextStyle *style, double x, double y)¶

Emit positioned Unicode spans using embedded fallback faces.

Owns a temporary Tk-derived layout. Resolves glyphs before placement, extends zero-width Tk advances when a real fallback glyph has positive advance, and recomputes justification. Shadow precedes foreground. Registers faces on the shared token and frees layout on early failure or completion; font definitions are finalized separately.

static void SvgText(Rbc_RenderContext *ctx, char *string, TextStyle *style, double x, double y)¶

Select embedded or system-font SVG text output.

Nonembedded output evaluates the global Tcl font command, retains its attribute result across interpreter-state restoration, and owns a temporary layout. Escapes family and text, preserving Tk line widths through textLength. State restoration is not a guard against arbitrary mutations by a replaced font command; supplied widget and style resources must remain live.

static void SvgPhoto(Rbc_RenderContext *ctx, Tk_PhotoHandle photo, double x, double y)¶

Read a borrowed Tk photo and encode its current pixels.

Missing handles or failed block acquisition record export errors. The block is consumed synchronously by SvgPhotoBlock; no photo reference or pixel storage is retained.

static void SvgWindow(Rbc_RenderContext *ctx, Tk_Window window, double x, double y)¶

Capture a mapped window drawable for SVG output.

Unmapped or empty windows emit nothing. A successful native color-image capture is owned temporarily and freed after encoding. The caller owns window lifetime and placement; this does not create or resize widgets.

static void SvgBitmapMask(Rbc_RenderContext *ctx, Display *display, Pixmap bitmap, double x, double y, int width, int height, const XColor *color, int background)¶

Emit a mapped monochrome marker mask as vector runs.

Missing bitmap/color or nonpositive dimensions emit nothing. Owns and releases the XImage readback, records failure, and translates the run group to the supplied origin. The background flag is intentionally unused; the caller selects the color for each pass.

static void SvgBackgroundPolygon(Rbc_RenderContext *ctx, const XColor *color, const Point2D *points, Tcl_Size count)¶

Emit an opaque even-odd background polygon.

Delegates borrowed geometry and color to SvgPolygon. This supplies opacity one and no outline; NULL paint remains none.

static void SvgBorder(Rbc_RenderContext *ctx, Tk_3DBorder border, double x, double y, int width, int height, int borderWidth, int relief, int fill)¶

Approximate a Tk 3D border with SVG rectangles and polygons.

Borrows the border and forces lazy shadow-color initialization. Optional background fill precedes relief. Flat or too-small borders stop after filling; groove/ridge recurse as two half-width reliefs. Solid relief uses black edges. Dimensions must satisfy caller integer-arithmetic limits.

static void SvgClearRectangle(Rbc_RenderContext *ctx, double x, double y, int width, int height)¶

Paint an opaque white rectangle.

This is SVG background painting, not alpha erasure. Nonpositive dimensions are ignored by SvgRectangle and the temporary white color is consumed synchronously.

static void SvgBackgroundRectangles(Rbc_RenderContext *ctx, const XColor *color, const Rbc_RenderRectangle *rectangles, Tcl_Size count)¶

Paint background rectangles in input order.

A NULL color selects opaque white clearing; otherwise the supplied color is used. Borrowed rectangles are not retained and nonpositive sizes are skipped by the rectangle helper.

static void SvgPlotBegin(Rbc_RenderContext *ctx, Tk_Font font, double x, double y, int width, int height, const XColor *background)¶

Paint the plot background and open its plot clip group.

NULL background means white. Emits the document-local fixed rbcPlot identifier and ignores the font argument. This scope is paired by SvgPlotEnd, independently of common rectangular clip-depth tracking.

static void SvgPlotEnd(Rbc_RenderContext *ctx)¶

Close the plot group opened by SvgPlotBegin.

Appends one group close without changing common clip depth or finalizing the SVG document. The caller must balance plot and nested clip scopes.
