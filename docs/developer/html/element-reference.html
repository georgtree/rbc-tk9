Element data C reference¶

These interfaces are private. See Element data and dispatch for ownership and ordering.

Data slots¶

int Rbc_ParseElemVectorObj(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, ElemVector *candidatePtr)¶

Stage a real named vector or a list of numeric expressions.

Never pass a populated slot: initialization would discard its resources. Complex vectors are rejected here. Named data borrows storage and owns a client ID; literal data owns an allocated double array. No notification callback is installed and the live element is unchanged. Release an unused successful candidate with Rbc_FreeElemVector.

Parameters:

  • interp – Interpreter used for lookup, conversion and errors.

  • elemPtr – Borrowed element that will own the staged data.

  • objPtr – Borrowed option value; vector-name lookup precedes list parsing.

  • candidatePtr – Empty caller-owned slot overwritten by initialization.

Returns:

TCL_OK with owned candidate resources, or TCL_ERROR on failure.

void Rbc_FreeElemVector(ElemVector *vPtr)¶

Release an element data slot and zero its record.

Releases a named-vector client ID when present; otherwise frees the owned literal array. Does not destroy the source vector or free borrowed storage.

Parameters:

  • vPtr – Initialized slot or zeroed candidate owned by the caller.

Common data transactions¶

int Rbc_PrepareElemDataTransaction(Graph *graphPtr, Element *elemPtr, ElemDataTransaction *transactionPtr)¶

Stage common element data options without replacing live data.

Processes defaults during initial configuration and explicit options in their original argument order. Repeated options are each validated. Commit only after all other fallible component validation succeeds; otherwise free the transaction. The borrowed option argument vector must remain valid.

Parameters:

  • graphPtr – Borrowed owning graph and interpreter context.

  • elemPtr – Element with current configuration arguments and option state.

  • transactionPtr – Empty caller-owned transaction initialized by this call.

Returns:

TCL_OK with staged resources, or TCL_ERROR after freeing candidates.

Tcl_Size Rbc_ElemDataTransactionPointCount(Element *elemPtr, const ElemDataTransaction *transactionPtr)¶

Count the ordinary X/Y pairs after a proposed data transaction.

Does not commit data or invoke a type-specific polar point-count callback. Named sources use current vector lengths, including pending resizes; literal slots use stored counts. Does not refresh arrays or deliver notifications.

Parameters:

  • elemPtr – Borrowed element supplying unchanged live dimensions.

  • transactionPtr – Staged transaction, or NULL to use only live data.

Returns:

Minimum of the effective X and Y lengths.

void Rbc_CommitElemDataTransaction(Element *elemPtr, ElemDataTransaction *transactionPtr)¶

Transfer staged common data into the element’s stable member slots.

Replaced slots are released. Candidate ownership moves to the destination, named-vector callbacks are installed there, and stagedMask is cleared. No fallible validation or redraw scheduling is performed here.

Parameters:

  • elemPtr – Live destination element.

  • transactionPtr – Successfully prepared transaction to consume.

void Rbc_FreeElemDataTransaction(ElemDataTransaction *transactionPtr)¶

Release all remaining staged arrays and vector client IDs.

Zeros its slots and staged mask. Safe after commit, which has transferred ownership out of the candidates. Does not modify the live element.

Parameters:

  • transactionPtr – Initialized or zeroed caller-owned transaction.

void Rbc_SyncElemDataOptionObjects(Element *elemPtr)¶

Parameters:

static int ComplexDivide(double nr, double ni, double dr, double di, double *realPtr, double *imagPtr)¶

Divide finite complex inputs using a denominator component ratio.

Chooses the larger denominator component to form the ratio. Returns FALSE for nonfinite inputs, zero denominator or nonfinite computed output. Early rejection leaves outputs unchanged; final finiteness rejection can leave computed nonfinite outputs, so callers must honor the return value. This formulation does not guarantee overflow-free arithmetic for all finite extreme inputs. Borrows scalar inputs and writes only the output doubles.

Parameters:

  • nr – [in] Real numerator component.

  • ni – [in] Imaginary numerator component.

  • dr – [in] Real denominator component; the complex denominator must be nonzero.

  • di – [in] Imaginary denominator component.

  • realPtr – [out] Required real-quotient destination, distinct from imagPtr; consume only on TRUE.

  • imagPtr – [out] Required imaginary-quotient destination, distinct from realPtr; consume only on TRUE.

static int GammaToNormalizedImpedance(double gammaReal, double gammaImag, double *resistancePtr, double *reactancePtr)¶

Convert reflection coefficient to normalized impedance.

Computes (1 + gamma)/(1 - gamma) through ComplexDivide, except exact (+1, 0), which succeeds with (HUGE_VAL, 0) for an open circuit. TRUE therefore does not imply finite output. Failure follows ComplexDivide output rules. No physical reference-impedance scaling is performed here.

Parameters:

  • gammaReal – [in] Real component of the dimensionless reflection coefficient.

  • gammaImag – [in] Imaginary component of the dimensionless reflection coefficient.

  • resistancePtr – [out] Required real-part output in normalized units; may be positive infinity on a successful singular case. Consume only on TRUE.

  • reactancePtr – [out] Required separate imaginary-part output in normalized units; consume only on TRUE.

static int GammaToNormalizedAdmittance(double gammaReal, double gammaImag, double *conductancePtr, double *susceptancePtr)¶

Convert reflection coefficient to normalized admittance.

Computes (1 - gamma)/(1 + gamma) through ComplexDivide, except exact (-1, 0), which succeeds with (HUGE_VAL, 0) for a short circuit. TRUE therefore does not imply finite output. Physical admittance scaling belongs to the caller; failed division outputs must not be consumed.

Parameters:

  • gammaReal – [in] Real component of the dimensionless reflection coefficient.

  • gammaImag – [in] Imaginary component of the dimensionless reflection coefficient.

  • conductancePtr – [out] Required real-part output in normalized units; may be positive infinity on a successful singular case. Consume only on TRUE.

  • susceptancePtr – [out] Required separate imaginary-part output in normalized units; consume only on TRUE.

static void GenerateSpline(Graph *graphPtr, Line *linePtr, MapInfo *mapPtr)¶

Resample a continuous run as a function of mapped data X.

Requires a nonempty map with valid source indices and no internal breaks. Natural/quadratic smoothing uses screen X normally or screen Y when inverted. Reflects decreasing abscissas into increasing canonical coordinates without reordering source indices. Retains every knot and adds visible pixel samples; inserted samples inherit the starting knot’s source index.

Commits replacement arrays only after interpolation succeeds. Size/allocation or evaluator failures preserve the input and set effective smoothing to none. Early exits for fewer than three points, nonmonotonic/equal abscissas, an invisible interval or empty screen span leave both input and effective mode unchanged. Thus the effective flag alone does not prove smoothing occurred. Does not alter reqSmooth or report Tcl errors; break handling belongs to GenerateSplineRuns.

Parameters:

  • graphPtr – [in] Owning graph supplying current mapped plot bounds and orientation.

  • linePtr – [inout] Owning line element; effective smooth may fall back to none, while reqSmooth is retained.

  • mapPtr – [inout] Nonempty owned mapped geometry with parallel source indices. Successful replacement frees old arrays; failure retains them.

static void GenerateParametricSpline(Graph *graphPtr, Line *linePtr, MapInfo *mapPtr)¶

Resample a continuous run by source interval and local parameter.

Requires nonempty finite mapped geometry with parallel source indices and no internal breaks. Retains knots and adds samples approximately every two pixels along visible portions of original straight segments. Evaluation parameters identify the source interval and its normalized position; inserted samples report the interval’s starting source index.

Selects natural, quadratic or Catmull-Rom evaluation from effective smooth. Replaces point/index arrays only after successful evaluation. Size, allocation, capacity or evaluator failure frees candidates, retains original arrays and sets effective smoothing to none, leaving reqSmooth unchanged. Sample density uses the original segments, not an adaptive bound on the curved result.

Parameters:

  • graphPtr – [in] Owning graph supplying current mapped plot bounds and orientation.

  • linePtr – [inout] Owning line element; effective smooth may fall back to none, while reqSmooth is retained.

  • mapPtr – [inout] Nonempty owned mapped geometry with parallel source indices. Successful replacement frees old arrays; failure retains them.

static int ConfigureLine(Graph *graphPtr, Element *elemPtr)¶

Prepare and commit line-family derived configuration state.

Borrows a live element with Tk option candidates already installed and the changed-option mask/argument order available. Validates opacity and data-mode restrictions; stages common data, complex data, parameters, pens, axes, state, tags, styles, scalars and fill resources as required. Validates prospective parameter lengths and error-band smoothing, then configures the built-in pen.

Validates polar reference impedance before configuring the embedded pen or transferring staged state. Commits non-data transactions, synchronizes the first palette pen, then commits staged data. Successful completion sets mapping flags. The enclosing caller restores Tk options on error.

Error cleanup releases still-owned staged resources and returns TCL_ERROR. It does not undo already committed derived state, restore Tk options itself, or make application callbacks during parsing generally reentrant.

Parameters:

  • graphPtr – [inout] Borrowed owning graph; staged resource operations use its live window and interpreter, and commits may update graph state.

  • elemPtr – [inout] Live line-family core with Tk candidates and changed-option metadata installed; caller owns rollback of those Tk values on error.
