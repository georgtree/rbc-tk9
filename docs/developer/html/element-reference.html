Element data C reference¶

These interfaces are private. See Element data and dispatch for ownership and ordering.

Data slots¶

int Rbc_ParseElemVectorObj(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, ElemVector *candidatePtr)¶

Stage a real named vector or a list of numeric expressions.

Never pass a populated slot: initialization would discard its resources. Complex vectors are rejected here. Named data borrows storage and owns a client ID; literal data owns an allocated double array. No notification callback is installed and the live element is unchanged. Release an unused successful candidate with Rbc_FreeElemVector.

Parameters:

  • interp – Interpreter used for lookup, conversion and errors.

  • elemPtr – Borrowed element that will own the staged data.

  • objPtr – Borrowed option value; vector-name lookup precedes list parsing.

  • candidatePtr – Empty caller-owned slot overwritten by initialization.

Returns:

TCL_OK with owned candidate resources, or TCL_ERROR on failure.

void Rbc_FreeElemVector(ElemVector *vPtr)¶

Release an element data slot and zero its record.

Releases a named-vector client ID when present; otherwise frees the owned literal array. Does not destroy the source vector or free borrowed storage.

Parameters:

  • vPtr – Initialized slot or zeroed candidate owned by the caller.

Common data transactions¶

int Rbc_PrepareElemDataTransaction(Graph *graphPtr, Element *elemPtr, ElemDataTransaction *transactionPtr)¶

Stage common element data options without replacing live data.

Processes defaults during initial configuration and explicit options in their original argument order. Repeated options are each validated. Commit only after all other fallible component validation succeeds; otherwise free the transaction. The borrowed option argument vector must remain valid.

Parameters:

  • graphPtr – Borrowed owning graph and interpreter context.

  • elemPtr – Element with current configuration arguments and option state.

  • transactionPtr – Empty caller-owned transaction initialized by this call.

Returns:

TCL_OK with staged resources, or TCL_ERROR after freeing candidates.

Tcl_Size Rbc_ElemDataTransactionPointCount(Element *elemPtr, const ElemDataTransaction *transactionPtr)¶

Count the ordinary X/Y pairs after a proposed data transaction.

Does not commit data or invoke a type-specific polar point-count callback.

Parameters:

  • elemPtr – Borrowed element supplying unchanged live dimensions.

  • transactionPtr – Staged transaction, or NULL to use only live data.

Returns:

Minimum of the effective X and Y lengths.

void Rbc_CommitElemDataTransaction(Element *elemPtr, ElemDataTransaction *transactionPtr)¶

Transfer staged common data into the element’s stable member slots.

Replaced slots are released. Candidate ownership moves to the destination, named-vector callbacks are installed there, and stagedMask is cleared. No fallible validation or redraw scheduling is performed here.

Parameters:

  • elemPtr – Live destination element.

  • transactionPtr – Successfully prepared transaction to consume.

void Rbc_FreeElemDataTransaction(ElemDataTransaction *transactionPtr)¶

Release all remaining staged arrays and vector client IDs.

Zeros its slots and staged mask. Safe after commit, which has transferred ownership out of the candidates. Does not modify the live element.

Parameters:

  • transactionPtr – Initialized or zeroed caller-owned transaction.

Type dispatch signatures¶

The callback declarations and table are included directly to retain their exact C signatures. They borrow the graph and element; the table does not provide lifetime protection or make arbitrary Tcl callback reentry safe.

Configuration transaction internals¶

These helpers separate candidate preparation from live-field commit and from retained Tcl option representations. See Element data and dispatch for their differing failure and cleanup rules.

Functions

static void CommitElemVector(Element *elemPtr, ElemVector *destPtr, ElemVector *candidatePtr)¶

Move a parsed data slot into its stable element destination.

Parameters:

  • elemPtr – Live owner of the destination field.

  • destPtr – Initialized live slot to replace; distinct from candidatePtr.

  • candidatePtr – Successfully parsed slot whose ownership is transferred. Releases the old slot, copies the candidate and zeroes it. Installs the owning element and, for named-vector data, a change callback whose client data points to destPtr rather than temporary storage. Does not destroy the source vector, copy its numeric storage, or schedule redraw independently.

static ElemDataOption GetElemDataOption(Element *elemPtr, Tcl_Obj *objPtr)¶

Identify an element’s common data option after Tk validation.

Parameters:

  • elemPtr – Element with concrete optionSpecs.

  • objPtr – Borrowed original option-name object.

Returns:

The corresponding ElemDataOption, or NONE for unrelated/unresolved names. Uses Rbc_GetCanonicalOptionName so synonyms and accepted abbreviations resolve through the concrete table. Does not parse values, acquire resources or change state. Exact -x and -y names must retain precedence over longer data names.

Returns:

X or Y axis identity, or NONE for unrelated/unresolved names. Uses Rbc_GetCanonicalOptionName so synonyms and accepted abbreviations resolve through the concrete table. Does not parse values, acquire resources or change state. Exact -x and -y names must retain precedence over longer data names.

static int StageElemTags(Tcl_Interp *interp, Tcl_Obj *objPtr, ElemTagsTransaction *transactionPtr)¶

Replace a candidate tag list only after its successor parses.

Parameters:

  • interp – Interpreter for list syntax diagnostics.

  • objPtr – Borrowed tag-list object; NULL represents an empty list.

  • transactionPtr – Initialized transaction owning any earlier candidate.

Returns:

TCL_OK on staging; TCL_ERROR preserves the earlier candidate. Success frees the old candidate block, transfers the new single-block string list and sets staged even for an empty list. Does not modify live element tags or execute a binding script.

void Rbc_FreeElemTagsTransaction(ElemTagsTransaction *transactionPtr)¶

Release candidate binding tags and reset their transaction.

Parameters:

  • transactionPtr – Initialized transaction, possibly empty or already committed. Frees the owned string-list block if present and zeroes the complete record. Does not alter the element or free tags already transferred to it.

int Rbc_PrepareElemTagsTransaction(Graph *graphPtr, Element *elemPtr, ElemTagsTransaction *transactionPtr)¶

Validate every relevant binding-tag occurrence before element commit.

Parameters:

  • graphPtr – Live owning graph and interpreter.

  • elemPtr – Element with a validated, even optionObjv/optionObjc sequence.

  • transactionPtr – [out] Fresh transaction; any earlier owned candidate must already have been released before this function zeroes the record.

Returns:

TCL_OK on preparation; TCL_ERROR after freeing all staged tag storage. On initial configuration, processes the retained default only if not explicitly overridden. Then parses explicit occurrences in caller order, so a later valid value cannot hide an earlier invalid list. Live tags remain unchanged.

void Rbc_CommitElemTagsTransaction(Element *elemPtr, ElemTagsTransaction *transactionPtr)¶

Transfer a prepared tag-list block into the live element.

Parameters:

  • elemPtr – Live destination element owning its previous tags.

  • transactionPtr – Successfully prepared tags transaction. Does nothing unless staged. Otherwise moves tags (including NULL), clears the candidate and flag, then frees the old live block. No parsing or binding script execution occurs; subsequent transaction cleanup is safe.

int Rbc_PrepareElemStateTransaction(Graph *graphPtr, Element *elemPtr, ElemStateTransaction *transactionPtr)¶

Validate state values in their original configuration order.

Parameters:

  • graphPtr – Live graph supplying the error interpreter.

  • elemPtr – Element with an even validated option sequence.

  • transactionPtr – [out] Transaction reset before preparation.

Returns:

TCL_OK when all relevant values pass; TCL_ERROR on the first bad state. Uses the initial retained state only when not explicitly overridden, then checks every explicit occurrence. Does not change live state. Unlike owning resource transactions, failure may leave an earlier scalar candidate marked staged; there is nothing to free, but callers must not commit after TCL_ERROR.

void Rbc_CommitElemStateTransaction(Element *elemPtr, ElemStateTransaction *transactionPtr)¶

Install a successfully prepared scalar state.

Parameters:

  • elemPtr – Live destination element.

  • transactionPtr – Transaction whose preparation returned TCL_OK. Copies state only when staged, then clears staged. Performs no resource cleanup, redraw scheduling or binding repick; the configuration caller handles those.

static int StageElemAxis(Graph *graphPtr, Tcl_Obj *objPtr, ElemAxisTransaction *transactionPtr, Axis **candidatePtrPtr, ElemAxisOption option)¶

Acquire a replacement axis before releasing the staged predecessor.

Parameters:

  • graphPtr – Live graph containing the axis registry.

  • objPtr – Borrowed axis-name object; an empty name is not accepted.

  • transactionPtr – Initialized axis transaction.

  • candidatePtrPtr – Address of the candidate matching option.

  • option – X or Y; any other identity is an internal fatal error.

Returns:

TCL_OK after staging; TCL_ERROR retains the previous candidate. Rbc_GetAxisFromObj checks in-use orientation (or assigns the class of an unused axis) and acquires a reference without creating an absent axis. Success releases the earlier staged reference, stores the new one and sets its mask bit. Live element axes are unchanged.

void Rbc_FreeElemAxisTransaction(Graph *graphPtr, ElemAxisTransaction *transactionPtr)¶

Release owned candidate axes and clear their transaction.

Parameters:

  • graphPtr – Owning graph used for reference release.

  • transactionPtr – Initialized, partially prepared or committed transaction. Releases each non-NULL candidate independently, then zeroes the record. It does not release references transferred to live element fields by commit.

int Rbc_PrepareElemAxisTransaction(Graph *graphPtr, Element *elemPtr, ElemAxisTransaction *transactionPtr)¶

Resolve ordered element axis options into owned candidates.

Parameters:

  • graphPtr – Live owning graph.

  • elemPtr – Element with even validated configuration arguments.

  • transactionPtr – [out] Fresh transaction, zeroed before use.

Returns:

TCL_OK on preparation; TCL_ERROR after releasing all staged references. Initial mapx/mapy defaults are processed only when not explicitly overridden. Every explicit occurrence is then resolved in caller order. Failure does not change live mappings; successful output must be committed or freed.

void Rbc_CommitElemAxisTransaction(Graph *graphPtr, Element *elemPtr, ElemAxisTransaction *transactionPtr)¶

Move prepared axis references to the element and release old mappings.

Parameters:

  • graphPtr – Owning graph for release of replaced references.

  • elemPtr – Live destination element.

  • transactionPtr – Successfully prepared axis transaction. Only staged X/Y slots are replaced. Clears transferred pointers and then the mask, allowing later transaction cleanup. No lookup or parsing occurs here; reference release may destroy a delete-pending axis whose count reaches zero.

static int StageElemDataVector(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, ElemDataTransaction *transactionPtr, ElemVector *candidatePtr, ElemDataOption option)¶

Parse a data slot before discarding its previous candidate.

Parameters:

  • interp – Interpreter used by the data parser.

  • elemPtr – Live owning element.

  • objPtr – Borrowed vector-name or expression-list object.

  • transactionPtr – Initialized common-data transaction.

  • candidatePtr – Candidate slot corresponding to option.

  • option – Data identity whose mask bit tracks this slot.

Returns:

TCL_OK after transferring the parsed candidate, TCL_ERROR with the previous candidate intact. Frees a failed temporary candidate before returning. Named data owns a vector client ID; literal data owns an array. The parser can evaluate Tcl expressions, so caller-owned element and argument lifetimes must survive callbacks. This staging helper adds no preservation boundary.

static int StageElemDataPairs(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, ElemDataTransaction *transactionPtr)¶

Stage a paired data value as an atomic X/Y candidate replacement.

Parameters:

  • interp – Interpreter for pair parsing and expression errors.

  • elemPtr – Live owning element.

  • objPtr – Borrowed alternating coordinate-expression list.

  • transactionPtr – Initialized common-data transaction.

Returns:

TCL_OK after replacing both staged slots; TCL_ERROR preserves both previous candidates. Failure frees both temporary slots. Success frees earlier staged X/Y records only after pair parsing succeeds, moves the new records and sets both mask bits. Live coordinates remain unchanged. Parsing can run Tcl.

static void ReplaceElemOptionObject(Tcl_Obj **objPtrPtr, Tcl_Obj *newObjPtr)¶

Replace one owned Tcl option-object reference.

Parameters:

  • objPtrPtr – Address of a retained object pointer, possibly NULL.

  • newObjPtr – Borrowed replacement object, or NULL to clear the field. Identical pointers are a no-op. Otherwise retains the new object before storing it and releasing the old reference. Does not copy contents, evaluate scripts or change internal numeric data.

static void SetElemDataPairOptionObjects(Element *elemPtr, Tcl_Obj *dataObjPtr)¶

Retain paired data and derive coherent X/Y option representations.

Parameters:

  • elemPtr – Element whose dataObjPtr, xObjPtr and yObjPtr are replaced.

  • dataObjPtr – Borrowed, already validated even-length coordinate list. Builds new X/Y lists using the original element objects, preserving expression spellings instead of reconstructing them from doubles. Retains all three results through ReplaceElemOptionObject. Invalid list structure or failure to assemble output is an internal Tcl_Panic, not a recoverable user error. Must run only after successful data validation; does not evaluate expressions.

void Rbc_SyncElemDataOptionObjects(Element *elemPtr)¶

Synchronize retained coordinate options after successful data commit.

Parameters:

  • elemPtr – Configured element with even, still-valid option arguments. Processes non-overridden initial defaults in data/X/Y order, then explicit arguments in caller order. A data occurrence sets coherent data/X/Y objects; an independent X or Y clears data and replaces that coordinate representation. Pins initial objects while replacing fields, then releases those temporary references. Does not rebuild numeric arrays or evaluate expressions. Call while optionsConfigured still identifies first configuration when applicable.
