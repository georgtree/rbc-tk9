PostScript token C reference¶

These private services are declared in rbcPs.h and implemented in rbcPs.c. See PostScript output and drawing state for ownership and prolog requirements.

PsToken Rbc_GetPsToken(Tcl_Interp *interp, Tk_Window tkwin)¶

Allocate an empty, color-mode PostScript token.

The caller owns the token and releases it with Rbc_ReleasePsToken(). The interpreter and window are borrowed; this function does not preserve them. Font and color mapping variable names initially are NULL.

void Rbc_ReleasePsToken(PsToken psToken)¶

Release a non-NULL token and its output buffer.

Borrowed interpreter, window and mapping variable names are not released. All pointers returned into the token become invalid.

char *Rbc_PostScriptFromToken(PsToken psToken)¶

Return the borrowed, NUL-terminated output buffer.

Do not free the result. Appending output may relocate it; releasing the token invalidates it. This accessor does not finalize a document.

char *Rbc_ScratchBufferFromToken(PsToken psToken)¶

Return borrowed mutable scratch storage of PSTOKEN_BUFSIZ + 1 bytes.

Formatting and prolog reads reuse this storage. It is not the output buffer and must not be retained across those operations or token release.

void Rbc_AppendToPostScript(PsToken, ...)¶

Append a sequence of NUL-terminated strings, ending with a NULL pointer.

Strings are copied without escaping. Callers supply PostScript syntax and must not pass binary data or pointers invalidated by output growth.

void Rbc_FormatToPostScript(PsToken, const char*, ...)¶

Append printf-formatted PostScript, using scratch storage or a temporary allocation when the formatted result exceeds the scratch capacity.

This void helper does not report a formatting failure to the interpreter. It performs no PostScript string escaping.

void Rbc_AppendPostScriptString(PsToken psToken, const char *string, Tcl_Size length)¶

Append escaped PostScript literal-string contents from Tcl UTF text.

A negative length selects strlen; otherwise length is a byte count ending at a character boundary. NULL input is ignored. The caller supplies the surrounding parentheses. Delimiters, controls and non-ASCII characters use octal escapes; characters above ISO-8859-1 are replaced with a space.

int Rbc_FileToPostScript(PsToken psToken, char *fileName)¶

Append a text prolog from fileName relative to the rbc::library variable.

Return TCL_ERROR for library lookup, open or read failure, with an interpreter diagnostic; otherwise return TCL_OK. Partial output is not rolled back. The channel is closed, but its close status is not propagated. Reads overwrite token scratch storage. Tcl variable and channel operations may execute callbacks; the enclosing export owns lifetime protection.

Functions

static void XColorToPostScript(struct PsTokenStruct *tokenPtr, XColor *colorPtr)¶

Append three normalized RGB operands from a borrowed XColor.

Uses only the upper eight bits of each 16-bit component, divided by 255. Emits no color-setting operator and performs no variable lookup.

void Rbc_BackgroundToPostScript(struct PsTokenStruct *tokenPtr, XColor *colorPtr)¶

Append mapped background code or RGB operands followed by SetBgColor.

If colorVarName is set, look up the color name in that Tcl array and append a found value verbatim, bypassing the default operator. Missing entries fall back to RGB conversion. Variable reads may run traces; the enclosing caller must protect token, interpreter and borrowed input lifetimes. This void helper neither reports lookup failure nor rolls back output.

void Rbc_ForegroundToPostScript(struct PsTokenStruct *tokenPtr, XColor *colorPtr)¶

Append mapped foreground code or RGB operands followed by SetFgColor.

Uses the same optional Tcl color-array lookup as background output, with the same trace/lifetime requirements. Found values are executable source, not escaped color names. Otherwise the prolog controls color, greyscale and monochrome conversion. No graphics-state save is emitted.

void Rbc_ClearBackgroundToPostScript(struct PsTokenStruct *tokenPtr)¶

Select white through the prolog background-color operator.

Appends SetBgColor operands only; it does not erase or fill any region. It bypasses the optional Tcl color map and does not restore prior color.

void Rbc_CapStyleToPostScript(struct PsTokenStruct *tokenPtr, int capStyle)¶

Append an X11-to-PostScript line-cap conversion.

CapNotLast and CapButt both map to butt; positive X11 values are reduced by one. The caller supplies a valid cap enumeration; no range validation or graphics-state restoration is performed.

void Rbc_JoinStyleToPostScript(struct PsTokenStruct *tokenPtr, int joinStyle)¶

Append the join enumeration directly to setlinejoin.

X11 and PostScript share miter=0, round=1 and bevel=2. The caller must supply a valid enumeration; the previous setting is not restored.

void Rbc_LineWidthToPostScript(struct PsTokenStruct *tokenPtr, int lineWidth)¶

Append an integer line width, clamped to at least one.

Zero and negative inputs become one rather than a PostScript hairline. Width is expressed in the current user coordinate system.

void Rbc_LineDashesToPostScript(struct PsTokenStruct *tokenPtr, Rbc_Dashes *dashesPtr)¶

Append a zero-terminated byte dash list with zero phase.

A NULL pointer or empty values array emits a solid-line dash array. A non-NULL values array must contain a zero terminator. The stored dash offset is not emitted; this helper always uses phase zero.

void Rbc_LineAttributesToPostScript(struct PsTokenStruct *tokenPtr, XColor *colorPtr, int lineWidth, Rbc_Dashes *dashesPtr, int capStyle, int joinStyle)¶

Append join, cap, foreground, width and dashes in that order.

Borrows all inputs and inherits the foreground color-map callback boundary. Finally defines an empty DashesProc in the current dictionary. This is not a scoped state change; subsequent strokes use the emitted attributes.

void Rbc_RectangleToPostScript(struct PsTokenStruct *tokenPtr, double x, double y, int width, int height)¶

Append a Box followed by the built-in fill operator.

Receives already mapped coordinates and dimensions. The prolog Box starts a fresh closed path; fill consumes it. No color, clipping or validation is added, and no outline is stroked.

void Rbc_RegionToPostScript(struct PsTokenStruct *tokenPtr, double x, double y, int width, int height)¶

Append a fresh closed rectangular path without painting it.

Uses the prolog Box procedure. The caller decides whether to fill, stroke or clip the resulting path and supplies valid mapped dimensions.

void Rbc_PathToPostScript(struct PsTokenStruct *tokenPtr, Point2D *screenPts, Tcl_Size nScreenPts)¶

Append a new open path from borrowed floating-point vertices.

A nonpositive count appends nothing and leaves the prior path untouched. For a positive count, screenPts must contain that many points. Emits one moveto and remaining lineto operations, with no stroke, close, clipping or path-size splitting. Numeric inputs must be suitable for PostScript.

void Rbc_PolygonToPostScript(struct PsTokenStruct *tokenPtr, Point2D *screenPts, Tcl_Size nScreenPts)¶

Close and fill a borrowed floating-point polygon through Fill.

Nonpositive counts append nothing. Otherwise builds a fresh path, adds an explicit line back to the first point, closes it and calls the prolog Fill procedure. Unlike built-in fill, Fill preserves the path. This helper does not validate polygon area, split large paths or select a color.

void Rbc_SegmentsToPostScript(struct PsTokenStruct *tokenPtr, XSegment *segPtr, int nSegments)¶

Append independent integer segments with DashesProc stroke.

Borrows nSegments XSegment entries; nonpositive counts append nothing. No initial newpath is emitted, so callers must ensure there is no pending path to stroke along with the first segment. Requires DashesProc to be defined. Each stroke consumes its path and restarts the dash pattern.

void Rbc_RectanglesToPostScript(struct PsTokenStruct *tokenPtr, XRectangle rectArr[], int nRects)¶

Fill each borrowed integer rectangle with the current color.

Delegates each entry to Rbc_RectangleToPostScript; nonpositive counts append nothing. No outline, color selection or clipping is supplied.

void Rbc_Draw3DRectangleToPostScript(struct PsTokenStruct *tokenPtr, Tk_3DBorder border, double x, double y, int width, int height, int borderWidth, int relief)¶

Append the border bands of a Tk relief rectangle.

Borrows a live border and the token window. Requires nonnegative bounded dimensions and borderWidth with representable integer arithmetic. Returns without output if either dimension is smaller than twice borderWidth. Initializes Tk shadow colors before querying them. Groove and ridge use two recursive half-width relief bands; raised and sunken swap light/dark top-left and bottom-right colors. Other cases retain the existing solid or background-color selection. Emits bottom/right rectangles and a top/left polygon; does not fill the whole interior or restore color/path. Color-map reads inherit the enclosing export callback requirements.

void Rbc_Fill3DRectangleToPostScript(struct PsTokenStruct *tokenPtr, Tk_3DBorder border, double x, double y, int width, int height, int borderWidth, int relief)¶

Fill the background rectangle, then append its relief border.

Borrows the border and token window. Selects its background with SetBgColor semantics before the fill, then delegates border geometry to Rbc_Draw3DRectangleToPostScript. Inherits that helper arithmetic and lifetime requirements; border omission does not undo the initial fill.

void Rbc_LineToPostScript(struct PsTokenStruct *tokenPtr, XPoint *pointPtr, int nPoints)¶

Append a stroked integer polyline with bounded path batches.

Counts below two are no-ops, without reading the point array or changing the output. Otherwise pointPtr must contain nPoints readable entries. Starts a new path, then emits DashesProc stroke at each PS_MAXPATH boundary and restarts at the shared endpoint. Stroke boundaries retain connected positions but restart stroke/dash processing. Requires a previously defined DashesProc; borrows the array.

void Rbc_2DSegmentsToPostScript(PsToken psToken, Segment2D *segPtr, Tcl_Size nSegments)¶

Append independent floating segments after clearing any pending path.

Nonpositive counts append nothing. Otherwise starts with newpath, then emits each segment followed by DashesProc stroke. This prevents a path retained by Fill from being stroked accidentally. Requires a defined DashesProc and a readable borrowed array of nSegments entries. No numeric validation, clipping or state restoration is performed.
