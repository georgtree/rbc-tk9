void Rbc_FontToPostScript(struct PsTokenStruct *tokenPtr, Tk_Font font)

Append a PostScript font name and size using the legacy fallback chain.

Borrows the token and Tk font. A found font-map array entry takes priority: its first list element supplies the raw font name; exactly two elements with an integer second element supply the size. Otherwise size remains twelve, including one-element entries. Parse errors do not stop output. Without a mapped entry, recognized family prefixes use Tk_PostscriptFontName. Other X11 families attempt XLoadQueryFont and property-based mapping, freeing the loaded font after copying its name into a temporary DString. Windows skips this attempt. Final fallback is Helvetica-Bold, normally at size twelve. Releases temporary Tcl descriptions, split lists and DStrings. No glyphs are embedded. Variable reads can execute traces; enclosing export code owns callback lifetime protection. This void helper does not report failure.

Parameters:

  • tokenPtr – [inout] Live borrowed PostScript token receiving output; caller owns document framing, prolog and lifetime.

  • font – [in] Borrowed Tk font, kept valid across optional font-map variable traces; no program is embedded.

Append nonempty layout fragments as adjusted PostScript text.

Borrows a live token and layout. Empty fragments are skipped, avoiding the prolog division by string length. Each other fragment uses escaped Latin-1 literal contents and its measured width with DrawAdjText. Coordinates add x/y to fragment baselines in Tcl_WideInt and emit the full sum, avoiding signed int overflow. Does not choose fonts, colors or transforms.

  • y – [in] Vertical offset added to fragment baselines using wide arithmetic.

Append anchored, optionally shadowed text under a saved transform.

NULL or empty strings append nothing. Borrows the string, style and Tk resources; allocates and frees a temporary layout. Requires finite bounded geometry and angles compatible with FMOD and ROUND.
