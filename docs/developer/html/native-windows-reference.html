Windows native backend C reference¶

Windows contracts use a separate Doxygen XML project so identical backend function and structure names cannot merge with the X11 implementation.

group Windows native backend

Private Windows implementation; extracted separately from X11 namesakes.

Functions

Tcl_Size Rbc_NativePolygonPointLimit(Graph *graphPtr)¶

Return the Windows component-level polygon allowance.

Returns TCL_SIZE_MAX, without an X11 request-size bound. Actual drawing still validates the count against INT_MAX and available workspace.

void Rbc_NativePolyline(Rbc_NativeTrace *ctx, const Point2D *screenPts, Tcl_Size nPoints)¶

Stroke connected mapped points through a retained Windows DC.

Borrows the trace context and input. NULL context/points or fewer than two points is a no-op. Converts coordinates to int and repeats the previous endpoint in continuation chunks. Uses preallocated POINT workspace; Polyline return values are not propagated.

void Rbc_NativeStrips(Graph *graphPtr, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size nSegments)¶

Draw independent two-point strips with one DC acquisition.

Owns bounded POINT and DWORD count buffers. Narrow strokes use up to 8192 segments per PolyPolyline call; wide strokes use 680. Converts endpoints to LONG, selects a GC-derived pen and raster operation, restores/deletes the selected pen and releases DC state. Allocation failure skips output; GDI drawing failures are not reported through this void interface.

Rbc_NativeTrace *Rbc_NativeBeginTrace(Graph *graphPtr, Drawable drawable, GC gc)¶

Allocate a Windows trace context and acquire its drawing state.

Borrows graph, target and GC; owns trailing POINT workspace, acquired DC state and selected pen/brush. Wide strokes use base capacity 100; narrow strokes use request-derived capacity, with one extra continuation slot. Returns NULL for capacity/allocation failure. DC and GDI object acquisition failures are not separately validated here. EndTrace must release the context.

void Rbc_NativeEndTrace(Rbc_NativeTrace *ctx)¶

Restore and release a Windows trace batch.

Accepts NULL. Reselects the saved pen/brush, deletes the displaced batch objects, releases acquired DC state and frees the combined context buffer. Does not free the borrowed graph, drawable or GC.

static int GetCirclePathTemplate(HDC dc, int radius, POINT **pointsPtrPtr, BYTE **typesPtrPtr, int *nPointsPtr)¶

Obtain reusable ellipse geometry generated by GDI itself.

Initializes outputs to NULL/zero. Builds an Ellipse path in the borrowed DC using diameter 2*radius+1 and copies GetPath points/types to owned arrays. Aborts the temporary path after extraction. Returns FALSE on invalid radius, path failure or allocation failure, releasing partial arrays. On success the caller owns both arrays; radius arithmetic must be representable.

static void LoadCirclePath(POINT *dstPoints, BYTE *dstTypes, const POINT *templatePoints, const BYTE *templateTypes, int nTemplatePoints, LONG x, LONG y, int radius)¶

Translate one ellipse template into caller-owned batch storage.

Borrows template arrays and copies point types unchanged. Translates points by center minus radius. Caller provides capacity for nTemplatePoints and representable LONG coordinates; no allocation or validation occurs.

static void DrawCircleCentersDirect(HDC dc, const POINT *centers, int nCenters, int radius)¶

Draw buffered circles individually using Ellipse.

Borrows DC and centers and preserves the existing radius-plus-one far edge. Used to replay a failed copy-compatible batch. Does not own GDI state or report individual drawing failures.

static int DrawCirclePathBatch(HDC dc, const POINT *points, const BYTE *types, int nPoints, int doFill, int doOutline)¶

Render a combined circle path or outline batch.

Outline-only calls PolyDraw directly. Filled batches bracket PolyDraw in BeginPath/EndPath, then use FillPath or StrokeAndFillPath. Returns the GDI success result; aborts failed construction paths. Caller owns DC, arrays and selected pen/brush and decides whether replay is safe.

void Rbc_NativeCircles(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int radius)¶

Draw Windows circle symbols with guarded path batching.

Borrows style/centers and advances interval counters for examined centers. Owns template/batch arrays, DC acquisition and non-stock pen/brush objects. Batching requires GXcopy for participating GCs and equal fill/outline colors when both are used. Filled batches contain at most 32 circles; outlines use 512, or 64 for wide pens. Setup failure selects individual Ellipse drawing; failed copy batches replay their buffered centers. Restores fill mode and selected objects and frees temporary resources. No Tcl error is produced.

void Rbc_NativeSquares(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int r)¶

Convert selected squares to closed polygon symbols.

Allocates five XPoints per input center, including a repeated first vertex. Subtracts radius before short conversion. Positive intervals update the style counter even for skipped centers. Delegates selected squares to Rbc_NativePolygonSymbols and frees storage; invalid/empty output or allocation failure is ignored.

static void LoadPolygonBatch(POINT *points, const XPoint *polygons, Tcl_Size first, Tcl_Size count, int stride, int nPoints)¶

Pack selected XPoint polygons into Windows POINT storage.

Borrows source and destination arrays. Source stride includes closure; nPoints chooses fill vertices without closure or the complete outline. Copies count polygons starting at first, widening existing short values to LONG. Caller ensures all bounds and destination capacity.

void Rbc_NativePolygonSymbols(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, const XPoint *polygons, Tcl_Size nPolygons, int stride, int nVertices)¶

Fill polygon symbols, then draw their closed outlines.

Owns bounded point/count arrays and one acquired DC. Copy fills use WINDING and small PolyPolygon batches; non-copy fills preserve per-polygon effects. Outlines use larger PolyPolyline batches only for GXcopy, otherwise each outline is drawn separately. Failed copy batches replay individual shapes. Restores fill mode and selected GDI objects, deletes owned brushes/pens and releases all buffers. Interval selection is the shared caller’s responsibility.

int Rbc_NativePolygonPointCount(Display *display, Tcl_Size nPoints)¶

Validate a polygon count for the GDI int interface.

Returns zero for fewer than three vertices or counts above INT_MAX; otherwise returns the int count. Does not enforce an X11 request limit or inspect coordinate geometry.

static void DrawWin3DRectangle1(HDC dc, const Rbc_Win3DBorderColors *colorsPtr, int x, int y, int width, int height, int relief)¶

Reproduce a one-pixel Tk raised or sunken rectangle bevel.

Borrows DC and extracted colors. Clamps the bevel for tiny rectangles. Draws left, right, top and bottom strips in Tk order; unsupported relief draws nothing. Does not acquire a DC or retain color resources.

static void DrawWinRbcOuter3DBorder(HDC dc, const Rbc_Win3DBorderColors *colorsPtr, int x, int y, int width, int height, int relief)¶

Draw the RBC-specific outer layer of a two-pixel bevel.

Requires dimensions greater than two; supports raised/sunken relief only. Uses the historical flat/light/dark color selection and right, top, bottom, left drawing order. Borrows DC and colors without allocating state.

static int Clamp3DBorderWidth(int width, int height, int borderWidth)¶

Clamp a requested bevel to half each rectangle dimension.

Returns the effective width using the same sequential width/height checks as Tk. Callers supply positive bounded dimensions and border widths.

int Rbc_NativeBarBorders(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, const Rbc_RenderRectangle *rectangles, Tcl_Size nRects)¶

Batch supported Windows bar bevels through one DC.

Handles raised/sunken border widths one and two; returns FALSE for other configurations so the shared caller can use ordinary relief drawing. Skips nonpositive rectangles and reproduces tiny-rectangle width clamping. Borrows border/colors and releases the acquired DC. TRUE means configuration handled, not verified success of every GDI drawing operation.

void Rbc_NativeBarRectangles(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, XRectangle *rectangles, int nRects)¶

Try optimized opaque-stipple bar fills before Xlib fallback.

Borrows prepacked rectangles and style GC. If the Windows stipple helper declines, sends the same batch to XFillRectangles. Caller bounds the request.

Rbc_NativePolygonBatch *Rbc_NativeBeginPolygonBatch(Graph *graphPtr, Drawable drawable, GC gc, Tcl_Size maxPoints)¶

Acquire a reusable fill-only Windows polygon context.

Validates positive workspace capacity and allocation size. Owns point workspace, solid brush and DC state; selects a stock null pen and the GC fill rule. Returns NULL for invalid capacity, workspace or brush failure. Later DC/selection failures are not separately checked. Borrows graph/GC; a successful context requires Rbc_NativeEndPolygonBatch.

void Rbc_NativeBatchPolygon(Rbc_NativePolygonBatch *batch, const Point2D *points, Tcl_Size count)¶

Fill one polygon using retained Windows batch state.

Requires a live context and valid point array. Rejects unsupported count or count exceeding workspace capacity. Deliberately converts through short before LONG to preserve the original polygon path. Does not propagate Polygon failure or retain input points.

void Rbc_NativeEndPolygonBatch(Rbc_NativePolygonBatch *batch)¶

Restore and free a live Windows polygon batch.

Requires non-NULL context. Restores fill mode and stock/previous selections, deletes the owned brush, releases DC state and frees workspace/context.

size_t Rbc_NativeClipStateSize(void)¶

Return extra Windows state size for a shared clip frame.

The common allocator reserves this payload immediately after its frame. Ownership remains with the shared clip stack.

int Rbc_NativePlatformClip(Graph *graphPtr, Drawable parent, int left, int top, int right, int bottom, void *clientData, Drawable *drawablePtr)¶

Install a Windows meta-region clip on an acquired parent DC.

Initializes caller-owned state, acquires DC, saves it and intersects bounds. Promotes the clip to a meta region so bitmap mask changes cannot bypass it. Caller must initialize the output drawable to None. Returns TRUE even on setup failure; a missing output means skip drawing, not scratch fallback. Every call requires PlatformUnclip, including partial setup failures.

void Rbc_NativePlatformUnclip(void *clientData, Drawable drawable)¶

Unwind complete or partial Windows clip setup.

Frees a non-None borrowed-DC wrapper, restores saved DC state when present and releases the acquisition record. Does not free the enclosing shared frame or own the parent drawable.

void Rbc_NativeRun(Graph *graphPtr, Drawable drawable, void *data, Tcl_Size count, Rbc_RenderRunProc *proc)¶

Run a callback through one temporary Windows drawable wrapper.

Ignores NULL data or nonpositive count. Acquires a DC and wraps it for one synchronous callback; acquisition/wrapping failure invokes the callback on the original drawable instead. Releases wrapper and DC after the call. Callback must be valid, preserve borrowed resource lifetime and not retain the temporary target. This is not a Tcl evaluation boundary.

int Rbc_NativeOpaqueBitmapRun(Graph *graphPtr, Drawable drawable, Pixmap bitmap, GC gc, int width, int height, const Rbc_RenderPosition *positions, Tcl_Size count)¶

Delegate opaque bitmap batching to the Windows compatibility layer.

Returns Rbc_WinCopyOpaqueBitmapBatch’s handled/fallback result unchanged. Borrows target, bitmap, GC and positions; the shared caller owns replay policy and requires copy-compatible input.

struct Rbc_NativeTrace¶

Windows trace allocation with trailing POINT workspace.

Borrows graph/GC/target, owns DC acquisition and selected pen/brush, and retains prior selections for restoration by EndTrace.

struct Rbc_NativePolygonBatch¶

Fill-only polygon context owning point workspace, brush and DC state.

Retains prior brush, pen and fill mode for restoration. Component callers remain responsible for style grouping and painter order.

struct NativeDCClip¶

Windows clip payload stored after the shared clip frame.

Owns the acquisition record and tracks a SaveDC token. The parent drawable remains borrowed; PlatformUnclip handles partial initialization.

Tk Windows resource boundary¶

These compatibility services confine private Tk drawable/DC representations to rbcWinDraw.c. Components use the renderer interface rather than these helpers.

group Windows drawing resource helpers

Drawable wrappers, acquisition records, raster fast paths and GC conversion.

Functions

Drawable Rbc_WinCreateDrawableFromDC(HDC dc)¶

Wrap a borrowed HDC as a Tk-compatible drawable.

Returns None for NULL DC; otherwise allocates a TkWinDC wrapper. Caller releases only this wrapper with Rbc_WinFreeDrawableFromDC. Underlying DC ownership and restoration stay with the caller.

void Rbc_WinFreeDrawableFromDC(Drawable drawable)¶

Free an owned HDC drawable wrapper.

Accepts None. The argument must come from Rbc_WinCreateDrawableFromDC; this does not release or destroy the underlying HDC.

Window Rbc_WinWindowFromHWND(HWND hWnd)¶

Wrap an HWND in static Tk window storage.

Returns a borrowed Window valid only until the next call. Does not create a Tk window, own the HWND or allocate a persistent wrapper. The static record is overwritten on each call and is not independent per thread.

HDC Rbc_WinAcquireDrawableDC(Display *display, Drawable drawable, Rbc_WinDrawableDC **statePtrPtr)¶

Acquire a drawable DC and allocate its release record.

Requires valid output storage. Always returns an owned state record through statePtrPtr, including when the returned DC is NULL. Release that record with Rbc_WinReleaseDrawableDC. The record contains private Tk DC state; callers separately restore GDI objects/state they explicitly change.

void Rbc_WinReleaseDrawableDC(Rbc_WinDrawableDC *statePtr)¶

Release Tk drawable state and its RBC acquisition record.

Accepts NULL. Calls TkWinReleaseDrawableDC only for a non-NULL acquired DC, then frees the record even after failed acquisition. Must be called once for each acquisition record; does not destroy the drawable.

void Rbc_WinSetROP2(HDC dc, int function)¶

Select the DC raster operation from the compatibility table.

Requires an X graphics-function index in the table range. Changes the borrowed DC without saving its prior ROP2 value; no range check or GDI error result is provided.

Pixmap Rbc_WinCreatePixmapFromBitmap(HBITMAP hBitmap, int depth, Colormap colormap)¶

Wrap a native bitmap in Tk pixmap representation.

Returns None for NULL HBITMAP; otherwise allocates a TkWinBitmap record with the supplied depth and colormap. The result participates in normal Tk pixmap destruction, including bitmap deletion. Do not independently delete the bitmap while the wrapper remains live.

HBITMAP Rbc_WinGetPixmapHandle(Pixmap pixmap)¶

Return the borrowed native bitmap handle of a Tk pixmap.

Returns NULL for None or a non-bitmap drawable. The returned handle remains owned by the pixmap; no reference or copy is acquired.

HPALETTE Rbc_GetSystemPalette(void)¶

Copy the system palette when the display is palette-based.

Acquires and releases a screen DC. For RC_PALETTE devices, allocates a temporary 256-entry LOGPALETTE and creates an owned HPALETTE. Caller deletes the returned palette with DeleteObject. Returns NULL on unsupported devices or acquisition/allocation/creation failure; temporary storage is released.

unsigned char *Rbc_GetBitmapData(Display *display, Pixmap bitmap, int width, int height, int *pitchPtr)¶

Read monochrome DIB data into a caller-owned byte buffer.

Requires pitchPtr, initializes it to zero and rejects invalid dimensions or overflowing storage sizes. Requests a positive-height one-bit BI_RGB DIB with DWORD-aligned rows; returned rows retain native bottom-up order. Uses at least the calculated stride times height even if biSizeImage is zero. Releases temporary global memory and each DC acquisition. Returns NULL on failure, or ckalloc storage to free with ckfree and the row pitch. A nonzero GetDIBits result is accepted; exact scanline count is not checked.

void Rbc_WinGet3DBorderColors(Tk_Window tkwin, Tk_3DBorder border, Rbc_Win3DBorderColors *colorsPtr)¶

Read Tk Windows bevel pixels into caller storage.

Borrows window and border; fills flat, light, dark, light2 and dark2 through TkWinGetBorderPixels. Does not allocate or transfer color resources.

void Rbc_WinFillRect(HDC dc, int x, int y, int width, int height, COLORREF color)¶

Fill a positive rectangle through Tk Windows drawing.

Borrows DC and ignores nonpositive dimensions. Uses TkWinFillRect so bevel strips match Tk geometry. Does not acquire a DC or report drawing failure.

int Rbc_WinFillOpaqueStippledRectangles(Display *display, Drawable drawable, GC gc, const XRectangle *rectangles, int nRectangles)¶

Try a pattern-brush fast path for opaque stipple rectangles.

Requires GXcopy, FillOpaqueStippled and a bitmap stipple. Borrows GC/rectangles and owns the pattern brush and DC acquisition. Sets text/background colors in reverse GC order for monochrome stipple expansion and uses the GC origin. Restores colors, brush and origin after painting. FALSE requests ordinary fallback and can follow partial output; copy semantics permit replay. Failed DC acquisition releases its allocated record and the pattern brush before returning FALSE.

int Rbc_WinCopyOpaqueBitmapBatch(Display *display, Drawable drawable, Pixmap bitmap, GC gc, int width, int height, const int (*positions)[2], Tcl_Size nPositions)¶

Copy a monochrome bitmap at multiple positions using shared DCs.

Borrows bitmap, GC and positions. Caller restricts this to the unmasked copy-compatible case; the helper does not validate raster-operation or clip-mask eligibility. Saves destination background mode/colors, sets the opaque expansion colors and uses SRCCOPY. Restores destination state and releases both DC acquisitions. FALSE can follow partial output; shared caller may replay only because this path has copy semantics.

long Rbc_EmulateXMaxRequestSize(Display *display)¶

Return the legacy Windows X request-size surrogate.

Returns SHRT_MAX divided by four, independent of display. This is a compatibility sizing value, not a query of a live GDI device limit.

void Rbc_EmulateXLowerWindow(Display *display, Window window)¶

Move the native window to the bottom of its stacking order.

Borrows the Tk-compatible Window, obtains its HWND and calls SetWindowPos without moving or resizing. Does not report failure or increment an X request counter; the flags do not explicitly suppress activation.

static int GetGCDashValues(GC gc, DWORD *dashArr)¶

Copy the bounded zero-terminated GC dash sequence.

Borrows the GC and writes at most RBC_MAX_DASH_VALUES DWORDs into caller storage. Reads unsigned bytes starting at gc->dashes using the established Windows GC dash layout. Returns the number copied, without allocation.

HPEN Rbc_GCToPen(HDC dc, GC gc)¶

Create an owned GDI pen from configured GC line attributes.

Clamps line width to at least one, maps caps/joins and duplicates a single dash value for a repeating user style. Both dash line styles use the same user-style pen representation. Sets the borrowed DC background mode to TRANSPARENT without restoring it. Uses a geometric pen for width above one and a cosmetic pen otherwise; asserts creation success. Caller selects and later deletes the pen after restoring its previous selection.

struct Rbc_WinDrawableDC¶

Owned release record for a borrowed Tk drawable DC.

Retains the drawable and private Tk state until release. A NULL dc still leaves this allocated record owned by the acquiring caller.

Compatibility drawing primitives¶

These entries implement the Windows Xlib-shaped drawing boundary. They consume mapped integer geometry and configured GCs, with the historical conversions and fallback policies described in Native renderer internals.

group Windows compatibility primitives

Xlib-shaped drawing entry points implemented with native Windows operations.

Functions

void Rbc_EmulateXDrawRectangles(Display *display, Drawable drawable, GC gc, XRectangle *rectArr, int nRects)¶

Draw rectangle outlines through one acquired Windows DC.

Ignores None target, NULL array and nonpositive count. Borrows GC/rectangles; selects an owned GC-derived pen and stock null brush, then draws rectangles in input order. Adds one to each far edge for the Windows pixel convention. Restores selections, deletes the displaced objects and releases DC state. Requires valid GC and usable DC; GDI results are not propagated.

static void DrawArc(HDC dc, int arcMode, XArc *arcPtr, HPEN pen, HBRUSH brush)¶

Translate XArc angle units and closure into a GDI arc operation.

Borrows an already configured DC and XArc. Sweeps of at least one full turn in magnitude use Ellipse. Other sweeps normalize angles in 1/64 degrees and swap endpoints for negative extent. Converts radial endpoints with the historical add-one-half then int conversion, accounting for inverted Y. Adds one to bounding-box far edges. A zero brush argument selects open Arc; a nonzero brush selects Chord or Pie from arcMode. Pen/brush selection is the caller’s responsibility; the pen argument is not otherwise used. Does not explicitly reject zero sweep or change the DC arc direction.

void Rbc_EmulateXDrawArcs(Display *display, Drawable drawable, GC gc, XArc *arcArr, int nArcs)¶

Draw open arcs with a retained pen and null brush.

Ignores None target, NULL input and nonpositive count. Acquires one DC, sets the GC raster operation and selects a GC-derived pen and stock null brush. Calls DrawArc for each item in order, then restores selections, deletes displaced objects and releases state. GC and array remain borrowed.

void Rbc_EmulateXFillArcs(Display *display, Drawable drawable, GC gc, XArc *arcArr, int nArcs)¶

Draw filled arc figures with a solid foreground brush.

Acquires one DC and selects both a GC-derived pen and an owned solid brush. DrawArc chooses chord/pieslice closure or a full ellipse. Thus this path retains a drawing pen rather than selecting a null pen for fill-only output. Ignores empty input; restores selections, deletes owned objects and releases DC state. Does not report individual GDI failures.

static int DrawXorSegments(HDC dc, GC gc, const XSegment *segments, int count)¶

Compose independent XOR segments offscreen and present once.

Requires nonempty valid segments, GC and DC. Intersects expanded segment bounds with GetClipBox and returns TRUE for empty coverage. Owns a compatible DC, bitmap and GC-derived pen. Clears black (XOR identity), translates the viewport and draws each segment as its own Polyline. Only successful composition triggers one SRCINVERT copy to the destination. Restores selected objects and frees temporary resources on handled failure paths. FALSE asks the caller to retry directly; no destination rollback is implemented.

void Rbc_EmulateXDrawSegments(Display *display, Drawable drawable, GC gc, XSegment *segArr, int nSegments)¶

Draw independent segments with XOR-specific presentation.

Rejects missing target/GC/segments and nonpositive count. GXxor first tries DrawXorSegments and stops if handled. Otherwise owns bounded POINT/count arrays and an acquired DC/pen: batches contain 8192 segments, or 680 for wide lines. XOR fallback uses individual Polyline calls to retain dash phase and overlap cancellation. Other operations use PolyPolyline, with per-segment MoveToEx/LineTo fallback on failure. Frees arrays and restores/releases pen and DC state. Void return does not report partial output or GDI failures.

void Rbc_EmulateXDrawPoints(Display *display, Drawable drawable, GC gc, XPoint *pointArr, int nPoints, int mode)¶

Write foreground pixels at absolute or accumulated positions.

Ignores None target, NULL array and nonpositive count. Acquires one DC and sets its raster operation, then calls SetPixelV with GC foreground for each point. CoordModeOrigin uses absolute positions; any other mode accumulates LONG offsets from the first point. Releases DC state. No explicit pixel read/modify/write composition or overflow check is performed here.

void Rbc_EmulateXDrawString(Display *display, Drawable drawable, GC gc, int x, int y, const char *string, int length)¶

Draw a counted string using the Tk font in the GC.

Ignores None target, NULL string and nonpositive byte length. Delegates to Tk_DrawChars with gc->font cast to Tk_Font and baseline coordinates. Borrows all arguments and does not create a DC, font or converted string itself.

Bitmap capture and transforms¶

Windows-specific image contracts are extracted without the same-named shared header declarations. See Image storage and tile clients for common image ownership and Native renderer internals for platform representations and limits.

group Windows bitmap and capture services

Platform implementation, extracted separately from shared image declarations.

Functions

static int GetMonoBitmapStride(int width)¶

Calculate a DWORD-aligned monochrome row stride.

Returns zero for nonpositive width or width too large for the alignment addition. Otherwise returns ((width + 31) & ~31) / 8 bytes. Height and total allocation-size validation remain with the caller.

Rbc_ColorImage Rbc_DrawableToColorImage(Tk_Window tkwin, Drawable drawable, int x, int y, int width, int height, double inputGamma)¶

Capture a Windows drawable rectangle into an owned color image.

Rejects nonpositive dimensions and nonfinite/nonpositive gamma. Borrows window/target, creates a 32-bit DIB and memory DC, then copies the rectangle with SRCCOPY. Converts bottom-up BGR rows using the bitmap row stride and a pow(channel/255, inputGamma) lookup; output alpha is fully opaque. Releases temporary bitmap/DC resources and any copied system palette. Returns NULL on checked capture failures; caller frees a successful image with Rbc_FreeColorImage. Not every GDI acquisition/selection is validated.

Pixmap Rbc_PhotoImageMask(Tk_Window tkwin, Tk_PhotoImageBlock src)¶

Create a Windows one-bit transparency mask from a Tk photo block.

Borrows photo storage and honors pitch, pixelSize and alpha offset. Requires a valid block with accessible alpha bytes. Sets bits only for exactly zero alpha; partial alpha is treated as opaque. Uses aligned temporary rows and the existing photo-specific row traversal before CreateBitmapIndirect. Returns an owned Tk pixmap, or None for all-opaque input, invalid dimensions or bitmap creation failure. Releases temporary bits; caller frees the pixmap.

Pixmap Rbc_ColorImageMask(Tk_Window tkwin, Rbc_ColorImage image)¶

Create a one-bit transparency mask from RBC color pixels.

Borrows a valid image and sets bits only where alpha equals zero. Uses aligned rows and the SetBit bottom-up addressing convention while traversing source pixels in logical row order. Returns None for all-opaque input or checked failure, otherwise an owned Tk pixmap to free with Tk_FreePixmap. Temporary bit storage is released after wrapping the native bitmap.

Pixmap Rbc_RotateBitmap(Tk_Window tkwin, Pixmap srcBitmap, int srcWidth, int srcHeight, double theta, int *destWidthPtr, int *destHeightPtr)¶

Create a rotated Windows monochrome pixmap.

Borrows source/window. Rejects invalid sizes, nonfinite angle or missing output pointers before initializing outputs. After initial validation, outputs are zero until success. Normalizes angle to [0,360), rounds bounding dimensions upward and checks stride, size_t and DWORD image-size limits. Uses exact quadrant mappings or inverse mapping with ROUND and source bounds checks. Frees readback bits and temporary storage; failed upload frees the destination. Returns None on checked failure, otherwise owned pixmap and dimensions. Caller releases the pixmap with Tk_FreePixmap.

Pixmap Rbc_ScaleBitmap(Tk_Window tkwin, Pixmap srcBitmap, int srcWidth, int srcHeight, int destWidth, int destHeight)¶

Scale a monochrome bitmap through Windows StretchBlt.

Borrows source/window and allocates an owned destination pixmap. Acquires source and destination DC records and releases both after SRCCOPY scaling. Returns None if pixmap allocation fails. This path does not validate sizes or test DC acquisition and StretchBlt success separately; callers must supply valid dimensions. A returned pixmap is not proof of successful copy.

Pixmap Rbc_ScaleRotateBitmapRegion(Tk_Window tkwin, Pixmap srcBitmap, int srcWidth, int srcHeight, int regionX, int regionY, int regionWidth, int regionHeight, int virtWidth, int virtHeight, double theta)¶

Construct only a region of a virtual scaled/rotated bitmap.

Validates positive source, region and virtual sizes plus finite angle. Borrows source/window; owns destination pixmap and readback/output buffers. Normalizes rotation and inverse-maps region coordinates through virtual scaling into source bits. Exact quadrant paths assume an in-bounds region and directly sample; arbitrary angles bounds-check source coordinates. Callers must keep region offsets and coordinate arithmetic representable and within the virtual image. Checks stride/storage limits and frees the destination on checked readback/upload failure. Caller owns successful pixmap.

char *Rbc_LastError(void)¶

Format the current Windows error in borrowed static storage.

Captures GetLastError before formatting. Uses FormatMessageA with the system default language and removes trailing CR/LF. Falls back to a numeric error string if formatting fails. The returned 1024-byte buffer is overwritten by later calls, is not thread-local, and must not be freed. Text is in the Windows ANSI encoding rather than guaranteed UTF-8; copy/convert if retained or exposed through a Tcl API expecting UTF-8.
