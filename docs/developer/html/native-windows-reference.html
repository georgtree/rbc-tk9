Windows native backend C reference¶

Windows contracts use a separate Doxygen XML project so identical backend function and structure names cannot merge with the X11 implementation.

group Windows native backend

Private Windows implementation; extracted separately from X11 namesakes.

Functions

Tcl_Size Rbc_NativePolygonPointLimit(Graph *graphPtr)¶

Return the Windows component-level polygon allowance.

Returns TCL_SIZE_MAX, without an X11 request-size bound. Actual drawing still validates the count against INT_MAX and available workspace.

void Rbc_NativePolyline(Rbc_NativeTrace *ctx, const Point2D *screenPts, Tcl_Size nPoints)¶

Stroke connected mapped points through a retained Windows DC.

Borrows the trace context and input. NULL context/points or fewer than two points is a no-op. Converts coordinates to int and repeats the previous endpoint in continuation chunks. Uses preallocated POINT workspace; Polyline return values are not propagated.

void Rbc_NativeStrips(Graph *graphPtr, Drawable drawable, GC gc, const Segment2D *segments, Tcl_Size nSegments)¶

Draw independent two-point strips with one DC acquisition.

Owns bounded POINT and DWORD count buffers. Narrow strokes use up to 8192 segments per PolyPolyline call; wide strokes use 680. Converts endpoints to LONG, selects a GC-derived pen and raster operation, restores/deletes the selected pen and releases DC state. Allocation failure skips output; GDI drawing failures are not reported through this void interface.

Rbc_NativeTrace *Rbc_NativeBeginTrace(Graph *graphPtr, Drawable drawable, GC gc)¶

Allocate a Windows trace context and acquire its drawing state.

Borrows graph, target and GC; owns trailing POINT workspace, acquired DC state and selected pen/brush. Wide strokes use base capacity 100; narrow strokes use request-derived capacity, with one extra continuation slot. Returns NULL for capacity/allocation failure. DC and GDI object acquisition failures are not separately validated here. EndTrace must release the context.

void Rbc_NativeEndTrace(Rbc_NativeTrace *ctx)¶

Restore and release a Windows trace batch.

Accepts NULL. Reselects the saved pen/brush, deletes the displaced batch objects, releases acquired DC state and frees the combined context buffer. Does not free the borrowed graph, drawable or GC.

static int GetCirclePathTemplate(HDC dc, int radius, POINT **pointsPtrPtr, BYTE **typesPtrPtr, int *nPointsPtr)¶

Obtain reusable ellipse geometry generated by GDI itself.

Initializes outputs to NULL/zero. Builds an Ellipse path in the borrowed DC using diameter 2*radius+1 and copies GetPath points/types to owned arrays. Aborts the temporary path after extraction. Returns FALSE on invalid radius, path failure or allocation failure, releasing partial arrays. On success the caller owns both arrays; radius arithmetic must be representable.

static void LoadCirclePath(POINT *dstPoints, BYTE *dstTypes, const POINT *templatePoints, const BYTE *templateTypes, int nTemplatePoints, LONG x, LONG y, int radius)¶

Translate one ellipse template into caller-owned batch storage.

Borrows template arrays and copies point types unchanged. Translates points by center minus radius. Caller provides capacity for nTemplatePoints and representable LONG coordinates; no allocation or validation occurs.

static void DrawCircleCentersDirect(HDC dc, const POINT *centers, int nCenters, int radius)¶

Draw buffered circles individually using Ellipse.

Borrows DC and centers and preserves the existing radius-plus-one far edge. Used to replay a failed copy-compatible batch. Does not own GDI state or report individual drawing failures.

static int DrawCirclePathBatch(HDC dc, const POINT *points, const BYTE *types, int nPoints, int doFill, int doOutline)¶

Render a combined circle path or outline batch.

Outline-only calls PolyDraw directly. Filled batches bracket PolyDraw in BeginPath/EndPath, then use FillPath or StrokeAndFillPath. Returns the GDI success result; aborts failed construction paths. Caller owns DC, arrays and selected pen/brush and decides whether replay is safe.

void Rbc_NativeCircles(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int radius)¶

Draw Windows circle symbols with guarded path batching.

Borrows style/centers and advances interval counters for examined centers. Owns template/batch arrays, DC acquisition and non-stock pen/brush objects. Batching requires GXcopy for participating GCs and equal fill/outline colors when both are used. Filled batches contain at most 32 circles; outlines use 512, or 64 for wide pens. Setup failure selects individual Ellipse drawing; failed copy batches replay their buffered centers. Restores fill mode and selected objects and frees temporary resources. No Tcl error is produced.

void Rbc_NativeSquares(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, Tcl_Size nSymbolPts, const Point2D *symbolPts, int r)¶

Convert selected squares to closed polygon symbols.

Allocates five XPoints per input center, including a repeated first vertex. Subtracts radius before short conversion. Positive intervals update the style counter even for skipped centers. Delegates selected squares to Rbc_NativePolygonSymbols and frees storage; invalid/empty output or allocation failure is ignored.

static void LoadPolygonBatch(POINT *points, const XPoint *polygons, Tcl_Size first, Tcl_Size count, int stride, int nPoints)¶

Pack selected XPoint polygons into Windows POINT storage.

Borrows source and destination arrays. Source stride includes closure; nPoints chooses fill vertices without closure or the complete outline. Copies count polygons starting at first, widening existing short values to LONG. Caller ensures all bounds and destination capacity.

void Rbc_NativePolygonSymbols(Display *display, Drawable drawable, Rbc_RenderNativeSymbolStyle *style, const XPoint *polygons, Tcl_Size nPolygons, int stride, int nVertices)¶

Fill polygon symbols, then draw their closed outlines.

Owns bounded point/count arrays and one acquired DC. Copy fills use WINDING and small PolyPolygon batches; non-copy fills preserve per-polygon effects. Outlines use larger PolyPolyline batches only for GXcopy, otherwise each outline is drawn separately. Failed copy batches replay individual shapes. Restores fill mode and selected GDI objects, deletes owned brushes/pens and releases all buffers. Interval selection is the shared caller’s responsibility.

int Rbc_NativePolygonPointCount(Display *display, Tcl_Size nPoints)¶

Validate a polygon count for the GDI int interface.

Returns zero for fewer than three vertices or counts above INT_MAX; otherwise returns the int count. Does not enforce an X11 request limit or inspect coordinate geometry.

static void DrawWin3DRectangle1(HDC dc, const Rbc_Win3DBorderColors *colorsPtr, int x, int y, int width, int height, int relief)¶

Reproduce a one-pixel Tk raised or sunken rectangle bevel.

Borrows DC and extracted colors. Clamps the bevel for tiny rectangles. Draws left, right, top and bottom strips in Tk order; unsupported relief draws nothing. Does not acquire a DC or retain color resources.

static void DrawWinRbcOuter3DBorder(HDC dc, const Rbc_Win3DBorderColors *colorsPtr, int x, int y, int width, int height, int relief)¶

Draw the RBC-specific outer layer of a two-pixel bevel.

Requires dimensions greater than two; supports raised/sunken relief only. Uses the historical flat/light/dark color selection and right, top, bottom, left drawing order. Borrows DC and colors without allocating state.

static int Clamp3DBorderWidth(int width, int height, int borderWidth)¶

Clamp a requested bevel to half each rectangle dimension.

Returns the effective width using the same sequential width/height checks as Tk. Callers supply positive bounded dimensions and border widths.

int Rbc_NativeBarBorders(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, const Rbc_RenderRectangle *rectangles, Tcl_Size nRects)¶

Batch supported Windows bar bevels through one DC.

Handles raised/sunken border widths one and two; returns FALSE for other configurations so the shared caller can use ordinary relief drawing. Skips nonpositive rectangles and reproduces tiny-rectangle width clamping. Borrows border/colors and releases the acquired DC. TRUE means configuration handled, not verified success of every GDI drawing operation.

void Rbc_NativeBarRectangles(Graph *graphPtr, Drawable drawable, const Rbc_RenderBarStyle *penPtr, XRectangle *rectangles, int nRects)¶

Try optimized opaque-stipple bar fills before Xlib fallback.

Borrows prepacked rectangles and style GC. If the Windows stipple helper declines, sends the same batch to XFillRectangles. Caller bounds the request.

Rbc_NativePolygonBatch *Rbc_NativeBeginPolygonBatch(Graph *graphPtr, Drawable drawable, GC gc, Tcl_Size maxPoints)¶

Acquire a reusable fill-only Windows polygon context.

Validates positive workspace capacity and allocation size. Owns point workspace, solid brush and DC state; selects a stock null pen and the GC fill rule. Returns NULL for invalid capacity, workspace or brush failure. Later DC/selection failures are not separately checked. Borrows graph/GC; a successful context requires Rbc_NativeEndPolygonBatch.

void Rbc_NativeBatchPolygon(Rbc_NativePolygonBatch *batch, const Point2D *points, Tcl_Size count)¶

Fill one polygon using retained Windows batch state.

Requires a live context and valid point array. Rejects unsupported count or count exceeding workspace capacity. Deliberately converts through short before LONG to preserve the original polygon path. Does not propagate Polygon failure or retain input points.

void Rbc_NativeEndPolygonBatch(Rbc_NativePolygonBatch *batch)¶

Restore and free a live Windows polygon batch.

Requires non-NULL context. Restores fill mode and stock/previous selections, deletes the owned brush, releases DC state and frees workspace/context.

size_t Rbc_NativeClipStateSize(void)¶

Return extra Windows state size for a shared clip frame.

The common allocator reserves this payload immediately after its frame. Ownership remains with the shared clip stack.

int Rbc_NativePlatformClip(Graph *graphPtr, Drawable parent, int left, int top, int right, int bottom, void *clientData, Drawable *drawablePtr)¶

Install a Windows meta-region clip on an acquired parent DC.

Initializes caller-owned state, acquires DC, saves it and intersects bounds. Promotes the clip to a meta region so bitmap mask changes cannot bypass it. Caller must initialize the output drawable to None. Returns TRUE even on setup failure; a missing output means skip drawing, not scratch fallback. Every call requires PlatformUnclip, including partial setup failures.

void Rbc_NativePlatformUnclip(void *clientData, Drawable drawable)¶

Unwind complete or partial Windows clip setup.

Frees a non-None borrowed-DC wrapper, restores saved DC state when present and releases the acquisition record. Does not free the enclosing shared frame or own the parent drawable.

void Rbc_NativeRun(Graph *graphPtr, Drawable drawable, void *data, Tcl_Size count, Rbc_RenderRunProc *proc)¶

Run a callback through one temporary Windows drawable wrapper.

Ignores NULL data or nonpositive count. Acquires a DC and wraps it for one synchronous callback; acquisition/wrapping failure invokes the callback on the original drawable instead. Releases wrapper and DC after the call. Callback must be valid, preserve borrowed resource lifetime and not retain the temporary target. This is not a Tcl evaluation boundary.

int Rbc_NativeOpaqueBitmapRun(Graph *graphPtr, Drawable drawable, Pixmap bitmap, GC gc, int width, int height, const Rbc_RenderPosition *positions, Tcl_Size count)¶

Delegate opaque bitmap batching to the Windows compatibility layer.

Returns Rbc_WinCopyOpaqueBitmapBatch’s handled/fallback result unchanged. Borrows target, bitmap, GC and positions; the shared caller owns replay policy and requires copy-compatible input.

struct Rbc_NativeTrace¶

Windows trace allocation with trailing POINT workspace.

Borrows graph/GC/target, owns DC acquisition and selected pen/brush, and retains prior selections for restoration by EndTrace.

struct Rbc_NativePolygonBatch¶

Fill-only polygon context owning point workspace, brush and DC state.

Retains prior brush, pen and fill mode for restoration. Component callers remain responsible for style grouping and painter order.

struct NativeDCClip¶

Windows clip payload stored after the shared clip frame.

Owns the acquisition record and tracks a SaveDC token. The parent drawable remains borrowed; PlatformUnclip handles partial initialization.
