Windows native backend C reference

Windows contracts use a separate Doxygen XML project so identical backend function and structure names cannot merge with the X11 implementation. Parameter descriptions identify retained DC/batch state, caller-owned clip payloads, and temporary drawables. Return values that select fallback are not interchangeable with drawing-success reports; see Native renderer internals.

For a retained polygon batch, pair rbcNativeWindows.Rbc_NativeBeginPolygonBatch() with rbcNativeWindows.Rbc_NativeEndPolygonBatch(). For direct clipping, rbcNativeWindows.Rbc_NativePlatformUnclip() must unwind even partial setup from rbcNativeWindows.Rbc_NativePlatformClip().
