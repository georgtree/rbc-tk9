Typed dispatch C reference¶

See Typed command dispatch for table lifetime, argument counts and callback boundaries. These are private implementation interfaces.

struct Rbc_OpSpecHeader¶

Common first member of persistent typed operation-table entries.

Terminate a table with a NULL name. Bounds count the complete command word vector; maxArgs <= 0 is unbounded. The enclosing entry supplies its own correctly typed callback, and its sizeof is the lookup stride.

int Rbc_GetOpIndexFromObj(Tcl_Interp *interp, const void *specArr, Tcl_Size specSize, Tcl_Size operPos, Tcl_Size objc, Tcl_Obj *const objv[], int *indexPtr)¶

Select a typed operation-table entry and validate total argument count.

Require a persistent NULL-name-terminated table whose entries start with Rbc_OpSpecHeader and have byte stride specSize. Tcl lookup accepts unique abbreviations and caches the table in the operation object. On success assign indexPtr, not a function pointer; the caller dispatches through its typed table. minArgs/maxArgs count all objc words; maxArgs <= 0 means unbounded. Leave the output unchanged on error and set an interpreter diagnostic.
