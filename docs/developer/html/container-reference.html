Container C reference

These interfaces are private. See Chains and keyed lists for ownership and traversal.

void Rbc_ChainInit(Rbc_Chain *chainPtr)

Initialize caller-owned storage as an empty chain.

Does not free existing links. Use Reset to clear an initialized chain.

Parameters:

  • chainPtr – [inout] Required caller-owned record to initialize; no existing links are released.

void Rbc_ChainReset(Rbc_Chain *chainPtr)

Free all linked records and leave an empty initialized chain.

NULL is harmless. External clientData is not freed. Inline storage created by ChainAllocLink is part of each freed record; run any payload cleanup first.

Parameters:

  • chainPtr – [inout] Initialized chain to clear, or NULL; container storage remains owned by the caller.

void Rbc_ChainDestroy(Rbc_Chain *chainPtr)

Reset and free a heap-allocated chain, accepting NULL.

Do not use on stack or embedded storage. External payload ownership remains with the caller.

Parameters:

  • chainPtr – [inout] Heap-allocated chain to consume, or NULL; all linked records and the container become invalid.

Rbc_ChainLink *Rbc_ChainAllocLink(size_t size)

Allocate a detached zeroed link with aligned trailing storage.

With nonzero size, clientData points into the same allocation; do not free it separately. With zero size clientData is NULL. Size overflow panics. Link it into a chain or release the detached allocation with ckfree.

Parameters:

  • size – [in] Requested trailing payload bytes, excluding the link header and alignment padding; zero creates a plain link.

Supply its actual chain; links do not store owner identity and this helper cannot validate membership. Clears next/previous pointers. The detached link may be reinserted or freed by the caller.

Requires a valid link and its actual chain. Does not free external clientData. All borrowed pointers into the link become invalid.

Parameters:

  • linkPtr – [inout] Required member link; allocation and inline payload are consumed; external payload ownership is unchanged.

Rbc_ListNode Rbc_ListCreateNode(Rbc_List list, const char *key)

Allocate a keyed node for a list without inserting it.

String and integer-array keys are copied into the allocation; one-word keys retain only the pointer value. Duplicate keys are permitted. The node already records the intended list: insert it before using ListUnlinkNode/DeleteNode, or free this never-inserted allocation directly with ckfree.

Parameters:

  • list – [in] Required initialized list supplying key type and initial owner identity; no node is inserted.

  • key – [in] Key matching the list type: readable NUL-terminated string, pointer-sized identity, or readable native int array; only identity keys may be NULL.

void Rbc_ListReset(Rbc_List list)

Free linked nodes and copied keys while retaining the list key type.

Accepts NULL. Does not free clientData or objects denoted by one-word keys. Nodes allocated but never inserted are not visited.

Parameters:

  • list – [inout] Initialized list to clear, or NULL; retains the container and key type but frees linked nodes.

void Rbc_ListUnlinkNode(Rbc_ListNode node)

Detach an inserted node without freeing it or its payload.

Clears owner, next and previous pointers. A previously unlinked node is a no-op, but a newly created, never-inserted node is not valid input: its owner field is already set although the list count does not include it.

Parameters:

  • node – [inout] Required inserted or normally unlinked node; clears membership without freeing it. Never-inserted nodes are invalid.

void Rbc_ListDeleteNode(Rbc_ListNode node)

Unlink and free an inserted or previously unlinked node.

Copied key storage is freed with the record; external clientData and one-word key targets are not freed. Never pass a newly created, never-inserted node.

Parameters:

  • node – [inout] Required inserted or normally unlinked node to consume; never pass a newly created, never-inserted node.

Rbc_ListNode Rbc_ListGetNode(Rbc_List list, const char *key)

Return the borrowed first node matching a key, or NULL.

Searches linearly in list order; duplicate keys are not rejected. A NULL list returns NULL. The node remains owned by its container/caller.

Parameters:

  • list – [in] Initialized list, or NULL for no match; membership is unchanged.

  • key – [in] Key matching the list type: readable NUL-terminated string, pointer-sized identity, or readable native int array; only identity keys may be NULL.

void Rbc_ListSort(Rbc_List list, Rbc_ListCompareProc *proc)

Reorder existing nodes with qsort without moving their allocations.

The comparator receives pointers to node pointers. It must not mutate the list, delete nodes or reenter code that does so. Equal-key ordering is not stable. NULL/short lists are unchanged; scratch-allocation failure silently leaves the list unchanged. Payload ownership is unaffected.

Parameters:

  • list – [inout] Initialized list to reorder, or NULL; NULL and lists shorter than two nodes are unchanged.

  • proc – [in] Comparator receiving pointers to node pointers; required for a nontrivial sort and must not mutate or destroy list state.
