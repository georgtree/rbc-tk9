Utility ownership C reference¶

See Allocation, strings and interned names for lifetime and failure policy.

void *RbcCalloc(size_t nElem, size_t size)¶

Allocate a zero-initialized Tcl-owned block.

Check nElem * size for size_t overflow and panic on overflow. A zero logical size allocates one zero byte, preserving a non-NULL ckalloc-style result. The caller releases the allocation with ckfree. Allocation failure is fatal, not a recoverable NULL result.

char *RbcStrdup(const char *ptr)¶

Copy a non-NULL NUL-terminated string into Tcl-owned storage.

Borrow the input and copy through its first NUL, including the terminator. The caller releases the result with ckfree, not libc free. Uses ckalloc failure policy; this is not a binary-data or length-delimited copy.

Rbc_Uid Rbc_GetUid(const char *string)¶

Acquire a reference to an interned NUL-terminated name.

Equal strings share a stable pointer while references remain. Do not modify the returned characters despite the historical mutable typedef. Pair each acquisition with Rbc_FreeUid. The process-static table is neither interpreter local nor protected by locks; this is not a cross-thread sharing API.

void Rbc_FreeUid(Rbc_Uid uid)¶

Release one acquired UID reference, deleting its key at zero.

Require a still-valid UID acquired through Rbc_GetUid. Do not free the string with ckfree or release a merely borrowed Rbc_FindUid result. Unknown valid strings produce a stderr diagnostic; NULL or dangling pointers are not safe.

Rbc_Uid Rbc_FindUid(char *string)¶

Borrow an existing interned name without increasing its reference count.

Return NULL when absent. The pointer remains valid only while an acquiring owner keeps a reference. Lookup lazily initializes the shared table but does not insert a missing name. Use Rbc_GetUid when independent ownership is needed.

char *Rbc_Itoa(int value)¶

Format an int into borrowed shared scratch storage.

Return a pointer to the same process-static buffer used by Rbc_Utoa and Rbc_Dtoa. A subsequent call to any of them overwrites it. Do not free or retain it without copying; concurrent calls are not synchronized.

char *Rbc_Utoa(unsigned int value)¶

Format an unsigned int into borrowed shared scratch storage.

Shares the buffer and overwrite/threading restrictions of Rbc_Itoa. The returned decimal string is not caller-owned.

char *Rbc_Dtoa(Tcl_Interp *interp, double value)¶

Format a double through Tcl_PrintDouble into shared scratch storage.

Borrow interp. Shares the buffer with Rbc_Itoa and Rbc_Utoa; copy the result before another formatting call and never free the returned pointer.

void Rbc_DStringAppendElements(Tcl_DString*, ...)¶

Append NUL-terminated strings as Tcl list elements.

Borrow the initialized DString and arguments, ending varargs with a NULL string pointer. Tcl_DStringAppendElement supplies list quoting. Existing contents remain; the caller owns the DString and eventually frees it.

void Rbc_AppendResultStrings(Tcl_Interp *interp, ...)¶

Append raw string fragments to a duplicate of the interpreter result.

Borrow interp and NUL-terminated arguments ending with a NULL string pointer. Duplicate the current object before appending, then install and release the local reference. Shared original objects remain unchanged. Fragments are not list-quoted, and this helper does not set structured Tcl error metadata.

void Rbc_InitHexTable(char *table)¶

Set hexadecimal digit entries in a caller-owned character table.

Require storage addressable by the character codes for 0-9, a-f and A-F (typically 256 entries). Set only those slots to 0 through 15. All other slots keep their previous contents; callers initialize invalid-digit sentinels.

double Rbc_RandomDouble(void)¶

Return a rand-derived value in the half-open interval [0, 1).

Consumes the C library PRNG state and does not seed it. No interpreter-local state, reproducibility across platforms or cryptographic quality is promised.
