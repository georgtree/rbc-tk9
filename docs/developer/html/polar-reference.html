Polar data and geometry C reference¶

These helpers are private to their implementation modules. See Polar data and grid geometry for source ownership and the distinction between data and grid coordinates.

Element data adapters (rbcGrLine.c)¶

group Polar element data internals

Private adapters from retained source data to Cartesian graph coordinates.

Functions

static int GetComplexLineDataPoint(Line *linePtr, Tcl_Size index, double *xPtr, double *yPtr)¶

Convert one borrowed complex sample to graph-plane coordinates.

Gamma input is copied directly, including nonfinite values; callers must validate coordinates before mapping. Impedance and admittance are normalized using z0, then converted to Gamma. A FALSE return does not promise unchanged output values. No source storage is copied, retained or modified.

Parameters:

  • linePtr – Borrowed line with validated data format and reference impedance.

  • index – Source index in the retained complex vector.

  • xPtr – Receives the real graph coordinate.

  • yPtr – Receives the imaginary graph coordinate.

Returns:

FALSE for an unavailable sample or failed impedance/admittance division.

static int ParseComplexVectorObj(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, ElemComplexVector *candidatePtr)¶

Acquire a staged client of a named complex vector.

The candidate owns its client ID and borrows the vector record and numeric storage. No update callback is installed until commit moves it into the stable line record. Release an abandoned candidate with FreeComplexVector. This parser does not accept a list of complex values as a fallback.

Parameters:

  • interp – Interpreter used for lookup and error reporting.

  • elemPtr – Borrowed owner recorded in the candidate.

  • objPtr – Borrowed vector name; NULL or empty means no vector.

  • candidatePtr – Fresh output slot, initialized here rather than released.

Returns:

TCL_OK for an empty slot or a retained complex-vector client; TCL_ERROR after releasing a failed lookup/type-check client.

Grid geometry (rbcGrPolar.c)¶

group Polar grid geometry internals

Private data-plane helpers; axes and grid records are borrowed.

Functions

static int GetPolarRadiusRange(Grid *gridPtr, PolarRadiusRange *rangePtr)¶

Bound radii intersecting the grid’s Cartesian viewport rectangle.

A viewport spanning the origin has minimum radius zero. The maximum is the farthest corner distance, not a fully contained circle radius. Outputs are unspecified on failure. No mapping or allocation is performed.

Parameters:

  • gridPtr – Borrowed grid with mapped X/Y axes.

  • rangePtr – Receives nearest and farthest distances from the origin.

Returns:

TRUE for a finite nonempty radial range; FALSE for missing axes, logarithmic axes, invalid axis bounds or nonfinite distances.

static Point2D SmithReactanceGamma(double reactance, double t, int admittance)¶

Parameterize a constant-reactance or constant-susceptance grid arc.

For t below one, the real component of normalized impedance or admittance is t/(1-t). At t >= 1 the infinite-real endpoint is supplied explicitly: (+1,0) for impedance, (-1,0) for admittance. The helper does not validate arbitrary external inputs and owns no resources.

Parameters:

  • reactance – Normalized finite reactive value chosen by grid mapping.

  • t – Arc parameter from zero through one.

  • admittance – Nonzero selects the admittance orientation.

Returns:

A point in the Cartesian Gamma plane, before screen mapping.

Line and polar data transactions (rbcGrLine.c)¶

These helpers also cover the real parallel parameter input shared by graph line and polar elements. The documentation-only scope keeps private names distinct from similarly named helpers in other modules.

group Line and polar data transactions

Source ownership, parallel parameters, notification policy and staged commit.

Functions

static void FreeLinePenColor(XColor *colorPtr)¶

Release an owned line-pen color unless it is NULL or COLOR_DEFAULT.

The sentinel represents inheritance rather than a Tk color allocation. Does not clear the caller’s pointer; callers must not release it twice.

static int GetLineArrayByteCount(Tcl_Size count, size_t elementSize, size_t *bytesPtr)¶

Validate a count-to-byte multiplication without allocating storage.

Rejects negative counts, zero element size and SIZE_MAX overflow. Assigns bytesPtr only on success. Zero count is valid with a positive element size. Returns TCL_OK or TCL_ERROR without setting an interpreter diagnostic.

static Tcl_Size LinePointCount(Element *elemPtr)¶

Return the current source point count for a line representation.

Complex mode uses Z length; X/Y mode uses the smaller length. Named sources are queried directly so pending notifications do not hide a resize. Literal slots use cached counts. Does not refresh cached pointers or deliver callbacks; a current count alone does not make cached sample storage current.

static int GetLineDataPoint(Line *linePtr, Tcl_Size index, double *xPtr, double *yPtr)¶

Read a cached source sample and convert it to graph-plane coordinates.

Complex input delegates to GetComplexLineDataPoint. X/Y input checks cached paired length and non-NULL arrays. Polar X/Y requires finite theta/radius and converts radians to Cartesian coordinates; Cartesian X/Y copies directly, without rejecting nonfinite values. Returns a boolean; callers must reject unusable outputs and ensure borrowed arrays are synchronized before reading.

static void SyncComplexVector(ElemComplexVector *vPtr)¶

Refresh a complex slot’s borrowed length, capacity and array pointer.

Requires a live vecPtr of complex type. Does not own the array, install a callback, compute extrema, invalidate mapping or schedule redraw.

static void FreeComplexVector(ElemComplexVector *vPtr)¶

Detach a complex-vector client and zero the whole slot.

Accepts an empty slot. Does not destroy the source vector or free its borrowed numeric storage. The previous elemPtr owner association is also cleared.

static void ComplexVectorChangedProc(Tcl_Interp *interp, ClientData clientData, Rbc_VectorNotify notify)¶

Refresh or clear a stable complex-data slot on vector notification.

Client data must identify the committed line member. Destruction clears the client ID, vector, array, length and capacity. Update reacquires the vector and refreshes cached storage on success. Always marks axes and element mapping dirty, scheduling backing-store redraw only when not hidden or plotHidden. No partial changed-range accumulation is performed by this callback.

static void ReplaceLineOptionObject(Tcl_Obj **objPtrPtr, Tcl_Obj *newObjPtr)¶

Replace one retained Tcl option object with balanced references.

An identical pointer is a no-op. Retains the replacement before releasing the old object; NULL clears the slot. Does not parse, configure or evaluate it.

static int StageComplexData(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, LineComplexDataTransaction *transactionPtr)¶

Replace a staged complex source only after candidate parsing succeeds.

Uses ParseComplexVectorObj, then releases an earlier staged client and transfers the new candidate. Failure leaves the earlier candidate untouched. The caller owns transaction cleanup; no callback is registered in temporary storage.

static int PrepareLineComplexDataTransaction(Graph *graphPtr, Element *elemPtr, Line *linePtr, LineComplexDataTransaction *transactionPtr)¶

Prepare complex-source replacement and data-mode selection in option order.

Initializes a fresh transaction from the current mode. First configuration considers the retained default unless explicit -cdata was supplied. Processes canonical explicit options in caller order: nonempty -cdata selects complex, empty -cdata or ordinary data options select X/Y. Later mode selection does not excuse an invalid earlier complex source. Failure frees staged clients and zeros the transaction, leaving live line storage unchanged.

static void CommitLineComplexDataTransaction(Line *linePtr, LineComplexDataTransaction *transactionPtr)¶

Commit a prepared complex-source transaction into stable line storage.

In complex mode, transfers a staged slot and then registers its notification callback against linePtr->z; an unstaged complex slot remains unchanged. In X/Y mode, frees live and staged complex clients and clears retained -cdata. Stores the selected mode and clears staged ownership. Does not free external vectors or itself schedule graph redraw; preparation must already have passed.

static void FreeLineComplexDataTransaction(LineComplexDataTransaction *transactionPtr)¶

Release an abandoned staged complex source and zero its transaction.

Safe after commit because staged ownership has been cleared. Does not release the live line source or change data mode.

static void SyncLineParamVector(ElemVector *vPtr)¶

Refresh a live real parameter slot’s borrowed storage and extrema.

Requires a valid vecPtr. Copies length, capacity, array and vector range without geometry invalidation, notification delivery or ownership transfer.

static void LineParamVectorChangedProc(Tcl_Interp *interp, ClientData clientData, Rbc_VectorNotify notify)¶

Refresh parallel parameter data without invalidating plotted geometry.

Destruction clears client identity and borrowed storage. Update reacquires the source and synchronizes it; failed lookup clears vector/array/count/capacity while retaining the client ID for later cleanup. Cached extrema are not reset on those clear paths. Does not reset axes, map geometry or request redraw.

static int StageLineParam(Tcl_Interp *interp, Element *elemPtr, Tcl_Obj *objPtr, LineParamTransaction *transactionPtr)¶

Parse and retain a replacement parameter candidate transactionally.

Accepts the common real-vector or numeric-expression-list input. On failure releases the local candidate and retains any earlier staged value. On success frees the earlier staged slot and transfers the candidate. Does not install parameter notifications until commit moves it to stable line storage.

static int PrepareLineParamTransaction(Graph *graphPtr, Element *elemPtr, Line *linePtr, LineParamTransaction *transactionPtr)¶

Prepare parameter input from defaults and ordered explicit options.

Initializes a fresh transaction. On first configuration uses the retained default only when no explicit canonical -param occurs. Validates every explicit occurrence in order, including values superseded later. Failure frees staged storage and zeros the transaction. Length compatibility is a separate check.

static void CommitLineParamTransaction(Line *linePtr, LineParamTransaction *transactionPtr)¶

Transfer staged parameter ownership to the line and install its callback.

No-op without a staged candidate. Releases the old live slot, moves the new one, restores its owner pointer and registers LineParamVectorChangedProc for a named source. Clears candidate ownership for subsequent transaction cleanup.

static void FreeLineParamTransaction(LineParamTransaction *transactionPtr)¶

Release a staged parameter candidate and zero its transaction.

Safe on an empty or committed transaction. Uses common slot cleanup for owned list arrays and retained vector clients, without destroying source vectors.

static int LineParamConfigured(Line *linePtr)¶

Test whether the retained parameter option is nonempty.

Examines paramObjPtr text only, not current numeric length or client validity. A nonempty option whose external source became empty is still configured.

static int LineParamLengthValidationNeeded(Element *elemPtr)¶

Decide whether configuration must validate parallel parameter length.

Returns true on initial configuration or an explicit canonical -param, -data, -x, -y or -cdata option. Other changes may proceed during a temporary mismatch caused by independently resized external vectors. Does not compare lengths.

static Tcl_Size ProspectiveLinePointCount(Line *linePtr, const ElemDataTransaction *dataTransactionPtr, const LineComplexDataTransaction *complexDataTransactionPtr)¶

Count prospective data points using current named-vector lengths.

Uses the staged mode when a complex transaction is supplied. Complex mode selects staged or live Z storage; X/Y delegates to the common transaction count. Named sources are queried directly, while literals use their stored counts. Does not refresh arrays, deliver notifications or commit candidates.

static int ValidateLineParamLength(Graph *graphPtr, Line *linePtr, const ElemDataTransaction *dataTransactionPtr, const LineComplexDataTransaction *complexDataTransactionPtr, const LineParamTransaction *paramTransactionPtr)¶

Require configured parameter length to match prospective data length.

Empty retained -param disables the check. Selects staged parameter storage when available, otherwise the live slot, querying current named-vector length. Obtains data length through ProspectiveLinePointCount. Returns TCL_ERROR with both counts on mismatch, TCL_OK otherwise. Does not refresh arrays, deliver notifications, commit candidates or free them.
