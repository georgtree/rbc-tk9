Spline C reference

These private geometry services use caller-owned arrays, not vector handles. See Spline interpolation and graph smoothing for parameter formats, failure behavior and graph integration.

int Rbc_NaturalSpline(const Point2D *origPts, Tcl_Size nOrigPts, Point2D *intpPts, Tcl_Size nIntpPts)

Evaluate a natural cubic spline at caller-supplied abscissas.

Preserves exact source-knot values and extrapolates with the first/last interval outside the source domain. Allocates and frees private workspace; does not own either caller array or invoke Tcl callbacks.

Parameters:

  • origPts – [in] Borrowed, separate source array with finite coordinates and strictly increasing X; at least three points are required.

  • nOrigPts – [in] Number of source points.

  • intpPts – [inout] Caller-owned non-NULL array; X supplies finite query positions in any order and is retained, Y receives interpolated values.

  • nIntpPts – [in] Number of queries, nonnegative; zero succeeds after validation.

Returns:

TRUE on success, FALSE on invalid input, allocation or arithmetic failure. Output may be partially modified on failure; no Tcl diagnostic.

int Rbc_QuadraticSpline(const Point2D *origPts, Tcl_Size nOrigPts, Point2D *intpPts, Tcl_Size nIntpPts)

Evaluate a shape-preserving quadratic spline at caller-supplied abscissas.

Preserves exact source-knot values and extrapolates with the first/last interval outside the source domain. Allocates and frees private workspace; does not own either caller array or invoke Tcl callbacks.

Parameters:

  • origPts – [in] Borrowed, separate source array with finite coordinates and strictly increasing X; at least three points are required.
