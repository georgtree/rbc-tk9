Vector storage private C reference¶

These registry, allocation, creation and destruction helpers are private to RBC. They are not substitutes for installed public stub entries. See Vector C API and storage primitives for their relationships and callback restrictions.

group Vector storage private implementation

Registry and storage primitives with guarded callback boundaries.

Functions

static size_t VectorElementSize(Rbc_VectorType type)¶

Return the byte stride for one real or complex value.

Uses sizeof(double) or sizeof(Rbc_Complex). Unsupported internal types panic; this is not a recoverable public type validator.

static int GetVectorByteCount(Tcl_Interp *interp, Rbc_VectorType type, Tcl_Size count, size_t *byteCountPtr)¶

Validate a value count and convert it to an allocation byte count.

Rejects negative counts and multiplication overflow with a Tcl error. Writes the output only on success; calls VectorElementSize, so the type must already be valid. Does not allocate storage or evaluate Tcl.

static int VectorAlive(VectorObject *vPtr)¶

Check logical liveness of a retained vector record.

The caller must already protect storage lifetime; this cannot validate an arbitrary pointer. Rejects destruction or interpreter deletion with RBC VECTOR DESTROYED. Does not check writability, name identity or numeric storage stability.

static void ReleaseVectorStorage(Tcl_Interp *interp, void *data, Tcl_FreeProc *freeProc)¶

Release detached numeric storage according to its ownership policy.

NULL storage and TCL_STATIC require no action; TCL_DYNAMIC uses ckfree. A custom release callback runs with the outer interpreter state saved and restored. The caller must install the completed replacement contract before calling, and separately protect record/interpreter lifetime across arbitrary callback code.

static void PublishVectorChange(VectorObject *vPtr, int all, Tcl_Size first, Tcl_Size last)¶

Publish an update while retaining the original vector identity.

Preserves vector and interpreter, saves interpreter state, optionally flushes mapped-array cache, then rechecks liveness before notifying all data or an inclusive interval. Callbacks may delete or replace the vector; this never resolves a replacement by name. Restores state and releases both records before returning.

static int CheckResizedVector(VectorObject *vPtr, void *data, Tcl_Size length, Tcl_Size size)¶

Validate a writable resize destination after callback activity.

Requires a retained record. Checks liveness and read-only state, then compares data pointer, length, capacity and full-vector selection against the caller snapshot. Reports RBC VECTOR CHANGED on layout mismatch. Does not prove that numeric values remained unchanged or that no same-layout mutation occurred.

static char *VectorTraceError(Tcl_Obj *objPtr)¶

Retain a Tcl object as a variable-trace error result.

Increments the supplied object reference and returns it through the legacy char pointer signature. Valid only with traces registered using TCL_TRACE_RESULT_OBJECT, which tells Tcl to consume an object rather than interpret the pointer as message bytes.

static void ZeroVectorElements(Rbc_VectorType type, VectorData data, Tcl_Size first, Tcl_Size last)¶

Zero the half-open interval [first,last) of typed storage.

Zeros both components for complex values. Bounds and capacity are caller preconditions; does not allocate, change metadata, invalidate extrema or notify.

VectorInterpData *Rbc_VectorGetInterpData(Tcl_Interp *interp)¶

Obtain or lazily initialize an interpreter-local vector registry.

Returns borrowed associated data. First access allocates the vector, math and special-index tables, installs built-in functions and registers interpreter cleanup. Does not create Tcl commands or establish thread-shared storage.

static void VectorInterpDeleteProc(ClientData clientData, Tcl_Interp *interp)¶

Destroy registered vectors and release interpreter-local tables.

Repeatedly takes the first remaining registry entry because destruction mutates the table and invokes callbacks. Deletes the math/index table containers and associated data, then frees the registry record. This is interpreter teardown, not a general-purpose registry reset API.

VectorObject *Rbc_VectorNew(VectorInterpData *dataPtr)¶

Allocate an unregistered empty real vector record.

Initializes static NULL storage, zero length/capacity, an empty observer chain, idle notifications, invalid extrema and no array flushing. The caller owns the record and may register it or use it as a temporary; release with Rbc_VectorFree. Does not create a name, Tcl command, mapped array or numeric allocation.

VectorObject *Rbc_VectorCreate(VectorInterpData *dataPtr, const char *vecName, const char *cmdName, const char *varName, Rbc_VectorType type, int *newPtr)¶

Create or reuse a registered vector and configure its access surfaces.

Qualifies the name in the current namespace; #auto selects an unused registry and command name. Existing vectors must be writable and have the requested type. Checks command collisions, replaces an existing instance command, and optionally maps an array. NULL command/variable arguments suppress that setup. Returns a borrowed record and writes newPtr on success, or NULL on error. Failure frees a newly created record, but does not roll back existing-object changes. Retains the record and interpreter across command deletion and mapping, and rejects destruction, new protection or replacement commands before continuing.

static void VectorInstDeleteProc(ClientData clientData)¶

Destroy a vector when its instance command is deleted.

Clears the command token before calling Rbc_VectorFree, avoiding deletion of the same command again. Called by Tcl; no record access follows destruction.

static void FreeVectorRecord(DestroyData data)¶

Release a record after Tcl preservation references have drained.

Calls ckfree on the supplied allocation. Used for deferred vector and client record reclamation; resources must already have been detached.

void Rbc_VectorFree(VectorObject *vPtr)¶

Destroy a vector identity, its observers and owned resources.

Ignores recursive destruction while the retained record is marked destroying. Preserves record/interpreter, deletes the command and mapping, unregisters the name, cancels pending idle work and delivers synchronous DESTROY with length zero. A temporary name copy remains valid during observer delivery. Detaches remaining clients, releases non-static storage, then defers record reclamation. Callbacks can run during command deletion, unmapping, notification and custom storage release. Preservation delays record reclamation, not logical destruction or storage cleanup. Requires a live non-NULL record; ignores read-only state.

int Rbc_VectorDuplicate(VectorObject *destPtr, VectorObject *srcPtr)¶

Resize an existing destination and copy the selected source values.

Requires matching numeric types; selected length is last-first+1. Checks byte arithmetic and writability, copies with memmove and copies the source offset. Completes copying before releasing old storage, including same-object slices. Invalidates extrema but does not create a vector, flush or notify. Retains the destination through custom release and rejects destruction, protection or storage/selection changes before returning success. Callback effects remain.

static int ResetVectorStorage(VectorObject *vPtr, void *valueArr, Tcl_Size length, Tcl_Size size, Tcl_FreeProc *freeProc)¶

Validate and replace the complete storage ownership contract.

Checks writability, nonnegative length/capacity, length<=capacity and byte counts. NULL data or zero capacity installs empty static storage. TCL_VOLATILE copies used values into capacity-sized owned storage, even for the same input address. Otherwise adopts/borrows the supplied pointer under freeProc. Releases the old owned allocation only when its address differs, after installing the completed metadata. Retains the record and interpreter through release and publication, skipping publication after destruction. Returns TCL_OK once the buffer ownership contract is accepted, even if callbacks destroy the vector; callers must not free an adopted buffer again. Precommit errors leave ownership with the caller. Does not reset the shared first/last selection.

int Rbc_VectorReset(VectorObject *vPtr, double *valueArr, Tcl_Size length, Tcl_Size size, Tcl_FreeProc *freeProc)¶

Apply a real storage reset after checking the vector type.

Rejects a complex vector with a Tcl error; otherwise delegates to ResetVectorStorage, including its ownership and callback restrictions. Does not convert types or make a separate numeric result.

static void VectorNotifyClients(ClientData clientData)¶

Deliver a snapshot of vector observers with stable update metadata.

Preserves vector, interpreter and snapshotted client IDs, not chain links. Clears pending update state before invoking callbacks. New clients wait for a later notification; detached or reassigned IDs are skipped and destruction stops remaining update callbacks. Temporarily installs the event interval on each client and restores its outer interval after nested delivery. Releases every retained ID even when delivery stops early.

int Rbc_VectorChangeLength(VectorObject *vPtr, Tcl_Size length)¶

Resize typed storage without publishing a change to clients.

Checks writability and a nonnegative length. Chooses a capacity starting at DEF_ARRAY_SIZE and doubling to fit, with overflow protection. Reuses an equal capacity allocation; otherwise copies the retained prefix into new storage. Zeros added values and installs length/capacity, selection 0..length-1 and invalid extrema before releasing old owned storage. Zero length releases storage. Does not flush or notify. Retains the record and interpreter across custom release; returns TCL_ERROR if it destroys, protects or changes the installed storage/selection. Such errors do not roll back the commit or callback effects.

static void ScheduleVectorUpdate(VectorObject *vPtr, int all, Tcl_Size first, Tcl_Size last)¶

Coalesce changed intervals and apply the notification policy.

Destroyed vectors are ignored. Increments dirty even when notifications are disabled. A full update supersedes interval metadata; ranged updates merge inclusive endpoints. Immediate mode can invoke callbacks before return; idle mode queues at most one pending callback. Does not itself invalidate or recompute extrema.

static void InvalidateVectorRange(VectorObject *vPtr)¶

Mark cached extrema as requiring recomputation.

Stores NaN bounds and negative indices, then sets UPDATE_RANGE. Does not inspect numeric data, increment dirty or schedule observers; callers separately publish the change.

static int UpdateVectorRangeForChangedRange(VectorObject *vPtr, Tcl_Size first, Tcl_Size last)¶

Maintain exact real-vector extrema after a bounded modification.

Requires a real vector whose caller has already changed only the stated inclusive interval. Returns FALSE without committing when the cache is invalid, bounds are invalid, an old extremum was touched or cache state is inconsistent. Otherwise scans only changed finite values, retaining the earliest index on equal extrema, and commits the exact cache. TRUE also covers a vector with no finite values.

int Rbc_CreateVector2(Tcl_Interp *interp, const char *vecName, const char *cmdName, const char *varName, Tcl_Size initialSize, Rbc_VectorType type, Rbc_Vector **vecPtrPtr)¶

Create or reuse a typed vector with explicit command and array names.

Validates nonnegative initialSize and real/complex type, then delegates to Rbc_VectorCreate. A positive size resizes; zero leaves an existing vector length unchanged. Writes an optional borrowed output pointer on success. Returns a Tcl status; initial resize failure removes a newly created identity if still alive. The output pointer is untouched on failure. Retains and checks the identity across callbacks; does not explicitly publish the initial resize. Existing-object changes and callback effects are not rolled back.
