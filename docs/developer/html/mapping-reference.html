Coordinate mapping C reference¶

These private helpers borrow their graph, axes and track records. Callers prepare current layout and retain the records throughout the operation. See Axes, mapping and track viewports for coordinate conventions and scoped viewport usage.

Data and screen coordinates¶

double Rbc_HMap(Graph *graphPtr, Axis *axisPtr, double x)¶

Map a data value to a horizontal widget coordinate.

Uses the owning track’s full world extent when the axis has a track; otherwise uses the graph offset and range. Does not clip, round, update layout, or execute Tcl. Descending direction is applied after normalization.

Parameters:

  • graphPtr – Borrowed graph with current ranges and layout.

  • axisPtr – Borrowed axis selecting the range, log scale and direction.

  • x – Data value, before logarithmic conversion.

Returns:

Double-precision pixel coordinate, or NAN for nonfinite input, invalid logarithmic input or failed normalization.

double Rbc_VMap(Graph *graphPtr, Axis *axisPtr, double y)¶

Map a data value to a vertical widget coordinate.

Uses the owning track’s full world extent when the axis has a track; otherwise uses the graph offset and range. Does not clip, round, update layout, or execute Tcl. Descending direction is applied after normalization.

Parameters:

  • graphPtr – Borrowed graph with current ranges and layout.

  • axisPtr – Borrowed axis selecting the range, log scale and direction.

  • y – Data value, before logarithmic conversion.

Returns:

Double-precision pixel coordinate, or NAN for nonfinite input, invalid logarithmic input or failed normalization.

Point2D Rbc_Map2D(Graph *graphPtr, double x, double y, Axis2D *pairPtr)¶

Map a data-coordinate pair to widget pixels without clipping.

Inversion swaps which screen direction receives each logical axis. Axis ownership selects track geometry without entering a temporary track scope. Does not update layout, round coordinates, or execute Tcl.

Parameters:

  • graphPtr – Borrowed graph with current ranges and layout.

  • x – X data value.

  • y – Y data value.

  • pairPtr – Borrowed pair containing non-NULL X and Y axes.

Returns:

Point2D in widget coordinates; invalid components may be NAN.

Point2D Rbc_InvMap2D(Graph *graphPtr, double x, double y, Axis2D *pairPtr)¶

Map widget pixels back to logical data coordinates.

Coordinates outside the plot are extrapolated rather than clipped. Log conversion returns NAN outside the supported DBL_MIN to DBL_MAX interval. The caller must check results for finiteness. Does not update layout or execute Tcl, and does not acquire ownership of graph or axes.

Parameters:

  • graphPtr – Borrowed graph with current ranges and layout.

  • x – Horizontal widget coordinate.

  • y – Vertical widget coordinate.

  • pairPtr – Borrowed pair containing non-NULL X and Y axes.

Returns:

Point2D in data coordinates, undoing inversion and axis direction.

Track layout and viewport scopes¶

struct RbcTrackViewport¶

Saved graph viewport for one paired track-entry scope.

Stack storage owned by the caller. Holds borrowed track identity and copies of graph extents, scales and padding; it neither retains nor frees resources. Restore in reverse entry order when nesting scopes.

void Rbc_LayoutTracks(Graph *graphPtr)¶

Compute full and visible track rectangles from the current plot.

Updates track extents and resets axis offsets. Fitted tracks distribute the available stacking range by minima and weights; scrolling tracks use their requested sizes and minima. Export computes a clamped offset without writing it back to the screen’s trackOffset. Does not draw or execute Tcl.

Parameters:

  • graphPtr – Borrowed graph with current plot geometry and track settings.

void Rbc_EnterTrack(Graph *graphPtr, RbcTrack *track, RbcTrackViewport *saved)¶

Temporarily select a track viewport for clipping and component work.

Uses visible bounds for clipping and full world bounds for the stacking direction’s offset and scale, clearing padding in that direction. Inversion changes the stacking direction from vertical to horizontal. NULL still saves state and changes activeTrack. Always pair with Rbc_LeaveTrack, including on early returns. Does not install a renderer clip or provide lifetime protection.

Parameters:

  • graphPtr – Borrowed graph whose viewport fields are temporarily changed.

  • track – Borrowed track, or NULL to select no active track.

  • saved – Caller-owned storage receiving the previous viewport.

void Rbc_LeaveTrack(Graph *graphPtr, const RbcTrackViewport *saved)¶

Restore the graph fields saved by a matching Rbc_EnterTrack call.

Restores active track, plot bounds, offsets, ranges, scales and padding. Does not undo other graph mutations, layout work or renderer clipping.

Parameters:

  • graphPtr – Same live graph used on entry.

  • saved – Intact saved viewport, restored in reverse order of nesting.

The graph layout entry point is documented in Graph lifecycle C reference.
