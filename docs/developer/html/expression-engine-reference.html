Expression engine internal C reference

These helpers are private to rbcVecMath.c. They operate on evaluator-owned temporaries and must not be used as named-vector mutation APIs. See Expression parser and adapter internals for parser state, adapter families and current limitations; Vector expression C reference covers the shared entry points.

Parameter directions and Tcl ownership use C calling conventions. Parser cursors point into caller-owned expression storage; returned prefix objects and evaluator temporaries have distinct release requirements. A helper may modify temporary state before returning an error. See the cursor and failure-state descriptions in Expression parser and adapter internals.

group Expression engine internals

Private evaluator helpers.

Registered vector types remain immutable.

Functions

static int GetArrayByteCount(Tcl_Interp *interp, Tcl_Size count, size_t elementSize, size_t *byteCountPtr)

Check a temporary-array allocation size.

Requires nonzero elementSize. Rejects negative count and size_t multiplication overflow with a Tcl error; writes byteCountPtr only on success. Does not allocate storage.

Parameters:

  • interp – [in] Evaluation/diagnostic interpreter; see Interpreter arguments.

  • count – [in] Nonnegative logical element count; negative values are rejected.

  • elementSize – [in] Nonzero element width in bytes, guaranteed by the caller.

  • byteCountPtr – [out] Required byte-count output, unchanged on failure.

Returns:

TCL_OK with the product, otherwise TCL_ERROR; no allocation occurs.

static int GetDoubleArrayByteCount(Tcl_Interp *interp, Tcl_Size count, size_t *byteCountPtr)

Check the byte count for real expression storage.

Delegates to GetArrayByteCount with sizeof(double); output remains untouched on validation failure.

Parameters:

Convert component results from complex input into real temporary storage.

Real input delegates to ComponentFunc. Complex input allocates real capacity and validates each transformed value before releasing old storage. Failure frees the new buffer and retains the old one. On success preserves length/capacity/selection and changes only the temporary type and owned data.

Parameters:

  • clientData – [in] Borrowed ComplexRealFunction descriptor, valid throughout synchronous dispatch; never freed here.

  • interp – [in] Evaluation/diagnostic interpreter; see Interpreter arguments.

  • vPtr – [inout] Exclusively owned evaluator temporary, not a registered named vector.

Returns:

TCL_OK on completion, otherwise TCL_ERROR; the adapter-specific contract defines partial mutation and finite checks.

These records describe stored state and resource ownership. Their presence in the reference does not make private layouts part of the installed C API.
