Expression engine internal C reference¶

These helpers are private to rbcVecMath.c. They operate on evaluator-owned temporaries and must not be used as named-vector mutation APIs. See Expression parser and adapter internals for parser state, adapter families and current limitations; Vector expression C reference covers the shared entry points.

group Expression engine internals

Private evaluator helpers.

Registered vector types remain immutable.

Functions

static int GetArrayByteCount(Tcl_Interp *interp, Tcl_Size count, size_t elementSize, size_t *byteCountPtr)¶

Check a temporary-array allocation size.

Requires nonzero elementSize. Rejects negative count and size_t multiplication overflow with a Tcl error; writes byteCountPtr only on success. Does not allocate storage.

static int GetDoubleArrayByteCount(Tcl_Interp *interp, Tcl_Size count, size_t *byteCountPtr)¶

Check the byte count for real expression storage.

Delegates to GetArrayByteCount with sizeof(double); output remains untouched on validation failure.

static int GetRotationOffset(Tcl_Interp *interp, double scalar, Tcl_Size length, Tcl_Size *offsetPtr)¶

Convert a scalar shift into a bounded rotation offset.

Initializes the output to zero. Length zero or one returns before finite validation. Otherwise rejects nonfinite counts, leaves nonpositive counts as a no-op for compatibility, reduces positive counts modulo length and truncates the remainder to Tcl_Size.

static int RotateExpressionVector(Tcl_Interp *interp, VectorObject *vPtr, int operator, double scalar)¶

Rotate real or complex temporary storage in place.

Requires LEFT_SHIFT or RIGHT_SHIFT and an evaluator-owned vector. Allocates a hold buffer for the wrapped portion, then uses memmove for overlap. Validation/allocation errors precede data mutation; successful rotation leaves type, length and selection unchanged and sends no notifications.

static void FreeExpressionData(VectorObject *vPtr)¶

Release a temporary allocation according to its current policy.

Static storage is borrowed, dynamic storage uses ckfree, and a custom policy is invoked directly. Does not clear metadata or retain the record across custom callbacks. Evaluator temporaries normally own dynamic storage; this is not the guarded public reset path.

static void ReleaseExpressionStorage(VectorObject *vPtr)¶

Release and clear an expression temporary’s storage metadata.

Resets data, length, capacity, selection and freeProc after FreeExpressionData. Leaves type and registration fields unchanged. Requires exclusive temporary ownership and no destructive release reentry.

static void SetExpressionVectorType(VectorObject *vPtr, Rbc_VectorType type)¶

Discard storage when changing an unregistered temporary’s type.

Same type is a no-op. A change asserts no registry entry, command or mapped array, releases old storage, then sets type. Not valid for changing a named vector’s immutable type.

static int CopyExpressionVector(VectorObject *destPtr, VectorObject *srcPtr)¶

Copy a selected source into an evaluator temporary of matching type.

Changes the destination temporary’s type before private duplication. The caller retains the source for the synchronous copy. Failure can leave the temporary cleared or retyped; no named output is committed here.

static int PromoteExpressionVectorToComplex(VectorObject *vPtr)¶

Promote a real temporary while preserving length and capacity.

Allocates complex capacity, copies used real values with zero imaginary parts and then releases old storage. Already-complex input is unchanged. Size/allocation failures leave old storage intact; requires exclusive temporary ownership across release.

static int SetExpressionRealScalar(VectorObject *vPtr, double value)¶

Replace an expression temporary with one real value.

Sets real type, resizes to one and stores the value. Returns Tcl status without checking finiteness; evaluation or the calling adapter owns that check.

static int SetExpressionComplexScalar(VectorObject *vPtr, Rbc_Complex value)¶

Replace an expression temporary with one complex value.

Sets complex type, resizes to one and stores the pair. Returns Tcl status; does not publish a named- vector change or validate component finiteness.

static int ApplyComplexBinaryValue(Tcl_Interp *interp, int operator, Rbc_Complex a, Rbc_Complex b, Rbc_Complex *resultPtr)¶

Compute one supported complex arithmetic operation.

Handles addition, subtraction, multiplication, division and power. Rejects zero divisor and unsupported operators; power delegates domain checks. Writes the output on success and returns Tcl status. The enclosing evaluator checks final finiteness.

static int ApplyComplexNotOperator(Tcl_Interp *interp, VectorObject *vPtr)¶

Replace a complex temporary with real boolean negation values.

Allocates a separate real array and computes exact complex-zero tests before releasing the input. Sets capacity equal to length and resets selection to the complete result. Validation/allocation failure leaves the input untouched.

static int ApplyComplexBooleanOperator(Tcl_Interp *interp, int operator, VectorObject *vPtr, VectorObject *v2Ptr)¶

Compute broadcast complex equality or logical results as real values.

Requires EQUAL, NEQ, AND or OR. Length-one operands broadcast; other lengths must match. Computes into a new real array before replacing the left temporary. Equality compares both components exactly; truth means either component is nonzero. Both operands have already been evaluated, so this is not short-circuit evaluation.

static int ApplyComplexShiftOperator(Tcl_Interp *interp, int operator, VectorObject *vPtr, VectorObject *v2Ptr)¶

Validate a real-valued scalar count and rotate the left temporary.

Requires a length-one right operand. A complex scalar with zero imaginary part is accepted; nonzero imaginary part is rejected. Rotation retains the left type and length.

static int ApplyComplexBinaryOperator(Tcl_Interp *interp, int operator, VectorObject *vPtr, VectorObject *v2Ptr)¶

Dispatch complex arithmetic, boolean or rotation operations.

Either operand may be real. Arithmetic promotes the left temporary and broadcasts scalars, otherwise requires equal lengths; boolean operations return real storage and shifts retain the left type. Unsupported ordering/modulus operators fail. Elementwise arithmetic can partially change the temporary before an error; named destinations are committed by the outer layer only.

static int ComplexValueIsFinite(Rbc_Complex value)¶

Test finiteness of both complex components.

Returns true only if both real and imaginary values are finite. Does not inspect errno or set a Tcl diagnostic.

static void InstallIndexProc(Tcl_HashTable *tablePtr, char *string, Rbc_VectorIndexProc *procPtr)¶

Install or remove a named special-index procedure.

Requires an initialized string-key hash table. Stores a borrowed function pointer, or deletes the entry for NULL. Does not own or release callback state.

static Tcl_Size First(VectorObject *vPtr)¶

Find the first finite real value in the selected interval.

Requires valid real storage and first/last bounds. Returns its storage index or -1. Does not alter selection or cached extrema.

static Tcl_Size Next(VectorObject *vPtr, Tcl_Size current)¶

Find the next finite real value after a current index.

Scans through last inclusive, returning a storage index or -1. Requires valid real storage and a current index from the same traversal.

static int CopyExpressionResult(Tcl_Interp *interp, VectorObject *destPtr, VectorObject *srcPtr)¶

Copy an evaluated temporary into a fixed-type destination.

Matching types delegate to private duplication. Real results can populate a complex destination with zero imaginary parts; complex-to-real assignment is rejected. Resizing/copying does not flush mapped caches or notify. The caller checks destination lifetime and writability across expression callbacks.

static void ExpressionDestinationChanged(Tcl_Interp *interp, ClientData clientData, Rbc_VectorNotify notify)¶

Record destruction of the original assignment destination.

clientData points to the caller’s live stack flag. Only DESTROY sets it. The destruction path releases the observer; the callback does not access the vector or keep an interpreter alive.

static int EvaluateExpression(Tcl_Interp *interp, char *string, Value *valuePtr)¶

Evaluate the complete writable expression into a caller-owned temporary.

Initializes parser state, calls NextValue and requires END. Rejects nonfinite components in the final result through MathError. The caller frees the temporary on success or failure. Substitutions and map callbacks execute Tcl; their side effects are not rolled back.

static int NextValue(Tcl_Interp *interp, ParseInfo *parsePtr, int prec, Value *valuePtr)¶

Evaluate one precedence-delimited expression into an existing temporary.

Owns a second operand temporary for this recursive invocation and frees it on every exit. Stops at END, CLOSE_PAREN, COMMA or an operator whose precedence is at most prec; token/nextPtr describe the terminator already scanned. Evaluates both operands before applying operators, including logical operators. Errors can leave partial temporary data and Tcl side effects.

static void SetMathError(Tcl_Interp *interp, const char *className, Tcl_Obj *messageObj)¶

Set an arithmetic message and structured Tcl error code.

Installs messageObj as result and as the third element of the ARITH/class/message error-code list. Accepts a newly created message object; Tcl result/error-code references retain it. Does not raise a completion code itself.

static void MathError(Tcl_Interp *interp, double value)¶

Classify a floating-point failure using errno and the value.

Reports DOMAIN for EDOM or NaN, UNDERFLOW/OVERFLOW for ERANGE or infinity, otherwise UNKNOWN. Reads but does not clear errno. Callers that depend on errno must reset it before the operation.

static int ParseSubstitutionResult(Tcl_Interp *interp, Value *valuePtr)¶

Convert a retained Tcl result into an expression value.

Increments the result object reference before clearing the interpreter result, so conversion cannot invalidate its borrowed string. Releases the reference afterward and returns ParseString status. Does not retain arbitrary vector identities resolved by the conversion.

static int ParseBracketScript(Tcl_Interp *interp, const char *string, const char **termPtr)¶

Locate a matching close bracket and evaluate the enclosed Tcl script.

Input begins after the opening bracket. Uses Tcl_ParseCommand repeatedly to respect command syntax, writes termPtr after the closing bracket once found, then returns Tcl_EvalEx completion unchanged. Missing terminator reports an error. The caller provides valid input and interpreter lifetime through evaluation.

static int ParseBracketValue(Tcl_Interp *interp, const char *string, const char **termPtr, Value *valuePtr)¶

Evaluate bracketed Tcl and convert its result to numeric storage.

Delegates bracket parsing/evaluation and then ParseSubstitutionResult. Non-OK Tcl completion propagates before numeric conversion.

static int ParseQuotedValue(Tcl_Interp *interp, const char *string, const char **termPtr, Value *valuePtr)¶

Parse and evaluate a quoted Tcl token sequence.

Input includes the opening quote. Uses Tcl parsing/substitution rules, releases parse storage after token evaluation, then converts the retained result. termPtr follows the closing quote on successful parsing; substitutions may execute Tcl.

static int ParseBracedValue(Tcl_Interp *interp, const char *string, const char **termPtr, Value *valuePtr)¶

Parse a braced Tcl value and convert it to expression storage.

Input includes the opening brace. Uses Tcl_ParseBraces and evaluates its tokens, preserving brace substitution rules including backslash-newline handling. Converts through ParseSubstitutionResult after freeing successful parse storage.

static int NextToken(Tcl_Interp *interp, ParseInfo *parsePtr, Value *valuePtr)¶

Scan one operator, delimiter or numeric/vector value.

Advances nextPtr and records token; VALUE fills the supplied temporary. Bare numbers use SetExpressionRealScalar. Substitutions use ParseString, while other names first try function lookup then vector/range lookup and copying. Variable traces, commands and map functions can execute Tcl; this scanner has no independent interpreter lifetime guard.

static double Fmod(double x, double y)¶

Compute the legacy floor-based real remainder.

Returns zero for a zero divisor; otherwise x-floor(x/y)*y. This differs from C fmod for negative operands. Does not report an error or validate finite input.

static int ParseString(Tcl_Interp *interp, const char *string, Value *valuePtr)¶

Interpret substitution text as a scalar, complex pair or vector reference.

Tries a fully consumed strtod number, then a two-element complex list, then a fully consumed vector/range reference. Does not accept arbitrary numeric lists as vectors. The current real-number branch uses the same real scalar setter as bare numeric tokens, clearing any complex type and imaginary component left in a reused operand temporary.

static Tcl_Obj *ParseMapPrefix(Tcl_Interp *interp, const char **nextPtr)¶

Parse and retain one Tcl command-prefix value.

Accepts braces, quotes, variable or bracket substitution, or a bare word ending at whitespace/comma/parenthesis. Substitutions run once in the current frame. Returns a reference- counted object and advances nextPtr, or NULL on failure. The caller decrements the reference; MapVector validates list structure and nonemptiness.

static int MapVector(Tcl_Interp *interp, Tcl_Obj *prefix, VectorObject *vPtr)¶

Apply a Tcl command prefix to every value of a detached temporary.

Retains individual prefix words against recursive shimmering and appends one real or complex-pair argument per invocation. Builds a separate zero-initialized result, promoting on the first pair return. Requires finite numeric results; empty input yields an empty real result with no calls. Tcl errors gain an element index, other completion codes become MAP COMPLETION errors, and invalid results become MAP VALUE errors. Frees argument references and partial results on failure; callback side effects remain.

static int ParseMapFunction(Tcl_Interp *interp, ParseInfo *parsePtr, Value *valuePtr)¶

Parse map(prefix, expression) before invoking element callbacks.

Retains the parsed prefix while evaluating the complete second argument. Requires comma and closing parenthesis; successful MapVector changes token to VALUE. Releases the prefix on every exit. Prefix and numeric-argument evaluation precede the per-element callbacks.

static int ParseMathFunction(Tcl_Interp *interp, char *start, ParseInfo *parsePtr, Value *valuePtr)¶

Try function syntax before falling back to vector-name parsing.

Requires a writable input string: temporarily replaces the opening parenthesis with NUL during lookup, then restores it. Recognizes map specially; ordinary names use the interpreter’s math table. TCL_RETURN means no recognized function, not a script return. Parses one expression argument and invokes its adapter after the close parenthesis. The hash entry is borrowed across argument evaluation; this helper does not guard registry teardown during callbacks.

static int ComponentFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Apply a real component function to finite selected values.

Rejects complex input, resets errno and walks First/Next. Writes each result before errno/finite validation; failure can leave a partially transformed temporary. Does not notify or commit named output.

static int ComplexComponentFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Apply paired real/complex component implementations.

Real input delegates to ComponentFunc. Complex input visits all used values, resets errno for each call, validates both components and stores each successful result. Errors can leave earlier elements changed.

static int ScalarFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Reduce a real temporary to one real value.

Rejects complex input, computes the scalar before resizing and checks errno. Stores one value on successful resize; final finiteness is checked by EvaluateExpression. No named-vector notification is sent.

static int ComplexScalarFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Reduce a real or complex temporary while retaining its type.

Selects the corresponding reducer, computes before resizing to one, and reports errno failures. A complex result remains a pair. Final nonfinite results are rejected by the enclosing evaluator.

static int ComplexRealScalarFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Reduce either numeric type to one real result.

Computes the reduction before any type change or release, checks errno, then uses SetExpressionRealScalar. Operates on evaluator temporaries only; final finiteness belongs to EvaluateExpression.

static int VectorFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Invoke a real-only whole-vector function adapter.

Rejects complex input and returns the selected function’s Tcl status. The function owns its mutation/allocation policy; this wrapper neither checks errno nor publishes notifications.

static int ComplexRealFunc(ClientData clientData, Tcl_Interp *interp, VectorObject *vPtr)¶

Convert component results from complex input into real temporary storage.

Real input delegates to ComponentFunc. Complex input allocates real capacity and validates each transformed value before releasing old storage. Failure frees the new buffer and retains the old one. On success preserves length/capacity/selection and changes only the temporary type and owned data.
