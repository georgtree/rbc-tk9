RBC Developer Manual
====================

This manual describes the C implementation for contributors. It is separate
from the Tcl command reference generated by Ruff. The interfaces described here
are private unless explicitly identified as part of the installed vector API.

The manual covers graph rendering, the common widget lifecycle and vector
ownership. Architecture and header chapters provide context; C references are
extracted from maintained source comments by Doxygen and included by Breathe.
Detailed numerical algorithms, binding and picking contracts, and individual
backend algorithms remain future chapters.
